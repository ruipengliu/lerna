# Real Content conformance world

`New` requires real PostgreSQL, Linux local object primitives, an absolute durable
TMPDIR and an absolute owned-scope registry. Missing prerequisites fail; none skip.
It creates one fresh exact recorded schema and object root, retaining native
holders from partial setup. `Reopen` really closes and reopens both PG/object handles.

Cleanup seals the world, confirms its specific infrastructure/current/admin/object
holders and every setup file's first Close, then deletes only original acknowledged
scope identities. Unknown closure or invocation exit retains the exact scope.
`HoldPolicy` uses a real row lock and pg_blocking_pids only as mechanical wait
control. It is never a private-table business oracle. `WriteIndependentObject`
creates/synchronizes exact owned byte faults/controls with tracked file closures.
Business assertions stay at public Content/Command entries and independent bytes.

Tagged migration tests cover fresh initialization, checksum repeat/refusal and
native reopen. `make test-integration` and `make test-integration-race` include
this fixture and the tagged local lifetime package.

Policy/version/Command/reader lock controls each retain their original locker and
observer until actual close. Ledger and parent-directory registration files are
owned immediately; any registration error, including Sync or first Close, seals
cleanup even if later handles close normally. Mechanical first-close tests use
independent real Close observations; they do not claim native close failures.
