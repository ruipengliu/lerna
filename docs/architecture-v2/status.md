## 2. 如何阅读检查结果

- 文档结构检查确认本地链接、锚点、表格和围栏是否完整，不证明设计语义或实现正确。
- Schema 与构造序列检查确认声明范围内的字段及关联，不证明引用正文存在、当前权限有效或外部效果发生。
- 图示渲染检查确认图形可呈现和可阅读，不证明并发、事务或恢复行为。
- 运行验收须报告实际环境、精确版本、操作步骤和可复现结果。只有通过对应验收，才能声明相应能力达到 L2、L3 或 L4。

[历史审查记录](review.md)保留原方案历次检查的日期、数量、发现和限制。其中的「本轮」指该条历史记录所属的修订，不表示本次整理；记录中的旧命令用于追溯原检查。
