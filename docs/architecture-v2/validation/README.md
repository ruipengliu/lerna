# 验收规则与复现入口

验收分别判断契约、真实恢复、质量、互操作和容量，各类证据不能互相替代。本文定义判定方法，[故障实验](fault-experiments.md)定义刺激与断言；所有执行结果和实现状态只记录在 [review](../review.md)。

## 静态校验

从仓库根运行以下命令，校验器只读取本系列内的机器资产；环境需要 Python 3、[requirements.txt](requirements.txt) 中的依赖和 Node.js。

```sh
python3 docs/architecture-v2/validation/validate_all.py
```

| 校验入口 | 检查内容 |
| --- | --- |
| [validate.py](validate.py) | 完成结果 Schema 和条件／效果关联 |
| [validate_protocol.py](validate_protocol.py) | 方法登记、协议正例与定向反例、跨调用身份和状态关系 |
| [validate_transport.py](validate_transport.py) | 严格编码、连接、帧、请求序号及证明向量 |
| [verify_transport_proofs.mjs](verify_transport_proofs.mjs) | JavaScript 侧摘要和签名证明向量 |
| [validate_brain.py](validate_brain.py) | 内部生成草稿、内容发布及有限计划实例化 |
| [validate_lease.py](validate_lease.py) | 离线租约账单的给定序列 |
| [validate_release_recovery.py](validate_release_recovery.py) | 独立批准回退和每计划唯一评测 run |
| [check_documents.py](check_documents.py) | 本地链接、锚点、围栏、表格、独立目录约束及规范资产导航 |

静态规则只能判断给定输入及关系，不能观察数据库是否真的提交、权限是否实际生效或目标是否产生效果。Mermaid 的结构检查、渲染和独立阅读也分别取证。

## 运行证据

每份实验固定版本、环境、初始状态、完整样本、授权、预算、期限、故障位置、独立真值与停止规则。测试通过真实入口触发，不能手改最终业务表制造通过。

| 证据等级 | 必需证据 |
| --- | --- |
| L1 契约定义 | 职责、字段、状态、错误、权限、恢复和能力声明可实施评审 |
| L2 参考实现 | 对应代码可运行，用例可复现，环境和限制可查 |
| L3 替换互操作 | 不同实现通过同一套契约与跨组件、跨节点用例 |
| L4 恢复治理 | 故障注入、权限变化、控制、升级和恢复；改善另需正式证据 |

Brain、Memory、Executor 各至少两种实现，分别验证本机 Orchestrator＋云能力和云 Orchestrator＋端侧能力；同实现换地址、只换模型供应商不算独立替换。模拟目标的真值入口只授予判定器，Agent 仍从正常观察操作。

每项断言输出 pass、fail 或 inconclusive。已知违规为 fail，必要证据缺席为 inconclusive；不得用其他通过项抵消。报告列出未决效果、账单和清理残留，即使 Task 已终态。受限正文和凭据不能为复现而进入公共日志。

## 计数与统计

冻结分母后再运行，保留失败、超时、未知、重试和成本。指标定义如下。

| 指标 | 计数规则 |
| --- | --- |
| API 覆盖 | 提供方命名空间＋语义业务操作唯一；版本、实例、账号、SDK 包装、参数排列不增数。只把所有声称支持范围内适用用例均通过且无必需 unknown 的操作计入至少 1000 项目标 |
| 首次调用正确率 | 分母为应发工具调用的冻结任务样本；未发、错误拒绝、工具／目标／参数／权限错误计失败。第一次逻辑行动的选择与实际目标适配正确才计入分子，目标 ≥90% |
| 有限重试任务成功率 | 分母为正式范围全部任务；失败、超时、未知效果和预算耗尽计未成功。每逻辑步骤最多两次额外安全尝试，任务轮数、期限和费用另固定，目标 ≥95% |
| 质量 | 正确性、证据支撑、约束和时效分别报告，不用加权总分掩盖关键失败 |
| 时延与成本 | 原入口至各成功点的 p50/p95/p99；全部模型物理请求、工具、失败、返工及核对费用 |

API 清单登记语义身份、提供方、输入／效果、别名和支持版本矩阵，每项至少十个不同有效上下文，加适用的参数、权限、幂等、查询、取消及故障反例。十个上下文用于覆盖，不直接证明该 API 达到比例目标。只读、幂等写、无幂等保证的写、单步、多步和歧义任务分层报告。

首次答复丢失但独立证据证明原行动正确可以计首次正确；证据不足保留未知，不能把第二次成功补成第一次。准备材料检索和被测目标动作的边界预先固定。权限负例独立作为契约集，不能混入“应调用”分母增分。排除项预先登记，正式开始后的提供方故障仍计失败；整次实验无效时保留记录并整组重跑。

### 比例目标与统计门槛

正式独立二元样本同时报告比例目标和双侧 Wilson 95% 区间下界，统计门槛要求下界达到对应的 90%／95%。计算固定 `z=1.9599639845`；这不是单侧 95% 下界。

| 样本来源 | 正式推断规则 |
| --- | --- |
| 明确抽样框架中的独立任务 | 预先固定总体、单位、样本量和停止规则，使用 Wilson 门槛 |
| 固定穷举或人工覆盖集 | 比例仅描述该集合，总体统计门槛为 inconclusive |
| 同源改写、共享环境等相关任务 | 保存来源组／cluster_map，改独立抽样或事先审查的组级分析；不能只减 n 而保留原成功数 |
| 重复种子、物理重投或有限重试 | 保留全部记录，一个逻辑样本占一个位置，不增加独立 n 或择优 |
| 不等概率、加权分层 | 保存权重和目标分布，不直接套普通 Wilson；方法在结果出现前冻结 |

计划内关键权限、隔离和重复副作用反例要求零违反且无必需 unknown。这是独立契约门槛，不能用高质量比例抵消。

<a id="comparison"></a>
### 改善比较

正式比较固定一个候选，与基线使用相同样本、初始状态、许可和预算，独立运行并判定。未知效果在已证明成功率中取零，同时保留未知原因。

| 配对结果 | 记号 |
| --- | --- |
| 双方成功 | a |
| 仅候选成功 | b |
| 仅基线成功 | c |
| 双方未成功 | d |

`n=a+b+c+d`，净改善为 `(b−c)/n`。主要指标须达到预先固定且大于零的 minimum_practical_gain，同时满足每个关键类别、契约、费用和延迟界限。缺失或未跑位置不能从分母删除。

独立二元配对可把精确 McNemar 检验作为预定附加条件；相关配对、连续评分、多指标或多候选需要另定适用方法与多重比较规则。显著性不能替代实用收益和逐类退化检查。首次正式确认前固定整个改进过程的候选范围、尝试上限和停止规则；换申请、候选或保留分片不清零历史。默认一次正式确认，多次需预定整体推断方法。

报告独立输出 target_attainment、statistical_gate、improvement_gate，先判断依据是否足够再判阈值，缺依据为 inconclusive。发布还需正式证据资格、完整必需覆盖、契约通过与[受信批准](../evaluation.md)。

## 专项验收

V1、V2 是专项编号，不对应工程阶段。真实质量与回放机制分别计量。

| 专项 | 样本与通过条件 |
| --- | --- |
| V1 联网问答 | 覆盖直接回答、多来源、冲突、证据不足、高时效；断言映射实际取得内容，保留发布时间、获取时间和截止。总体正确性及引用支撑均 ≥90%，实际获取和时间记录完整率 100%，受限资料外发零违反 |
| V2 手机 GUI | 至少三个独立身份和状态的模拟设备，含列表、详情、表单、确认、返回；点击／滑动／输入／返回改变可观察状态。按首次 90%、有限重试 95% 口径判定，并验证旧观察、失效控制不启动新动作 |

## 优化对照

优化先比较单因素，再比较组合；所有候选使用相同已通过适用契约的授权和恢复机制。策略改变须取得所属任务类别的收益证据，未覆盖类别保持固定原配置。

| 对照 | 基线与候选 | 需额外观测 |
| --- | --- | --- |
| X-01 上下文 | 规则裁剪、原文抽取、独立获准摘要 | 多轮约束／来源保留、完整费用、超窗拒绝 |
| X-02 记忆 | 预提取经验、按任务读时整理、按进展检索 | 纠正、时间冲突、partial、处理／存储成本 |
| X-03 选择 | 准确目录＋规则／检索、限定 Skill 策略 | 未召回、选错、加载过晚、加载无收益分别计数 |
| X-04 规划 | 同模型规则优先路径、提示或提案粒度调整 | 目标漏项、补证轮数、收益；换模型另作因素 |
| X-05 协作 | 单 Agent、有限独立并行分支 | 顺序任务另分层；包含汇总、等待、重复与清理成本 |
| X-06 有限计划 | 每步决策、固定前提及退出规则的计划 | 构建／维护／失配、旧效果未知、前项质量失败 |

完成可信度同时报告“错误完成数／全部声明完成数”和“错误完成数／全部参考未满足数”；误拒绝按参考满足样本计，unknown 单列。成功成本为全部冻结样本费用除以独立确认成功数，不能只统计成功者账单；分母为零标不适用。账单未结展示已知、预留／未知部分和最终性，不提前断言省费。

长任务按长度和压缩次数分层，记忆以加入／纠正／禁用的配对效果评估。判断器敏感性使用预定第二判断单列，不能择优。OPT 组合故障及框架、模块运行矩阵见[故障实验](fault-experiments.md)。

### Memory 策略对照

Memory 对照按用户、原始会话和任务来源组划分开发、选择、保留数据；派生摘要、改写和种子留在原组。各臂从同一初始 Memory 快照独立运行，不共享先前写入，标注答案与反馈不进入被测记忆。

| 编号 | 比较 |
| --- | --- |
| E0 | 无可选长期记忆与 B0 字面基线 |
| E1 | B0 与 B1 中文词法，双方关闭关系扩展 |
| E2 | B1 与 B2 混合候选，双方关闭关系扩展 |
| E3 | 原提取与覆盖／语义保留／来源支撑检查 |
| E3a | 固定同一语料，有无双向一跳关系扩展 |
| E4 | 已提取经验与按当前进展读时整理 |
| E5 | 仅组合已有独立收益证据的策略 |

先在开发集估方差和负载，再在读取选择／保留结果前冻结最小改善、非劣界、样本量、费用和延迟。报告保存断言支撑率／应存覆盖率、否定与时间范围保留、Recall@k／排序、纠正后旧值采用和误合并、下游真实成功及全部提取／向量／读取／整理／重建／清理成本。未授权处理、重复发布或关闭后复活均阻止批准。

建设先完成 B0、候选发布及来源关闭闭环，再分别比较中文词法、写入质量和一跳关系，随后按证据选择 B2 或读时整理；残余问题才触发多跳、重排、训练或流程产物设计。

## 保证与限制

固定样本通过不证明所有未来任务或平台可靠，模拟设备也不证明真机支持。统计结论只适用于冻结的抽样框架和时间窗。契约、安全、恢复、质量及容量各自判定，不能用一个综合分数替代。

## 交付检查

交付先通过本目录静态校验，再由不带设计讨论上下文的独立读者复述正常链和关键异常的负责方、持久事实、成功点与继续条件。读者无法推出的步骤回到对应权威文档修订；语义改变进入[待决问题](../open-questions.md)，修订后重新校验受影响资产。
