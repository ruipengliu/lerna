# 1.4 系统协作过程

组件全景给出了职责和依赖。本章把这些组件放到同一次处理过程中：输入进入业务模块，内核组织决策，执行系统产生可核对事实，交互系统交付结果。先认识这条共同过程，后续各子系统章节再展开本方的行为与成立条件。

下面讨论需要外部行动的任务。输入目标已经明确，相关资源和处理位置具备许可；工具可能异步执行。纯回答任务可能不需要工具步骤，已准入工作也不必每推进一步都重新请求模型。

## 1. 从输入到正式任务

Renderer 采集用户输入，UIStateManager 根据输入目标形成正式操作并保存转交责任。目标可能是新任务、原任务的补充、等待项回应、控制要求或独立应用操作。一个聊天窗口可以包含多个对象，系统不能仅凭窗口身份推定任务。

任务输入交给 Core。内核检查目标、身份、控制和预算等条件，由 RunStore 与 WorkStore 共同保存接纳结果、任务状态和后续工作。界面显示“已收到”或通信端确认持久接收，不代表任务已被业务接纳；界面根据业务结果更新正式进展。

## 2. 从任务事实到有限提案

内核先恢复应该优先处理的既有工作。需要新判断时，领取决策工作并持久预留生成预算，再以提交后的任务版本组织输入。ContextAssembler 汇集获准证据、记忆和能力信息，保留来源修订、约束与缺口；它不修改记忆权威，也不推进任务。

Brain 消费这份受控输入，必要时通过 ModelAdapter 调用模型，输出有限提案或明确失败。能力目录提供候选和准确版本声明；检索排名只帮助选择，不授予权限。提案描述目标、参数与依赖，不能直接启动工具。

生成在事务外进行，返回后依据可能已经变化。Core 复核任务版本、来源、资格、控制、能力、权限和预算，通过后才原子保存准入记录、操作关联及待处理工作。来源与权限的跨模块检查不形成全系统事务，实际处理端还要执行自己的检查。

## 3. 从已准入工作到外部效果

Scheduler 找到到期候选，Worker 取得有效领取，完成一轮有限处理。到期只是检查时机，不代表依赖和执行资格已经满足。发往执行系统的请求沿稳定操作身份交接；每个模块在自己的存储中保存记录。

ExecutionCoordinator 接纳操作，固定输入、实现版本与恢复依据。实际启动前复核当前条件，并持久保存启动准备；Driver 再调用外部 API 或设备。外部调用不在任务数据库事务内，启动准备也不能证明调用尚未发出。

异步工具返回作业引用时，执行系统保存原操作与作业的关联及后续核对安排。Worker 可以结束本轮，下一轮沿原关联查询进展。槽位是否可释放取决于其责任，外部作业仍占用的配额不能随 Worker 结束而释放。

## 4. 从执行事实到交付

执行系统将效果证据与待回报责任共同保存。内核核对报告、幂等纳入任务事实，并更新依赖和后续工作。已经准入且条件齐备的后续步骤可以按规则继续；新的判断才需要再次调用 Brain。

完成判定由任务目标决定。工具接受请求、外部效果已确认、产物满足要求、必要交付已完成，分别需要相应依据。交互系统保存呈现进展；只有交付属于任务条件时，内核才将核对后的呈现事实纳入完成判断。终态还须满足在途责任和预算处置条件，不能只看某次调用返回成功。

| 交接 | 接收者据此可以判断什么 | 仍不能判断什么 |
| --- | --- | --- |
| 持久接收回执 | 消息和后续处理责任已保存。 | 业务是否接纳、外部效果是否发生。 |
| 业务接纳回执 | 对应操作已经由业务模块接纳。 | 工具是否完成，任务是否完成。 |
| 效果报告 | 在声明的证据范围内，原操作效果已确认或仍未知。 | 其他依赖、内容质量与用户交付是否完成。 |
| 呈现反馈 | 对应显示版本已应用或发生显示失败。 | 用户是否阅读、是否同意，或其他业务是否成功。 |

## 5. 条件改变时沿哪条责任继续

若准入提交后回执丢失，先查原提交；若执行端接纳或外部效果未知，沿原操作查询和核对。两者的不确定性不同，都不能直接变成重新生成、重新执行。

若用户在模型生成期间追加要求，正式接纳的新输入推进任务版本，旧提案不能按旧依据准入。若来源被删除，即使任务版本未变，来源依赖也可能失效。暂停、取消和撤销分别阻挡其适用的新工作，在途动作仍要核对。每个实际处理位置依据自己的当前记录落实限制。

若连接中断，补齐原消息和操作结果；若进程退出，从持久工作恢复领取；若任务要转移拥有者，执行独立的所有权移交过程。重连、换 Worker 和移交不是同一件事。

至此，读者可以将一次处理放回四类依据：任务事实、来源与权限、执行效果、呈现进展。下一章据此列出[对象与状态归属](05-domain-and-state.md)；[子系统设计](../02-subsystems/README.md)展开各方行为，[跨模块协作](../03-coordination/README.md)展开交接失败与控制条件。[完整任务示例](../../examples/01-task-lifecycle.md)把这条过程落实到具体资料、操作和交付物。
