## B. 到期核对工作的一轮处理

下面仅展开执行端的核对轮次，中文动作为行为示意。内核消费结果的原子组见[详细设计的输入处理](../design/01-runtime-kernel.md#commands)；内核 RECONCILE 查询原执行操作，执行端才沿外部作业 J 核对。

```text
执行端处理到期核对:
  候选 = 分批扫描已保存且到期的未决工作
  对每个候选:
    按当前条件在执行存储中领取；失败则跳过
    读取原操作 S、作业 J 与当前记录版本
    事实 = 在事务外查询原作业 J
    按记录版本与当前领取资格原子提交:
      保存事实，完成本轮工作
      若仍需核对: 登记下次核对工作
      若结果明确: 登记报告及待发 Outbox
    提交确认后，释放可释放的本地槽位
    提交未知则查原提交，不推进后续工作
```
