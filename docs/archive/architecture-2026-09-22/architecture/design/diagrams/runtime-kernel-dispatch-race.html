共同起点：操作 S 已准入，S = UNSENT，Outbox = HELD。两个分支各自从该起点开始，先后指事务成功提交顺序。

A 分支。 更新增加目标修订，冻结尚未派发的目标工作并隔离旧领取。新决策可显式 KEEP／DROP；未提及的工作继续冻结。

B 分支。 派发准备原子保存 MAY_HAVE_SENT 与 Outbox READY。实际网络发送在事务外，可能尚未发生；因此更新后仍须核对原操作，不能用“没有回包”证明可以 DROP。
