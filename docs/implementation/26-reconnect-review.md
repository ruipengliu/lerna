## Spec

审查发现并关闭五项问题：

- P1：缓存快照可能绕过当前披露权限。恢复逐条重新检查，成功回执查询原权威；撤权后不返回旧快照。
- P2：KNOWN 非终态停止刷新。后续仍查询原操作，只有已确认终态可清理。
- P2：关闭接收流可能丢失未确认回复的授权依据。回复自身保留脱敏关联，不依赖已清理的请求正文。
- P2：对象级拒绝阻塞健康消息。接收拒绝原子保存摘要和通用失败；发送拒绝使用不执行的摘要处置补齐位置，后续消息继续。预算在实际尝试时计费。
- P2：KNOWN 的后续查询未计入持久预算。所有恢复查询统一计费，耗尽后明确保留 UNKNOWN，不因重启重置。
