## 两种模式与资源上界

A：冻结材料经真实 loopback HTTP 搜索及页面服务，答案由真实模型 API 生成。B：同版材料经固定回放 Adapter，答案由同一模型 API 生成。先 A 四例，再 B 四例，各例只运行一次；没有自动质量纠错或失败后补考。B 不访问搜索及页面网络，但仍访问模型服务，不能将“回放”写成完全离线。

两种模式使用独立原任务、相同配置上界，不要求输出字节相同。实际页面取得时间、URL、模式、失败类型和模型计费分别记录；不得复制 A 的取得时间冒充 B 的读取时间。比较逐例状态、事实覆盖、引文支持、错误、用量与耗时，不把传输差异解释成模型能力变化。

本轮上界：每任务 3 个行动操作、3 次 Core 模型请求（其中最多 1 次外部答案模型请求）、128 次必要查询；单来源共享网络操作额度 2，冲突例 3。页面 1024 字节、搜索响应 4096 字节、最多四个候选；总调用 30 秒、任务期限 1 分钟、单次 HTTP 1 秒，沿用参考执行期限，不因服务慢而增加本轮上界。答案输出最多 512 token。

模型 token 预留在第一次运行前由执行锁定文件固定：至少覆盖两次行动决策的 18432 token，加上 max(2048, 模型声明 InputUpper)+512 的答案预留；不能超过 RuntimeConfig 的 1048576 上限。实际模型能力与请求参数原样记录，不能将云模型标记为 local 或缩小其声明上界。

八例合计最多 8 次外部模型请求。失败、超时、未知响应也计入，不退款或改用新任务重试；未发出请求的失败单独记录。此前提出的额外 12 次模型请求预算尚未得到答复，本计划**不构成费用授权**，不得使用现有凭证启动调用。

## 独立评分

生成全部结束后，评审者只读取已归档的原始输入、原始模型输出、正式发布答案和冻结期望；不由被测模型自评。报告评审者身份或角色、是否参与实现、是否看过既有答案及评分时间，不将实施者复核称为外部盲审。

先调用 NewSemanticReview 绑定原始字节并验证结构，再独立填写每条主张与引用的支持判断、正文支持、范围、处置和全部禁止项；每项有具体理由。SummarizeSemanticReview 只核验绑定与完整性，不认证评审者或语义真值。

- 引用支持：分母为实际主张—引用对，分子为被片段支持的对；同一来源支撑不同主张分别计数。另完整检查正文，防止未进入 claims 的无据结论逃逸。
- 必要事实覆盖：分母固定为上表的 2/0/2/0，额外正确事实不补偿遗漏；分别报告分子/分母。
- 零分母为不适用，不换算为 100%。结构拒绝、任务失败或无正式答案保留失败状态，不能从总体结果中删除，也不能将空答案视为合格。
- 每例合格要求：有正式可查询答案、状态正确、适用事实全部覆盖、全部引用支持、正文/范围/处置/禁止项均通过。权限或隐私违规直接失败，不做平均抵消。
- 报告八例逐项结果；不从该样本推断完整 V1 的 90%/95% 门槛。新版本再次运行必须另建计划，保留本轮全部输出与失败。
