Memory 的通用存储/处理校验不能自动证明拥有提取权或持续监听权。现有来源校验是按来源逐项检查，不提供通用自然语言脱敏证明。首版提取器采用允许位置内的本地规则，规则不支持时形成可查询等待或不支持状态。
