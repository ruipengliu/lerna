这是实施助手对本地协议夹具输出的逐例审阅，不是生成夹具自评分，也不是独立外部人员的盲审或真实模型质量报告。不运行答案生成代码来推出预期评分。下面只判断保留的文本与引用；临时 Content 已移除，缺少原始失败事实及无引用正文的持久化快照，因此不将无法重读的引用身份视为完整证据归档。

支持分母为实际回答中需要证据的关键事实，覆盖分母为预登记必要事实。没有事实主张的输出不以 100% 计分。占位语句单独判无效，不因没有可核验主张而获得质量通过。范围与缺口处置单独判断，不能被引用分数抵消。
