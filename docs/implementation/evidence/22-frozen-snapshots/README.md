# 冻结材料的模型输入与输出快照

该轮在原四类虚构来源上运行实际回环 HTTP、Core、SQLite、SDK 和正式答案发布。模型仍为本地协议夹具，没有调用真实模型或公网；固定回放尚未运行。原来源与 expectations 不变，未提高任务预算或改写预期。

复现命令：

```sh
go test -race ./profiles/fetchcheck -run 'Test(FrozenResearch|OneTask|ActionBrainHands|ConcurrentResearch)' -count=1 -v
```

`test.log` 的 `record=` 行保存模型实际收到的 Brain.Input、原模型 JSON 输出及读取到的正式答案。四个同名 JSON 文件从这些行提取，包含运行模式、模型身份及来源摘要；不重新生成答案。测试逐一核对原模型输出与正式答案在结构和值上相同，并直接用保留 Input 重验原输出。成功证据带实际正文、URL、摘要、获取时间和引用身份；有限失败块带原状态、模式和请求数。输入快照由模型边界深拷贝，不从 expectations 或评分结果重建。

范围严格限于测试中明确提供的虚构公开材料。此日志出口不接受用户数据，也不是通用 Content 导出器。通用运行归档仍需当前授权、用途、位置、来源继承及留存期限治理；不得将通过此测试视为获准将受限来源永久写入文件。

临时 Content 在测试后删除。新的快照使本次答案的缺口/引用事实可离线复查，但它们不是可继续使用的在线 Content 引用，不包含签名证明，也不能据此重新获得已撤销的权限。快照只记录答案阶段实际输入，不声称完整记录所有搜索决策上下文或运行事件。

本轮未改动占位回答与预设缺口响应。先前 `22-frozen-loopback/review.md` 指出的可回答例遗漏事实、失败例描述不够具体等文字问题仍然存在。归档完整性和引用结构通过不等于语义质量通过。
