# 已保存协议答案的独立语义评审

本记录由实施助手在生成完成后阅读四份 `22-frozen-snapshots` 的原答案和实际输入证据作出，沿用原 `expectations-v1.json` 的必要事实、范围、处置及禁止结论。没有重新生成答案、调用模型或将评分材料传入候选上下文；不是外部盲审，也不是实际模型效果报告。

`search-semantic-review-v1` 是本次新增的评审记录格式，属于对历史输出的事后补评，不宣称该格式和计数细节在历史运行前已冻结。后续正式运行应先固定此格式与评价方法。旧报告及原失败保持不变。

计数与边界：

- 引用支持分母为答案中每个“主张—引用”对；同一来源用于两个主张分别计数。分子仅计独立判断为支持该主张的引用。未评或不支持均保留在分母，不按唯一 URL 去重。
- 必要事实覆盖继续沿用原冻结分母，不以答案写出的主张数量替代。
- 无引用时支持为 0/0、不适用。正文结论支持、范围、处置及每条禁止结论仍必须评审，不能因此宣布答案合格。
- `citation:i:j` 评价该片段是否支持该主张；`answer_support` 评价答案正文有无超出实际证据的结论；`scope` 评价范围及时效；`disposition` 评价是否按题目要求应答或说明缺口/冲突/失败；`forbidden:i` 的 pass 表示没有违反对应禁止项。
- 每个完成判断有理由，初始为 unreviewed。答案、实际输入及期望摘要绑定，缺项、重复项和错误版本拒绝。结构校验只证明引文对应实际输入，不能证明语义判断正确或评审者身份。
- `ReviewComplete` 仅表示判断填写完整；即使有失败项也可以为 true。没有综合质量通过标志，零分母不能转成百分之百。

| 用例 | 引用支持 | 必要事实覆盖 | 独立判断 |
| --- | --- | --- | --- |
| answerable | 0/1 | 0/2 | 主张和答案是占位文字，引用没有支撑其含义；范围也未明确原桥和记录版本。 |
| conflicting | 2/2 | 2/2 | 保留两份记录各自年份与来源，不以新版替代冲突。 |
| insufficient | 0/0，不适用 | 0/0，不适用 | 正确限定为所取记录不提供造价，不声称造价不存在。 |
| fetch_failed | 0/0，不适用 | 0/0，不适用 | 没有伪造正文，但笼统失败表达没有说明拒绝原因及承载力仍待核实，处置项失败。 |

每项理由及精确绑定在同名 JSON。已保存判断的复核命令不生成新判断，也不发出网络或模型请求：

```sh
cp docs/implementation/evidence/22-semantic-review/check.go.txt /tmp/lerna-22-semantic-check.go
go run /tmp/lerna-22-semantic-check.go
rm /tmp/lerna-22-semantic-check.go
```
