# 22 票真实模型评价 v3

计划 search-small-prospective-v3，执行前登记。v2 的8例失败已归档，不追认、不替换。v3 是看过v2结果后修复的已知材料回归，不是盲测或泛化正确率。

材料、四例顺序、必要事实分母2/0/2/0、禁止项及逐例合格要求沿用 [v2方法](22-prospective-evaluation.md)，固定文件摘要见本轮execution-lock。先loopback四例，再replay四例；每例一次，最多8次真实答案模型请求，输出512 token，无自动补考。仍为真实本地HTTP材料与固定回放对照，公网搜索另验。

唯一模型表达方式变更：开启Ark CompactEvidence，提供最多64个、每个最多512字节的输入原文片段。模型给出支持其主张的片段编号，适配器展开该输入的准确字节范围、引用、摘要和获取时间，仍由原Brain证据校验器验证。ProviderContent是原始模型文本，Content是展开后的模型结果，正式发布答案另行保存；三者不能混为一谈。明确要求answer/scope非空，不通过省略难点或消除冲突取巧。模型能力版本后缀citations-v2区分旧恢复绑定。

每任务模型token预算262144、查询128、搜索4096字节、页面1024字节、三次Core模型请求（两次本地行动决策+最多一次真实答案）、原网络限额2或冲突3。调用期限30秒、API超时20秒，其他原计划限制不变。单次预留1元，本轮最多8元管理额度；用户授权开发验证累计模型费用低于500元，此前v2预留8元保留，不把预留称为账单。不把页面模型费用混入搜索调用次数。

生成全部结束后，由独立Spec审查Agent按冻结期望逐例评审正式答案和引用，不由被测火山模型自评；评审者参与过实现审查且已看过v2，非外部盲审。正式答案缺失直接失败，适用必要事实覆盖0/2，不适用0/0标N/A；引用无分母标N/A。保留实际失败、未知用量与输入输出，不以新任务覆盖。不得仅用结构校验替代语义支持。

执行前代码审查：Spec和Standards均无可操作发现；真实HTTP Unicode引用展开和伪造索引拒绝通过，Ark及Brain race、全仓build及相关vet通过。未声称覆盖多字节字符恰跨512字节切分点的测试。全仓旧版本验证仍在独立工作树运行。
