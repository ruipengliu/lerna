## 单来源获取上下文装配

fetchcontext.Assemble 对单一页面或单一失败来源完成受控读取后，仅作本地投影、JSON 编码和大小检查，省去末尾同一来源的重复 Validate。多来源装配保留完整末尾复查；独立 Validate、模型调用前后及发布前复查保持。

通过真实 HTTP 获取、Core 任务与 Content 视图的既有上下文测试增加计数断言，先观测两次读取而非一次，反例失败（0.338s）。输出仍核对实际正文、出处和时间，外部指令不能替代任务事实；原任务替换、超限和撤权分支保持。单页失败最低查询数随之为53、Content45、Outcome2，上限64保持。相关 race 回归正在执行；此改动不解决多来源冻结场景的预算失败。

单来源上下文、真实模型调用边界撤权/发布、证据答案发布恢复及单页账本的 race 组合通过（13.643s），vet/diff通过。Standards与Spec独立增量静态审查均无actionable findings。多来源装配未修改，之前冻结预算失败仍有效；未重复运行相同多来源组合或将此结果外推为整票完成。
