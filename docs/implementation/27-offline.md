# 27：授权同步与有限离线执行

参考配置同步的是**已分配原操作的有效授权视图**：每条记录绑定接收方、出示节点、原操作、语义、动作和一个已预留额度，包含当前策略与祖先校验结果、期限及修订。它是权威计算的受控投影，不复制权威数据库、签发私钥或任意策略管理权限；本地执行权威仍独立检查本地授权、任务资格和控制意图。

## 接入与生命周期

授权方通过 `GrantAuthority.OfflineView` 创建稳定视图，通过 `Allocate` 使用现有 `ReserveUse` 为原操作分配额度。是否允许离线由受权宿主在分配时明确指定；没有无限离线默认值。若额度预留成功而视图保存失败，原预留保留，重试不再次消费或退款。

双方 WebSocket 协商 `authorization.sync.v1`，受信 Binding 提供精确匹配接收节点的 `Authorization` 视图。现有 `Disclose` 在查询与实际发送时持续检查披露策略。`Peer.ReadAuthorization` 使用现有认证、分类队列、分块、I/O 上限及请求关联。同步响应是由安装时固定的可信密钥签名的分页内容；新增 `NewVerifier` 仅持有公开验证密钥并检查有限轮换期限。

接收方通过 `NewOfflineReplica` 绑定本地授权存储、稳定视图、接收身份、明确配置、验证密钥、时间源及必要的当前保存策略检查。`Receive` 只持久保存经过验证的页面；`Apply` 在同一 SQLite CAS 中替换完整受控投影并推进应用游标。保存策略在接收、应用和准入时检查。`Progress` 区分已接收与已应用，`Confirm` 单独报告应用边界；通知确认丢失不回滚已应用状态。

源端 `Read` 支持一致分页快照及按已完成修订接续的替换增量。每个增量是这个有限视图的完整替换，因此删除/撤销不能被局部补丁遗漏。分页绑定快照版本、接收身份、视图及接收方新挑战；并发修改通过后续版本接续。若分页时发现更晚权威版本，旧快照仍可应用，但不能建立执行时间依据，须同步最新状态。游标/页面过期至多重取一次快照；无法完成保持等待。源端进展查询重新检查当前权威，即使没有接收方轮询也会显示未送达撤销为 pending。

`Execution.Service.BindOffline` 在实际首次启动之前叠加远端授权门禁，并保留已有 StartGuard。提供 reader 时，每次启动在线重新同步；不提供 reader 时，只能使用当前进程内已经取得的有限离线授权。宿主负责在连接状态变化时安装适用绑定及调用同步；本票不引入永久后台守护进程。在线必需操作无 reader 时拒绝，远端不可达不自动扩大权限。已开始操作继续走既有原效果核对，传输和授权同步不重复调用 Driver.Start。

## 时间与恢复

在线交互使用接收方新挑战，建立本进程的有限时间依据。单调经过时间限制离线窗口，独立墙钟检查可检测偏差和休眠异常。系统墙钟样本剥离 Go 的单调分量，避免墙钟相减悄悄退回单调时间。授权链、策略及登记期限也限制每项操作，不能仅因长连接或读取旧页面延长。

实际墙钟来源和操作系统受信；不能证明时间有效时停止新动作。进程重启领取新接收会话并隔离旧持有者，持久副本可以恢复应用，但不恢复时间依据。复制旧数据库也不会得到本进程在线挑战和时间依据。完整宿主被控制或整套环境恶意回滚不在信任保证内。

本地权威继续沿原本机策略、时间与执行恢复路径工作，不需要配置远端门禁或联系外部云。使用远端授权的宿主必须在暴露恢复的执行服务前恢复 `BindOffline`；不能把遗漏受信宿主配置当作授权。

## 有限配置与证据

参考值：视图 16 项，页面 1 项，整个离线分区 64 KiB，离线窗口 1 分钟，时钟不确定性 1 秒，同步 I/O 5 秒，修订保留 1 分钟。构造时允许范围为 1–128 项、1–16 项/页、4 KiB–1 MiB，离线窗口 1 秒–1 小时，I/O 1 毫秒–5 秒；保留期不短于 I/O 且不超过 1 小时。源视图与接收视图各最多 16 个，分区总字节限制仍适用。每条分配固定一个额度，未知交付/消费不回收。达到存储上限明确拒绝，历史仅在有限保留范围内接续。

专项验证包含 SQLite 接收/应用故障、重复页面、分页与游标恢复、原操作额度、撤销与期限、墙钟样本、克隆副本隔离、真实 mTLS WebSocket、独立进程重启以及独立 SQLite counter 的实际效果。模拟时钟用于制造期限及偏差；没有修改宿主系统时钟或宣称完成真实设备休眠实验。实际系统时钟检查证明墙钟样本不含单调分量；异常路径另用可控时间源验证。

执行入口为 `scripts/verify-offline.sh`，原始环境、依赖、生成一致性、构建、静态检查、专项及受影响竞态回归保存在 `build/offline`。冻结版本全部阶段通过，报告和原始证据索引见 [验证报告](evidence/27-offline-report.json)，问题与修复见 [审查记录](27-offline-review.md)。未运行组合不表示通过。范围不包括任意策略镜像、所有变更方法、所有权迁移、完整 UI 或记忆同步、外部 exactly-once 与全系统质量验收。
