# 验证、依赖与待决项

[总览](README.md) · [身份与接口](contracts.md) · [判定、消费与恢复](mechanisms.md)

本页将设计审查与运行证据分开。当前交付是模块契约与验证设计；没有授权服务、接入适配器或驱动参考实现，不能报告 L2–L4 或 V1／V2 已通过。

<a id="dependencies"></a>
## 1. 依赖与能力缺席时的行为

| 提供方 | 所需输入、输出及保证 | 缺席时本模块的行为 |
| --- | --- | --- |
| 受信应用入口／认证适配器 | 可验证用户、端点／实例身份；固定范围的真实用户确认；受控管理接口 | 不签发根许可，不开放远程自助登记；已有有效范围内的工作仍按自身条件判断 |
| 启动组装器／本地监督器／运行存储 | 端点持续账本、独占运行资格、旧实例隔离证明 | 禁止实例接替；重装新身份不得重做旧操作 |
| 资源处理端／目录 | 真实资源规范化、动作／用途语义、有限使用单元、约束执行与本地门禁 | 不授予无法解释或落实的范围；不将声明字符串当作执行保证 |
| 执行协调器／驱动 | 原操作去重、持久启动准备、状态与效果查询、可声明的中断能力 | 不因许可消费推断操作结果；无原操作核对能力时保留未知、不自动重做 |
| 任务核心／上下文组装器 | 固定操作与来源集合、控制／预算条件、准入及派发复核、授权 blocker | 本模块只返回权限结论；不能代替核心启动任务或裁决 completed |
| 消息交付／端点授权适配器 | 本轮快照与连续变化接续、持久应用证明、按行为门禁 | 跨端初始开放和恢复等待；core.resumed 不能补齐缺口 |
| 时间与离线账本适配器 | 有界时间误差、计时语义、防回滚及唯一消费依据 | 不开放离线许可；普通在线短期使用也必须能保守判断启动截止 |
| 数据／记忆服务与受控出口 | 用途、驻留、删除、最小记录保留及出口隔离 | 拒绝不满足数据策略的使用／可靠执行模式；不报告删除完成或无泄露保证 |

这些身份接口定义邻接模块的接入合同；具体适配器接入及其运行保证仍待验证，不能由接口已有设计推断实现已就绪。

## 2. 运行验收矩阵

每例固定实现版本、接入／存储／驱动配置、用户及端点、许可和原操作标识。测试观察授权回执、处理端实际启动日志、持久效果事实和对外答复，不能只检查一个 allow／deny 返回。以下均为待实现用例。

| 编号 | 前置条件与刺激／故障 | 预期可观察结果 | 保证／目标 |
| --- | --- | --- | --- |
| IA-01 | U1、U2 有相同本地对象名；U1 请求携带 U2 的 grant_ref／endpoint_id | 无跨用户读取或启动，无对象存在性泄露；缓存、回执查询也拒绝 | I1、I7／C7、A4 |
| IA-02 | 同用户 Agent A、B；B 复制 A 的许可引用并自报 actor | 受信宿主绑定不符，拒绝；日志归因真实调用方 | I1／C6、C7 |
| IA-03 | 两连接并发消费同票据；首次 welcome 丢失后重连 | 只有一次消费成功；新连接须新票据，原业务 ID 和持续账本不重置 | I1／C5、C6 |
| IA-04 | G1 写 A，G2 读 A；重复批准同一确认、丢签发响应，随后执行正常写入及读回 | 原确认只签发一份许可；G1 在 Evaluate 后仍未消费，准入后分配 O1，BeginUse 才绑定；O2 使用 G2，效果由执行端证明 | I2、I3／C4、C7 |
| IA-05 | 批准写 A 后将路径改 B、改内容、换接收方；或用符号链接替换目标 | 确认摘要／意图／实际资源检查失败，B 不发生获准范围外写入 | I2／C4、C7 |
| IA-06 | 父许可只允许本地读取；子请求新增同步、延长期限或降低限制 | 委派拒绝；合法收缩通过；撤销祖先后叶子新使用拒绝 | I2、I4／C5、C7 |
| IA-07 | 一次许可被两个操作竞争；同操作重投 100 次或更换来源 slot；持续读取进入下一块 | once 唯一占用且所有 slot 共用原截止；continuous 只为真实下一单元建新回执；不同参数冲突 | I3／C4、C7 |
| IA-08 | BeginUse 提交后断响应，查询暂时未见，旧事务稍后提交 | Unknown 期间不启动、不换键；ReadUse 只返回历史，重投 BeginUse 才查当前资格；过启动截止不刷新 | I3／C5 |
| IA-09 | G1 已消费，处理端在保存启动前或驱动返回前分别崩溃 | 前者仅在可证明未启动且仍获准时继续原操作；后者按原操作核对，绝不凭授权记录推断效果 | I3／C4、C5 |
| IA-10 | Revoke 与 BeginUse 并发；分别注入通知延迟和回执返回后已知断网 | 提交顺序可解释；撤销后的新消费拒绝；在线剩余启动窗口不允许已知断网后首次启动；不报告即时远端停止 | I4／C7 |
| IA-11 | O1 可能已写入、响应丢失；撤销行动权限但保留最小核对权 | G1 不退回；原操作可查最小状态，读文件和上传仍分别检查；未知效果不重做 | I3、I4／C4、C5 |
| IA-12 | 同上，进一步撤销读回与披露；迟到事实携带敏感正文 | 保留获准的最小控制事实及缺口，拒绝无权正文；历史回执不泄露今天无权查看的数据 | I2、I7／C2、C7 |
| IA-13 | 设备有有效离线许可；墙钟回拨、休眠、重启、恢复整机快照或旧账本分别注入 | 只有有效时间锚和唯一账本时继续；无受信防回滚依据则关闭所有离线模式，既有效果保持真实 | I5／C5、C7 |
| IA-14 | 离线时云端撤销；端点到期前／后继续调用；后重连 | 有限范围内的延迟如实报告；到期阻止新使用；重连先取本轮依据，禁止自动上传受限结果 | I4、I5／C5、C7 |
| IA-15 | 快照分页中并发撤权，过滤流无相关变化、丢页、日志截断、旧轮回执迟到 | 变更落入快照或连续覆盖区间；缺口阻止相关行为；旧轮或旧 owner 证明不能解锁 | I6／C5、C6 |
| IA-16 | 旧实例离线仍有效，新实例请求接替；或仅换 WSS 会话 | 无隔离证据不激活；本地受控接替后旧入口不能写新消息／启动；原在途效果继续核对 | I1、I5／C5 |
| IA-17 | GUI 自动动作排队，用户本地接管并使云端不可达 | 本地屏障先阻止新动作，尽力停止在途；重连不自动开放；V2 验证实际界面变化 | I4／C4、C7、V2 |
| IA-18 | 来源只许上下文使用，模型建议保存记忆或把日志交给评测 | 再用途检查拒绝；不因来源已读或模型引用删项而放行 | I2、I7／C2、C8、C9、V1 |
| IA-19 | 新许可请求耗尽用户队列／存储；另一个用户查询并发撤销 | 新接纳受限，控制与核对仍有保留容量；其他用户不被无限饿死，无已接纳回执静默删除 | I7／C5、C7、C8 |
| IA-20 | 删除正文后重投原命令；旧备份恢复身份库或丢失消费记录 | 不重建新许可／新消费；恢复依据不足时受限，旧权威先隔离；报告历史缺口 | I3、I7／C2、C5 |

先完成同进程 IA-01～12、18～20，再验证具体端点适配器及 IA-13～17。用 PostgreSQL／SQLite 分别运行事务、崩溃和旧备份用例；离线、外部登录和设备接替按平台分别声明支持。V1 仍需证明真实取证和引用质量，V2 仍需观察设备效果，权限矩阵通过不能替代专项效果验收。

观测指标包括判定耗时及 indeterminate 原因、单用户锁等待、票据重复消费、授权提交未知、单次绑定冲突、撤销提交到端点应用的延迟、过期窗口内启动、恢复缺口和拒绝的越权使用。按用户汇总资源消耗、排队和存储占用，采样与导出也须满足用途限制。负载报告提供分布与故障条件，不用平均延迟遮盖撤销尾延迟。

## 3. 已采用的跨端授权合同与验收

身份 P1 已采用，权威定义在[跨端授权、恢复与确认](cross-endpoint.md)。WSS 领域消息复用现有交付、源身份与网关路径；专属 HTTPS 不作为另一套授权同步路径，认证接入只提供受限引导。授权恢复、执行目录、完整来源与用户确认分别保留自己的裁决。对应 Schema 为 [identity](../endpoint-communication/schemas/identity.schema.json) 与 [domain-common](../endpoint-communication/schemas/domain-common.schema.json)。

| 追加验收 | 刺激与应观察结果 |
| --- | --- |
| IA-21 首次恢复 | 普通业务许可尚未同步；受限 bootstrap grant 只能恢复本端点固定集合；替换主体／owner、使用工具或读取正文均拒绝 |
| IA-22 确认绑定 | 普通表单伪装授权批准、替换范围摘要／surface／input／nonce、批准响应丢失；只有真实受信本人证明可以消费原确认，重复返回原结果 |
| IA-23 跨端连续性 | 快照分页期间撤销、空变化页、旧轮应用回执；完整性与覆盖区间成立前行动关闭，旧 owner 不能解除门禁 |
| IA-24 离线编码 | 替换 typ／alg／kid／aud、伪造父链、更换账本或时间锚、许可期限长于源证明；全部拒绝，不能回退到宽松算法 |
| IA-25 离线撤回 | 权威撤销时设备离线；展示各端应用状态与原最晚使用截止；截止不证明既有调用终止或副本物理清除 |
| IA-26 受限本人管理 | 管理 bootstrap 引导、近期认证与服务 actor 分开；后台 Agent 不能继承本人确认，权威失联不生成新许可 |

以上是应执行的运行验收，不表示已有实现通过；默认离线上限仍为 0，部署必须固定并验收正值、可信时间和防回滚保证。
