# 扩展清单、运行器与激活恢复

状态：扩展清单、管理与运行接口、激活恢复、运行器及 SDK/格式基线已确认；尚未实现或完成运行验证。基础方向见 [扩展生态](09-extension-ecosystem.md)，决策过程见 [确定插件、Skill 与外部 Agent 的接入生命周期](../../.scratch/harness-technical-design/issues/12-extension-lifecycle.md)。本文的字段和方法为设计接口，不表示已有实现。

## 清单与锁定结果

参考清单采用 `harness-extension.json`，由已登记版本的 JSON Schema 校验。Skill 可以直接导入目录，由导入器生成伴随管理记录，无须修改原 SKILL.md。外部 Agent 登记使用同样的身份、兼容和授权元数据，但端点与协议描述属于接入记录，不伪装成可在本地安装的代码资产。

| 字段组 | 需要表达的内容 |
| --- | --- |
| 身份与来源 | 命名空间、扩展名、对象类型、版本、来源定位及不可变内容摘要；发布者与被信任身份的映射由管理配置确定。 |
| 提供内容 | 能力、Skill、Agent 模板、模型/存储等 Interface 实现、Schema、Renderer 及 UI 类型；各自引用和版本独立于包版本。 |
| 运行入口 | 编译组装键、独立进程入口、受限运行器资产或远程端点；运行平台、语言及必需特性。 |
| 依赖 | 必需/可选依赖、兼容版本范围、所需接口与 Schema 版本；部署位置及适用运行器要求。 |
| 权限与数据 | 申请的资源/动作/用途、允许处理位置、可能读取或生成的数据、凭证引用需求及必需隔离限制。清单不携带授权签发权或原始凭证。 |
| 配置与恢复 | 配置 Schema、默认非秘密配置、持久状态/检查点版本、可支持的迁移入口及兼容范围。 |
| 质量依据 | 对应契约测试、支持能力、运行范围及验证资产引用；声明本身不构成测试通过证据。 |

能力名称采用命名空间内的稳定引用，别名仅供发现。同名同版本不同内容拒绝覆盖；多个实现提供同一能力时显式配置选择关系，不能按安装顺序抢占。清单中的权限请求只能经授权模块判断，不能当作实际授权。

依赖解析在准备阶段进行，输出精确锁定结果：资产摘要、选定版本、接口/Schema 版本、运行器配置及非秘密配置修订。激活和运行只使用该结果，不根据远程仓库最新状态临时换包。可选依赖未满足时撤去相应可选贡献；必需依赖缺失、循环或冲突则拒绝激活。

初版不允许同一组装范围内隐式选择多个不兼容的同名版本。确需并行旧版本以完成在途工作时使用已固定的版本引用和独立运行上下文，不能让依赖解析覆盖旧工作。编译集成的 Go 实现必须已经包含在受信宿主构建中，导入清单不产生运行期重新编译宿主的效果。

导入器只在隔离的暂存位置读取并校验有界资产，拒绝目录越界、越界链接、超限解包或缺失摘要，不执行安装钩子。来源获取与验证分别记录；联网下载本身沿数据、网络和来源策略执行。本地目录每次导入形成不可变快照，后续工作不能继续引用会被编辑的原文件。

## 管理与运行接口

| Interface | 方法 | 责任与恢复约束 |
| --- | --- | --- |
| ExtensionManager | Prepare / Validate / Activate / Disable / Remove / Get / LookupOperation | 准备锁定资产、静态及行为验证、激活绑定、停止新工作或隔离、清理可删除资产、查询状态与原操作。变更使用稳定操作身份及预期管理版本，不能由普通工具参数触发管理权限。 |
| ExtensionRuntime | Prepare / Start / Inspect / Stop | 校验运行能力、启动获准实例、查询真实状态和请求停止；停止返回与已停止分别报告，具体业务恢复仍沿任务及执行接口。 |
| ExtensionStore | Load / Commit / LookupCommit / ListRecoverable | 保存资产与锁定引用、验证记录、激活意图、当前绑定、节点应用进展、操作回执及恢复工作/Outbox；原子边界属于本地管理范围。 |

管理 RPC 归入既有任务协作领域的 ExtensionService，各方法映射上述管理意图；能力调用、记忆访问和端云连接继续使用各自契约。不增加扩展专用的第五类协议，不向普通扩展开放存储接口。查询状态按授权过滤来源、位置及资产信息。

Prepare 的导入、依赖获取和生成锁定可在事务外分阶段进行，只有全部必需资产就绪后才提交可验证记录；崩溃后的未引用暂存资产可以清理。Validate 记录针对精确资产、配置、运行器和测试集的结果，不能把另一版本的通过记录复用到当前版本。

清单/Schema/依赖检查可以不启动代码。需要行为验证时在获准测试环境中启动，使用受控测试能力与数据；不能让包通过“自检”访问真实账号或任意外部资源。运行器能力不足时记录不支持，不静默降低限制。

## 激活的一致性边界

每个节点的管理范围有持久化激活修订。Activate 绑定精确锁定结果、准备好的实现、声明贡献及预期管理版本；执行前复验当前信任、权限、位置和运行器能力。验证已通过但权限随后收紧时不得激活。

先完成资产与 Schema 准备、运行器就绪及依赖检查，再原子提交该范围的新激活修订、贡献绑定与通知。目录、Skill 发现、UI 类型和模块组装读取同一激活修订或使用带该修订的投影；投影尚未应用时拒绝使用新绑定，不暴露半套声明。更新目录或发出通知的成功不等于业务已经在新版本执行。

进程启动在数据库事务外，实例在激活前不能接纳正式工作；启动完成但激活提交失败时隔离或停止该候选实例。激活提交结果不明时查询原提交，不能重新发起另一项激活。投影通过幂等交接恢复，原有任务、运行存储和外部效果不纳入激活事务。

跨节点激活是逐节点准备与应用，不承诺一次全局原子升级。分别报告每个目标节点已准备、已激活、失败或待联系；不兼容的节点在协作准入时显式等待或拒绝。离线节点只有在原版本仍获准且满足离线条件时继续工作，不能因管理端指针改变就被当作已升级。

每次已经固定版本的决策和能力调用使用原绑定；下一段尚未固定的工作可以按已激活且兼容的配置选择版本。不在一次决策或已准入动作中间改绑。旧工作所需的实现、Schema、Skill 和恢复数据保留到不再需要或明确处置，持久引用不能只靠进程内计数管理。

## 停用、隔离、回滚与删除

Disable 区分正常停止新工作与风险隔离。正常停用不接纳新的非恢复工作，跟踪旧实例排空；风险隔离阻止新的受限执行并请求停止，仍保留事实与可用的核对通道。无法停止的外部调用不提前记为结束，不能卸载后再以新操作重试。

回滚通过 Activate 选择已知旧锁定结果，也须重新核对当前信任、权限、依赖与数据状态；以前可用的代码不自动获得本次激活资格。若持久状态已迁移而旧实现不兼容，回滚进入待处理状态，不能回放旧数据库覆盖新事实。迁移本身需要声明范围、版本前提、失败恢复及适用授权。

Remove 先确认已停用以及无在途、恢复或允许保留的依赖引用，再清理代码/内容资产；业务记忆、操作记录、授权消费及撤销水位按各自生命周期保留，不因卸载插件一起删除。用户要求删除受限内容时应使相关上下文或工作失效并处置引用，不能借恢复需要无限保留被禁止保存的数据。

外部 Agent 的停用表示不再向其分派新工作；它的独立运行时不能由本地卸载状态推断已停止。端点身份、协议或声明变化影响新准入，旧任务沿原远端关联查询与核对。无法证明远端实现版本固定时明确记录保证范围，不把 Agent Card 快照当作远端二进制版本证明。

## Skill 与 SDK 最小契约

Skill 导入保留名称、用途、正文、引用资源和脚本资产的内容快照；Harness 的版本、依赖和授权需求放在伴随记录。未知的可选元数据保留但不获得执行含义，必需语义无法支持时拒绝激活。多个来源的同名 Skill 显式消歧；正文读取受预算、位置和来源权限限制。

Skill 可以组合调用已登记能力或引用其他已锁定知识；动态执行仍由有限决策与任务运行机制控制。内容冲突不能通过拼接自动解决，明确作用域和优先关系，任务目标与强制授权限制保持有效。`allowed-tools` 等内容建议不作为实际授予权限，脚本存在不意味着系统默认支持其语言或依赖。

原生 SDK 以可导入的 Go 领域接口、生成的 Protobuf 消息、具名客户端/服务端绑定、Manifest/Schema 校验器和语言无关测试夹具为最小交付。SDK 隐藏线协议细节，但公开取消、未知结果、去重、权限与版本失败语义；不能用 SDK 自动重试掩盖副作用风险。

外部 MCP/A2A SDK 只位于对应 Adapter 内，标准目标、Schema 快照、SDK 版本与 Harness 兼容范围分别锁定。SDK 尚未覆盖目标时明确补齐映射并验证，或者报告该组合未支持，不改变既定目标或伪报已兼容。具体基线及需补齐的适配见下表，完整源码证据见 [SDK 与格式快照研究](../research/harness-extension-sdk-and-skill-snapshots.md)。

MCP Adapter 的 HTTP 服务端显式设置 `Stateless = true`。参考配置开启请求 context 的取消传播，用来收束连接等待和临时处理；已持久接纳的业务操作使用自己的执行生命周期，断开请求不直接写为业务取消或失败。真正的取消请求仍经适用契约发起，并核对实际停止情况。

MCP 严格模式仅接受既定目标版本：入站在业务分发前验证版本与方法，出站在业务调用前验证协商结果，并通过专用适配或定向补丁关闭发现失败后的旧握手回退。仅检查最终协商版本不够。v1.7.0 未提供全部所需公开配置，因此此项属于必须实现并测试的差异，不能仅锁定依赖就报告完成。独立 Tasks 扩展首期不启用，未来启用需另锁扩展规范/实现和验收记录。

A2A 客户端禁用默认传输集合，只注册 HTTP+JSON；检查远端声明的绑定与协议版本。普通 JSON 消息支持规范推荐的 `application/a2a+json`，同时按兼容规则处理 `application/json`；专用适配须在 SDK 错误解析前识别媒体类型并保留结构化错误及原始元信息。SSE 仍为 `text/event-stream`，不得统一改写。规范补丁号、线上协议版本与 Go 模块主版本分别记录。流式/推送仍按已有可选能力规则启用，不从 SDK 方法存在推导验收已通过。

Skill 校验按固定快照执行。参考生成器及默认激活命名采用 ASCII 小写字母、数字和单连字符子集，目录同名，名称 1–64 字符，描述 1–1024 字符；正文和描述可使用中文等 Unicode 内容。对超出参考名称范围的导入给出明确兼容诊断，不静默改名，不宣称上游规范禁止 Unicode。需要更宽名称范围时通过显式校验配置和一致性夹具扩展。其他元数据、目录和资源按格式快照处理，未知可选字段无新增执行语义；无需引入 Python 工具作为运行依赖。

SDK 的局部修改保持在 Adapter 或明确记录的补丁依赖中，锁定上游版本、补丁摘要、规范源摘要和对应测试结果。实际引入时保存 go.mod/go.sum 与完整传递依赖；后续稳定版通过同一矩阵后可替换，不能在运行中自动改用最新版本或预发布版本。依赖版本未被实现、配置或测试前，支持状态仍为未验证。

### 受限执行的具体边界

依据已核实的运行器证据，采用可嵌入 Go 的 wazero WebAssembly 运行器处理显式支持的受限模块。参考范围限定为按约定编译的模块及声明的宿主接口，不承诺导入任意 Python、Shell 或其他原生脚本后即可隔离运行。普通 Skill 的内容导入与其附带脚本可执行性分别报告。

默认不挂载宿主目录、不继承环境变量、不开放宿主网络或子进程。需要数据时由受控宿主入口提供有界内容或获准能力调用；文件读取、网络和凭证访问通过对应处理模块检查，不将只读挂载当作路径隔离保证。内存页、模块体积、并发准备/实例数、执行时间、输入输出及宿主回调均设有限上限；额度随运行配置锁定，在行为测试前确定。Wasm 及任务评测的首版有限额度已在 [评测基准与发布判定](10-evaluation-contracts-and-release-gates.md) 固定；研究报告中的其他示例不是默认配置，实际限额能力仍须验证。

显式启用 `WithCloseOnContextDone(true)`，实例化与调用均传递有期限的 context；模块 start 段也可能执行代码，清空导出启动函数配置不能跳过它。加载/解码与编译阶段另约束资产大小和并发，不能依赖调用超时为其提供硬资源上限。每次调用使用新 guest 实例，缓存仅保存获准编译产物，取消后的实例不复用。

宿主回调必须限制参数、内存分配和输出，并向下游传递期限；可能永久阻塞的回调不进入参考范围。guest 内存页限制不等于宿主进程 RSS 限制，guest 取消也不能强杀任意 Go 回调。需要进程级硬资源限制或更强故障隔离时选用已验证的独立后端，不把这些保证附加给内嵌引擎。

默认不依赖 guest 的模拟时间或确定性随机源作授权、到期或密钥判断；这些判断由宿主负责。确需真实时间或随机数时使用明确登记的受控入口。参考 Wasm ABI 只暴露清单声明且运行器实际支持的接口子集；不承诺所有存储、传输或界面接口都能用同一 ABI 实现。

宿主入口按扩展所实现的 Interface 裁剪。执行类脚本可以在授权内提出受控子调用，Brain 等仅允许提出决策的实现不得借宿主入口直接执行行动。每项真实子动作由内核/执行模块登记操作及预算，再交付执行；模块返回文本不等于子动作的效果已确认。

默认不保存 WebAssembly 执行栈以实现透明续跑。进程或模块中断后核对已登记子动作，不盲目重启脚本产生重复效果；纯计算可以在声明允许且预算足够时重新执行，有副作用的调用按原操作及子调用事实处置。停用运行器不清除这些事实。

依赖原生环境的脚本只在已声明支持该环境的运行器中执行。受信模式与受限模式分别启用，后者不可用时不能隐式切换为受信宿主执行；具有更强操作系统隔离能力的运行器作为独立 Adapter 验证。浏览器 Renderer 同样按宿主声明的信任范围接入，默认只加载已获准的受信实现。

## 验证范围

扩展一致性验收包括摘要冲突、依赖缺失或循环、资产越界、无授权自检、版本不匹配、激活前后崩溃、目录投影延迟、端云部分激活、并行旧版本工作、隔离后迟到结果、迁移失败、删除引用与回滚兼容，以及外部 SDK 的具体协议行为。运行器需另验实际资源与宿主访问限制，Skill 需证明加载与脚本执行分离。补充外部互操作用例包括旧版本发现回退、HTTP 请求断连与已接纳操作、A2A 两种 JSON 媒体类型及结构化错误、SSE 类型保持，以及 Skill 格式/名称兼容诊断。运行器覆盖 start 段、无限循环、超大输入、hostcall 阻塞和目录访问等有界失败。当前仅有文档设计和官方源码核对，没有实现或运行证据。
