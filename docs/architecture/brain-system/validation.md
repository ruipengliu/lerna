# 验证、依赖与交付状态

[总览](README.md) · [决策机制](decision-policy.md) · [接口与模型运行](contracts-and-runtime.md)

本页区分设计保证与运行证据。当前仓库尚无大脑参考实现；以下测试规定未来如何验收，不将文档审查或 Mermaid 渲染计为模型、恢复或任务效果通过。

## 1. 依赖入口与缺席行为

| 提供方 | 必须提供的输入／输出与保证 | 未提供时本模块行为 |
| --- | --- | --- |
| 任务核心／运行存储 | 固定 work／attempt／原领取、call_prepared、预算、可信事实、整体准入、关闭及迟到账务 | 不发起模型调用，不自建调度补偿。接口已设计，实现仍待验证 |
| 上下文组装器／内容服务 | 来源完整的固定快照、精确声明；按[内容与来源合同](../content-and-provenance.md#bindings)取得获准字节、耐久引用、所需保留依据及绑定用途／接收方的当前证明 | 必需资料缺失则不生成相应提案；可选记忆缺失可继续并披露限制。内容引用未保存或所需保留不能成立时不充当可恢复事实 |
| 授权与宿主 | Evaluate／BeginUse／ReadUse、真实模型接收方与资源规范化、当前控制资格、受信用户确认、唯一受控发送入口 | 无当前使用资格不发送；确认或消费未知查原键；不能证明旧实例隔离时不接替发送 |
| 模型适配器与供应方 | 固定 profile、结构输出、原调用事实、可信用量及准确声明的查询／终止能力 | 不支持项标 none；未知费用和物理占位保留，硬预算保证缺失拒绝对应任务 |
| 能力与执行 | 精确版本、参数、效果和核对语义，实际内容获取，API／GUI 前提及事实 | 候选不足不编造声明；原操作未知不回退或重做 |
| 应用任务策略／效果判定器 | 支持目标类型、验收条件绑定、固定验证器与成果版本；开放语义评估的普通能力接口 | draft 时不准入目标行动；验证器缺失不建议成功，临时不可用等待，范围不支持则澄清／失败 |
| 记忆系统／扩展管理器 | 获准记忆、Skill／策略包固定版本与来源、停用与隔离能力 | 无记忆时只作当前任务决策；无隔离只启用受信内置策略，不动态加载未知插件 |
| 协作任务端点 | 受信 Agent 声明、父子结果关联、收缩许可、预算份额、可靠接纳／结果／取消 | 合同不完整就不提供 delegate 候选；不包装为不透明工具 |
| 端云与恢复 | 当前任务／授权／执行依据，获准数据交接和调用回执回送 | 首期同进程大脑；缺跨端依据的行动及远程大脑保持关闭。离线只在全部本地能力和许可已验证时开放 |

这里列的是启用条件，不声称邻接模块已经实现。模型动作规范化器与受控出口属于本模块适配器；其使用身份、用途与消费规则沿身份契约。任务策略、语义评估器、记忆和协作端点需要各自提供方交付，不能因为大脑文档描述了调用就算闭环可运行。

## 2. 观测与问题定位

每轮保留可获准读取的 work／attempt、输入与配置版本、能力候选精确键、选定行动及简短依据、证据缺口、结构校验结果、模型停止原因、准入／拒绝关联、已知用量和未知占用。操作、答案和验证结果通过引用关联，避免复制敏感正文。

观测只消费提交后事实；日志丢失不能丢掉核对和账务责任。诊断应能区分“未生成”“生成无效”“提案过期”“准入拒绝”“业务已接纳”“效果未知”与“任务完成”。耗时分别测排队、上下文组装、授权、生成、准入及等待外部结果，不能只报模型响应速度。

用户通过现有任务状态、输入请求和固定结果了解进度；权限恢复通过身份管理入口，操作核对通过执行管理入口。模型账单／停止依据缺失由受信宿主调用 ReadCall／RequestStop 处理并回送核心，不开放用户手填费用或模型声称“已停止”来释放占位。核对预算耗尽时停止主动消耗，保留一次通知和原关联；当前接口不支持强制成功、追加额度或重开终态任务。

### V1／V2 与质量计分

沿用[执行方案的计分口径](../capability-and-execution/validation.md#tests)：1000 个 API 是不同业务 API 操作的覆盖数，90% 首次调用正确率包括能力、参数、对象、权限和实际结果，95% 有限重试任务成功率以全部必需条件满足为准。结构正确率另报，不能替代首次调用质量。失败、未知、超时和预算耗尽不从冻结分母剔除；越权／坏参数集另测正确拒绝率。

V1 测答案正确性、引用支撑、获取时间与时效约束、证据缺失和冲突行为，并设置有／无获准记忆的配对样本。V2 用多个有状态模拟设备逐一验证点击、滑动、输入、返回、中断及接管，读取模拟器真实状态和前后观察；模拟通过不代表真实手机已支持。整个问答到保存的组合场景不能替代 V1／V2 独立报告。

效果评测固定目标集、供应方／模型 profile、采样参数、结构修复和业务重试上限、全任务时间／费用上限。参考业务重试可复用执行方案“首次加最多两次新尝试”的待验证 profile；模型结构修复单独计数，未知副作用不能为通过率重做。报告分层样本量、置信区间、p50／p95 耗时、已知费用及未知预留，比较策略版本时使用同一冻结集。

优化策略、提示词、Skill 或 Agent 配置只生成带来源、版本和评测证据的候选；启用和回滚交改进管理器。插件或内核代码按 C9 产生可审查补丁并经维护者发布，大脑不能自行降低验证阈值。目标等级逐项以项目 L1–L4 记录，当前仅交付契约和验收设计材料，不宣称 L2／L3／L4。

## 4. 跨模块待决范围

同进程大脑沿当前内部合同接入，以下远程能力仍为未采用的条件方案。跨模块依赖和统一状态见[待决索引](../open-decisions.md)；本地调用回执不能作为远程协议已支持的依据。

| 待决项 | 问题、推荐与具体联动范围 | 取舍与验证 |
| --- | --- | --- |
| BS-P1：独立远程大脑 | 现有内部 Brain.Decide 没有远程调用资格、可靠用量回送和重投语义。推荐首期保持同进程，确需独立服务时定义带原 work／attempt／领取／输入绑定的版本化领域 profile，固定接纳／只查原调用／取消与回送。届时联动 task-kernel/storage-and-interfaces.md、decision-and-work.md、endpoint-cloud-protocol/extensions.md 及 Schema／manifest／示例、本模块 | 单纯同步 RPC 较少协议工作，但断连无法证明未生成；必须通过 BS-07～16、24，证明丢确认不产生第二次生成。需确定是否支持独立远程部署及其合同，当前不阻塞同进程实现 |
| 沿用身份 P1、执行 CE-P1／P2 | 跨端授权／来源与准确目录、事实修订／用量／取消答复恢复仍按[身份提案](../identity-and-authorization/validation.md#proposals)和[执行提案](../capability-and-execution/validation.md#proposals)办理；本模块消费采用后的契约，不复制另一套字段 | 可先本地验证；跨实现互操作依赖这些联动，不以本地回执证明远端支持 |
| 跨端 Agent 委派 | task.submit@1 未承载完整委派合同；父子、授权收缩、预算、结果和取消的跨端编码沿[协作 CO-P1](../coordination-and-cloud/validation.md#proposals)，内核仍按[依赖边界](../task-kernel/recovery-and-validation.md#gaps)放行 | 本地已具完整协作适配器可以先验；缺失时禁用 delegate，不用普通工具绕过 |

模型 profile 的具体型号和容量数值在参考实现阶段依据数据策略、硬件与冻结评测选择；不能在缺这些输入时承诺某个模型达到 90%／95%。
