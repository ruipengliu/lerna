# 端云记忆驻留与联合检索

状态：已确认。定义端侧隐私数据的驻留、联合检索、端侧挖掘和结果披露规则，作为参考实现及一致性验收依据。

前置规范：[上下文、记忆与同步](05-memory-and-context.md)、[数据契约与生命周期](05-memory-data-and-lifecycle.md)。决策记录：[确定上下文、记忆与同步的数据模型](../../.scratch/harness-technical-design/issues/08-memory-context.md)。

## 分别定义存储、计算、发现和结果披露

“端”与“云”是部署位置，不能单独作为信任结论。策略绑定受认证节点或节点组及用途；用户指定的一台设备、个人设备组、自托管服务器和外部模型服务可属于不同范围。

| 策略维度 | 必须表达的内容 | 与其他维度的区别 |
| --- | --- | --- |
| 存储位置 | 原文、元数据、索引、派生内容、备份分别允许保存在哪些节点 | 禁止云端落盘不等于允许先发给云模型；传输缓存也属于受控副本。 |
| 计算位置 | 检索、向量化、重排、提取、摘要与推理允许在哪些节点/处理服务运行 | 原文仍在端侧，但调用远程 Embedding 或模型处理，也产生了数据外发。 |
| 可发现范围 | 其他节点能否知道集合存在、记录存在、命中数量及记录定位信息 | 允许路由一个查询不自动允许返回“某隐私记录存在”。 |
| 返回范围 | 可返回引用、投影字段、片段、计算结果、摘要或全文，以及接收方/用途 | 布尔值、统计和摘要也可能承载隐私；不以输出短小视为可披露。 |
| 留存与再使用 | 结果能否被接收方临时使用、缓存、跨任务保存或再次同步 | 一次查询返回不授予长期保存和转发权限。 |

集合策略给出默认范围，记录/字段与来源限制进一步收缩。多个来源共同产生的内容默认满足全部来源的限制；策略冲突时暂停受影响的步骤并报告冲突。容量不足、设备离线或模型效果不足都不能成为自动上云的理由。

## 已确认：参考数据存储策略

以下为参考部署的默认策略配置，业务可通过已授权策略调整；并非按某个具体业务场景写死。未分类或策略不明的数据先保留在取得它的受控端侧，不自动上传；如果该位置本身未获准保存，则不保存，而非强制落端。

| 数据类别 | 默认端侧保存与计算 | 默认云侧保存与计算 | 检索及回传 |
| --- | --- | --- | --- |
| 禁止离端的原始资料和记忆 | 指定端或明确许可的端设备组保存，索引、提取、摘要和推理均在允许位置运行 | 无原文、内容索引、向量、内容摘要；不注册记录标题或命中目录 | 本地检索并本地使用；远端仅能调用获准的通用端侧处理能力，具体命中默认不披露。 |
| 原文留端、允许有限结果离端 | 端侧保存原文与全文索引，端侧完成检索和投影/计算 | 仅接收策略允许的引用、字段或计算结果；保存另行检查 | 联合查询返回受控结果，Get 不得绕过限制读取全文。 |
| 用户明确允许端云共享的记忆 | 可保留授权副本及本地索引 | 在指定云节点保存批准字段并建立授权范围内索引 | 按既定单一修改权威与版本规则同步；默认不附带全部原始资料。 |
| 云端取得且获准存储的公共知识、业务资料 | 可按用途缓存必要部分 | 指定云节点保存并检索 | 实际来源/使用限制继续有效；“从互联网取得”不自动说明内容无隐私或可任意留存。 |
| 端侧挖掘的偏好、事实、推断、经验 | 默认与来源同等或更严格；来源限端时，派生内容也限端 | 只有策略明确允许的投影或经过授权披露处理的派生记录可进入云 | 模型不能自行把敏感推断标为可共享；仍需来源和修订跟踪。 |
| 上下文、截图、日志、调试记录和 UI 状态 | 随其实际内容的限制存放，按任务恢复和用途控制保留 | 仅保存允许的控制元数据与内容投影 | 敏感输入不进入云端提示词、Trace、异常栈、附件或消息补投正文。 |

端侧保存不等于只能存一台设备。允许的端设备组可以同步副本，但每台设备均需获准；严格指定单设备的数据不能自动复制到用户其他设备。

### 修改权威与数据位置的相容性

- 保存完整受限记录并确认其内容修订的 Memory Authority 必须位于获准处理该内容的位置。云端任务拥有者不能因此获得端侧完整记忆。
- 端侧原始记录与允许同步的脱敏/聚合记忆若具有不同内容语义、保留规则或修改权威，应作为不同记忆记录，以来源修订关联，不能伪装成同一记录的普通副本。
- 若只是同一记录的字段投影，则仍由原集合权威负责修订；云端副本不可覆盖端侧未披露字段。变更通过受控字段意图回到原权威。
- 集合策略收紧时，先阻止不再允许的传输和新计算，撤销旧同步视图，按已确认删除传播规则处理现有副本。授权放宽不自动触发历史数据全集上传。
- 严格留端的记录不应先放进云端权威集合再等待过滤。选择集合、存储和处理位置是在写入前的策略判定。

此默认配置的代价是云侧无法获得全量语义索引；端侧资源和在线状态会影响检索范围与速度。它保留了后续按用途开放有限披露的能力。

## 已确认：查询到数据所在处执行

联合检索不要求云端建立原文、摘要或向量的全量目录。参考实现按获准节点/集合路由查询，在数据所在位置过滤、检索和生成可返回结果。节点能力目录只表达获准声明的能力，不默认登记私有记录的标题、关键词或数量。

### 查询流程

1. 入口提供查询、用途、调用主体、期望结果形式、允许接收位置、新鲜度和有界预算。查询文本本身也按数据限制处理，不能把含私密条件的查询广播到所有节点。
2. 选择符合查询传输及数据策略的节点。协调者可位于端或云；端侧可合并云端返回的公共/共享结果与本地私有结果。
3. 每个接收节点重新检查授权，按当前政策和来源修订查询。对仍禁止离端的命中，就地完成获准处理，不把检索片段送往云端重排。
4. 返回允许披露的结果，或将私有结果直接交付获准端侧 UI/本地任务。云侧只取得本次协作获准的控制状态；控制状态如“匹配成功”本身敏感，也应抑制或改为不表明命中的统一回应。
5. 协调者仅合并自己可见的结果，不将“不可联系”“未授权范围”当作零命中。不同后端的相似度分数不直接视为同一尺度；可在允许位置排序和合并。
6. 取正文、形成模型上下文、缓存结果及后续行动参数分别再次检查用途、位置和来源有效性。私有信息不能经工具参数或云端任务日志间接离端。

| 结果表达 | 含义 | 限制 |
| --- | --- | --- |
| 允许的内容投影 | 指定字段、片段或获准计算结果 | 只返回 Schema 声明和策略允许的内容；附可披露的来源、新鲜度和保留约束。 |
| 受控引用 | 接收方获准知道并定位某结果，正文尚不可见 | 引用需受作用域、用途与有效期约束，不是公开下载地址；解引用重新授权，引用本身可能敏感。 |
| 本地处理 | 端侧已受理某段工作或将结果呈现到本地 | 远端不必知道具体命中或答案；若需要自主推理则用既定受委派子任务，普通检索不强制建子任务。 |
| 可见范围内的覆盖状态 | 已查询范围、暂不可用或结果不完整 | 覆盖报告也先过滤权限，不泄露隐藏节点或集合的存在；不得声称未授权范围内没有数据。 |

来源离线时，仅使用当前获准且新鲜度满足用途的已存在投影/副本；否则返回部分结果或等待。不能临时上传原文以弥补离线，也不能把旧缓存当作当前端侧事实。

### 云端大脑无法读取端侧私有内容时

数据不得离端的任务，需要在允许位置完成相应推理：可将受限步骤委派到端侧，或由端侧协调者完成答案合成并直接呈现。云端只处理其获准接收的部分。

端侧没有满足要求的模型或处理能力时，明确返回能力不足/等待。用户可另外选择允许某种结果披露，但系统不能自行降级数据限制。此参考实现不依赖同态加密、可信执行环境或联邦学习来承诺云端可以理解完全不可见的内容；未来此类 Adapter 必须另行说明信任假设与能力。

## 已确认：端侧挖掘与来源限制继承

端侧不仅保存数据，也可提供元数据索引、文本检索、规则提取、本地模型提取、摘要及经验整理能力。核心不绑定某一个模型；本地规则/文本处理可支持单机基础验证，模型能力按 Adapter 声明并以提取质量验收。

1. 按数据源登记允许读取的范围及触发条件。持续扫描需要已授予的持续读取/提取授权；单次任务读取不自动变成后台监听。
2. 在允许的端侧处理位置读取必要内容，生成有来源及修订的候选记忆，标明事实、偏好、推断和置信依据。文件或聊天中出现的指令属于来源数据，不可改变授权策略。
3. 候选继承来源的存储、计算、用途、保留和披露限制；混合来源适用限制交集。提取内容本身也需评估，多个普通字段组合出的敏感推断可以要求更严格限制。
4. 在已授予保存权限的范围内可自动入库；超出权限仅保留获准的临时候选或提出交互请求，不能借“自进化”自动保存。
5. 可共享部分通过已登记的字段投影或受控转换产生；模型声称“已脱敏”不构成放宽权限。规则/主体有授权时可自动执行这类转换，无须每条记忆都重新询问用户。
6. 所有允许离端的输出经过结果范围校验，日志、推送、调用参数和附件遵守相同约束。规则校验只保证声明的处理和字段约束，不宣称消除了任意自然语言输出的全部隐私推断风险；无法确认符合策略则不外发。
7. 源记录纠正、删除或策略收紧时，派生记录及已披露投影参与既定失效与删除传播；备份、候选缓存、索引与评测样本都不能绕过来源生命周期。

该策略允许在既定权限内自主积累个性化记忆，代价是端侧计算消耗以及对来源和派生依赖的跟踪。任务经验不是自动安装的 Skill，生成候选不自动获得发布或代码修改权限。

## Interface 与部署落实

- **Memory.Query/Get** 增加用途、接收位置、允许结果形式与新鲜度等语义输入；调用者传入的范围只能收缩已有权限。返回内容、受控引用与覆盖状态用固定类型区分。
- **联合检索协调 Module** 调用相同 Memory Interface，负责有界扇出、失败聚合与可见结果合并。进程内与多节点 Adapter 可替换；不让每个 Brain 自己实现数据路由策略。
- **策略判定 Interface** 统一回答某内容能否在指定位置存储、处理或交付；Memory、ContextAssembler、模型/执行 Adapter 和消息出口分别落实。仅在 WebSocket 序列化时删字段不足以阻止此前上传给模型。
- **端侧提取** 作为已登记处理能力或受委派任务运行，复用 operation_id、幂等、取消、持久化及状态核对，不另建隐藏后台运行时。只读查询不伪造变更操作身份，保存候选和长期写入沿用 Memory 操作。
- **本地参考部署** 以一个端侧节点、另一模拟端节点和一个模拟云节点建立独立数据库、索引和内容目录；即使同一机器运行，也经真实协议和相互隔离的数据路径验证。共享进程可用于开发，但不能据此证明进程/操作系统级安全隔离。

端侧私有数据仅写端侧 SQLite/内容存储；云侧 SQLite 保存云端获准数据及许可投影。无需独立数据库集群。默认元数据外发范围及策略模板按本册矩阵执行；凭证、可信身份与策略执行机制由授权分册落实。

## 能力验收设计

| 验证内容 | 要求 |
| --- | --- |
| 原文禁止上云但可用 | 端侧检索命中并在端侧影响应答或行动；检查云端数据库、索引、模型请求、消息、日志和缓存未出现禁止外发的原文及派生载荷。 |
| 有限披露 | 仅批准字段/计算结果到达指定云端；受控引用不能越权解引用，查询返回不能自动被长期保存。 |
| 隐藏存在性 | 不向无权方泄露私有记录标题、命中数或目录；控制状态按声明范围返回。普通测试不宣称证明所有时序侧信道均不存在。 |
| 端侧持续挖掘 | 在授权范围内生成并保存可追溯记忆，来源变化使派生内容失效；授权外数据不被持续扫描。 |
| 受限模型调用 | 仅端侧可用信息不会被发送到远程模型、Embedding 或重排器；无合适本地能力时明确不足。 |
| 多端与离线 | 本地、共享和许可投影按各自策略查询；离线呈现不完整或等待，不伪造零命中或偷偷扩大同步。 |
| 策略变化 | 收紧后停止新增外发并跟踪清理；放宽不触发未授权全量历史上传。 |
| 可替换与效果 | 更换检索、提取或存储 Adapter 后遵守相同位置和披露契约，并以受控数据集验证个性化实际效果。 |

上述为待实现的测试设计，无运行或安全验证结果。验收围绕数据驻留、可检索性、提取和跨端治理能力，不要求真实手机。

数据策略的可信身份、签发与处理端检查已在 [授权分册](08-authorization-and-user-control.md) 落实。原文、索引和能力描述的可发现/披露范围均进入判定，密钥留在允许位置；签名授权不替代来源修订核验或允许云端放宽端侧私有策略。
