# ADR-0008：公共合同保留内部语义，外部协议经适配器接入

外部协议的 Task、取消和完成不必具有 Lerna 的目标与效果含义，协议版本也会演进。因此，Application 与 Component 合同保存本地任务、命令身份、恢复和关闭语义，MCP 与 A2A 通过独立适配器接入。远端 completed 或取消回执只作为输入事实，不能直接决定本地成功或效果关闭。

Application 面向目标提交、控制、观察和交互；Component 面向可替换能力的固定输入、持久接纳、查询、费用与关闭；Host 是默认宿主的内部同版接口，不要求第三方远程组件采用。SDK 可以隐藏编码、重连和分页，但必须保留输入已保存、业务已接纳、执行结果未知等差异。

端云采用 WSS，服务间采用 gRPC，同进程使用直接接口；发现、认证与内容字节使用 HTTPS。gRPC 以 Protobuf 外壳承载严格 JSON 领域正文，避免两份字段规范。Schema 按 profile 和方法版本协商，未知字段、枚举或未支持语义默认拒绝；合同、生成类型、SDK 和正反例同版发布。

**取舍与代价。** 不直接复用 MCP/A2A 状态机作为内部权威，也不暴露默认数据库和队列为扩展 API。需要维护远端句柄映射、转译、版本兼容、WSS 流控与重连测试。不能提供必要去重、查询或关闭保证的服务应限制用途或拒绝开放，不能由适配器伪造保证。

**重新评估条件。** 只有公开生态协议能够完整表达并通过测试验证所需语义时，才考虑减少包装。当前行为文档和占位版本不是完整线协议 Schema；开放方法前仍需机器契约、独立实现及真实协议故障测试。
