# ADR-0007：分离准确内容、长期记忆和决策快照

同一份材料可能包含原始观察、摘要和后续更正，不能混成一个可任意覆写的提示字符串。因此，Content 保存准确版本字节，Memory 保存获准跨任务复用的语义与来源，Snapshot 固定一次决策实际采用的材料、预算和版本。三者分别承担存储、复用与决策依据责任。

ContentRef 标识版本与摘要，读取仍检查当前权限。Memory 保存来源、观察时间和适用范围，更正形成新版本；检索先限定获准集合再排序。默认词法与元数据检索，向量、混合和关系索引作为可替换、可重建的投影，不能成为独立真值或授权来源。

上下文必须保留当前目标、必要条件、控制、预算、期限和相关未决效果。强制信息超过模型上限时返回 `context_overflow`，不静默删掉约束。读取、处理、长期保存、同步和披露分别授权；派生结果受全部实际处理来源约束，不能只记录答案展示的引用。

**取舍与代价。** 不把任务历史自动变为长期记忆，也不把供应商缓存当作持久快照。准确来源、版本与 holder 增加写入和清理成本；撤权先停止新使用，再传播清理，离线残留必须可见。正文可按政策清理，但唯一依据已删除时不得继续声称证据可回读。

**重新评估条件。** 是否默认使用向量检索或更复杂上下文策略，由固定任务集的质量、累计费用和维护成本决定。可以按保留政策减少正文与副本，不能省去当前权限、来源更正或证据可用性说明。
