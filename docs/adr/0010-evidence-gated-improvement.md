# ADR-0010：以业务效果和故障证据控制优化与发布

更多 Agent、更大上下文或更多调用会同时改变结果、成本与失败机会，外部论文也不能证明 Lerna 已取得同样效果。因此，优化以冻结条件下的业务结果、累计成本、耗时、错误效果和恢复证据比较；经验、策略与代码候选经过各自用途授权、验证和受控发布。

实验固定任务与样本、模型可取得的版本、工具、数据、预算、重试及期限，调参与最终验收材料分离。所有分支与维护费用计入同一根预算，unknown 和未完成样本保留在分母；人工纠错或代做的样本单独报告，不计为自主成功。每个故障反例都需要允许正常动作完成的正向对照。

常规记忆更新可以在明确授权内自动生效；声称能力改善则需要对照证据。插件与内核代码形成可审查补丁，由维护者批准发布。评测通过不授予发布权，发布批准不代表实例就绪；扩大范围或修改门槛需要新的批准，质量下降触发封新使用或有资格的回退。

**取舍与代价。** 不以机制数量、论文名目、模型自评或最好一次结果评价先进性，也不让策略修改自己的验收门槛。需要维护冻结任务集、独立真值、重复实验和真实目标状态。文档检查、合同符合性、能力质量和生产容量分别取证，模拟或单进程结果不能替代生产验证。

**重新评估条件。** 候选策略在同等条件下没有净收益时保持可选或停用，不能为既有投入临时放宽门槛。新增能力必须有真实使用者、明确负责方和可验证收益；没有完成专项合同与恢复验证的可选能力保持不支持。
