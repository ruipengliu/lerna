# ADR-0005：显式记录未知效果，沿原身份核对

外部写入可能已经发生，而本地还没有保存回执；数据库检查点无法消除这个窗口。因此，Executor 将 Effect 的 `applied`、`not_applied`、`unknown` 与 `may_apply_later` 分开保存。只有效果确定且不会迟到发生，才满足效果关闭条件；普通超时不能证明未执行。

恢复沿原 Operation 和原请求身份查询、读回或安全重传。安全重传需要目标强制幂等且处于有效保留期，或有可信证据证明未发送、不会再发生；新增物理 Attempt 不改变 Operation 身份。无查询能力且无法排除已发生时，保留 unknown，阻止同义盲目重做，并请求受信处理。

取消先于 invoke 到达时，Executor 保存绑定原 Task owner、Operation 和意图摘要的关闭记录，拒绝迟到启动；已经可能发送的操作继续核对。取消、补偿和重新行动都有各自业务含义，不能声称撤销了历史效果。Task 失败或取消后，原效果、费用与清理责任继续保留。

**取舍与代价。** 不承诺任意第三方动作恰好执行一次，也不把持久引擎的任务重试当作行动重试许可。部分工具会留下需人工介入的未知状态；纯读取也可能收费或泄露材料，仍需声明重复语义、权限和用量。

**重新评估条件。** 优先采用能提供更强幂等或原请求查询的目标 API。只有目标系统明确参与同一原子协议时，才考虑收紧该能力的保证；用户点击重试、租约过期或查询暂未找到都不足以改变保证。
