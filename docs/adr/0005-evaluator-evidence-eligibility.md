# 通用质量评估分级准入，停用与旧证据失效分别裁决

普通开放质量保留 `assessed` 路径：固定规则、实现、适用范围及契约与反例测试齐备时可以完成任务，未做专项校准须明示；专项准确性保证和高影响自动判断另需独立样本、预先固定的指标与阈值。相比所有评估都先校准，这保留通用任务的覆盖范围，代价由结果使用者承担尚无定量准确性保证的限制，提供方与评测维护者仍对声明范围及缺陷处理负责。明确业务需要更强保证时，通过固定 TaskPolicy 收紧准入，不能事后用项目总体成功率充当验证器准确率。

普通退役、到期或升级只封闭新调用；受信维护者确认判断缺陷且命中规则、实现版本和适用范围时，活动任务保留旧记录但不得再靠该记录通过条件，须补证或重核。已成功任务保留固定 Result 与终态，另展示证据失效说明。相比所有撤回都重核，这避免正常维护使有效成果失效；相比旧证据永远有效，这要求宿主维护当前缺陷检查及可恢复的影响处理。跨域缺陷的即时可见性不能由安装批准协议推导。
