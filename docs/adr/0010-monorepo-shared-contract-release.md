# 同仓维护核心、默认组件与 SDK

2026-09-28 用户确认：实现采用单一 monorepo，Go 初期使用一个 module，核心、默认组件、Go/TypeScript SDK、CLI/Web、部署适配和验收资产共同维护。协议、实现和一致性证据随同版契约一起验证，避免尚未稳定的接口在多仓独立发布中提前分叉；生产进程仍按既定职责独立装配。

代价是维护者要在同仓管理 Go 与前端构建，Go SDK 初期也随该 module 发布。目录区分公开扩展接口、客户端与内部实现，不能把所有领域实现都承诺为稳定 API；只有确有独立发布节奏、依赖体积或维护团队边界时，再拆 module 或仓库。显式 SQL、独立 PostgreSQL/SQLite 适配和 React/TypeScript/Vite 选型随工程方案维护，不另设发布权威。
