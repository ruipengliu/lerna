# Harness 评审后续优化项（2026-09-28）

本记录收录 28 日评审意见。第 1 项公共框架的详细设计和九模块接入已纳入正式文档，运行实现与故障／性能验证仍待完成；第 2 项规则 shortcuts 已获设计确认并纳入 Brain，System One 应用方案已补充；两者尚未运行实现或实测。

## 1. 统一可靠接纳与持久工作推进框架

**已有依据：**[默认宿主的装配与持久接口](../../docs/architecture/deployment.md#4-默认宿主的装配与持久接口)已定义 transaction、command_store、job_store 及宿主工作领取边界。[Brain 实现](../../docs/architecture/brain/implementation.md)等模块各自保存接纳、处理和恢复责任。原评审建议在既有接口上提炼可复用骨架，当时仅登记候选；本轮已完成选择和文档落实，不声称已经实现。

**已确认公共骨架：**采用可装配的接纳与有界工作模板，统一逻辑 JobStore，保留各提交域的存储布局。沿原命令去重，将领域准备或业务决定、合法回执阶段及下一责任共同保存；有界领取与回写分别核验 lease_epoch 和 work_revision；外部步骤在事务外执行。领域处理器可组织多个短事务，继续裁决业务成功、外部效果与安全重试。选择依据见[评审提案](reliable-work-framework-proposal-2026-09-28.md)及 [ADR](../../docs/adr/0009-reliable-work-framework.md)。

**文档落实：**[框架详细设计](../../docs/architecture/reliable-work.md)集中定义接口、事务句柄、处理器、领取及责任版本、恢复、故障套件和成本口径；[九模块接入](../../docs/architecture/reliable-work.md#integration)分别定义责任键、共同提交内容和领域完成条件。[FW-01～09 与领域验收矩阵](../../docs/architecture/validation/fault-experiments.md#reliable-work-framework)覆盖失答复、接替、新责任竞争、外部未知及恢复放大，仍待真实运行。

**边界：**领域接纳规则、成功判断、外部效果核对和安全重试条件继续归各模块。公共框架不能自动重试未知副作用，也不能绕过领域事务；共享实现不强制同一数据库或工作池，不要求只读或可同步结束的调用全部异步化，不新增通用业务状态机或独立调度服务。原评审登记时的“本轮不修改正式设计”已由本次用户明确要求及两项设计确认推进为正式文档整合，第三方公开方法和回执阶段保持。

## 2. 模型调用成本与等待优化

**评审范围：**先检查每次物理模型推理的必要性，再比较确定性替代、剩余调用用量与异常回退。具体方案及逐次调用清单见[模型调用优化](model-call-optimization-2026-09-28.md)。用户后续确认增加规则 shortcuts，并要求调研 Jev 等 System One 模型。规则与可选类型化模型现已纳入 [Brain 决策路径](../../docs/architecture/brain/decision-paths.md)，外部证据见[研究笔记](../../docs/research/system-one-models-2026-09-28.md)；原合成对照保留，运行实现及启用仍待完成。

**纠偏与推荐：**`decide` 工作、`brain.decide` 请求与物理生成分属三个层次；每个 Decision 可以对应零个或一个 ModelCall。原实例的蓝牙 2／3 次与报告 5 次是“每 D 都生成”的所选基线，相关歧义已在实例正文及其生成源同步修正，原轨迹与统计保留。推荐先利用既有 DecisionPolicy 验证蓝牙 D2／D3 的规则提案，再验证报告 D2 查询模板与有界 D3 选页；候选正常路径分别为 1 次、4／3 次。

**成立边界：**条件改变后仍保存新修订、新快照和新决定责任，原行动及 plan_delta 全部失效。规则使用完整条件、准确能力与当前证据构造新提案；缺权限、过期事实和未知效果分别由原负责方处理，不靠新生成绕过。报告保留综合与独立质量／引用语义评价，结构化查询参数来自当前 fixture 的已知输入，不能推广为任意自然语言的免费前提。

**验证证据：**[配套投影与检查](model-call-optimization-data/README.md)核对零模型 Decision、字段来源、新计划、原基线完整性和调用／材料字节计数；它不是完整协议执行或性能基准。真实 token、费用、延迟、任务成功率与约束遗漏尚待实际适配器和隔离评测。次数下降不等于同比例费用下降，运行实现与正式启用另行推进。

**System One 补充：**首个候选为规则不能处理的报告选页。它替换其中一次语义调用，不额外充当所有任务的入口路由；合法拒判须保存原调用，再由固定策略另开 Decision 升级。规则可选完页面的 R3 不插入模型，D4 综合及 O7 独立评估保留。Jev、AnyJev 和 TypeLLM 的机制、概率含义与测量口径分别列明；供应方费用上界及恢复依据未核实前不激活严格预算 profile。
