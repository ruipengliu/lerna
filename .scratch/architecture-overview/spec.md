## 已核实的实现及图形工具事实

现有方案按事实裁决划分模块；适用的同库事实共同提交，跨独立提交域使用原身份恢复。模块、owner、进程与提交域不一一对应。Task Home 与当前进程、业务状态与效果、内容引用与当前用途、发布批准与实例就绪均需分别表达。

本机 draw.io 为 28.0.6，路径 `/Applications/draw.io.app/Contents/MacOS/draw.io`，支持原生模型导出 PNG 及非压缩 XML 回读。diagram-design 提供图示规范及 drawio 提取器，没有原生 drawio 导出器；按用户指定格式生成 mxfile/mxGraphModel/mxCell，遵循其配色、字体层级、直角圆弧连线和标签留白规范。

## 验证计划

1. 独立读者根据总览及当前架构正文复述抽象原则、事实归属与关键失败链，不提供会话讨论历史。
2. XML 检查 ID 唯一、parent／source／target 有效、层级无环、原生节点可编辑；核对图中关系与正文。
3. 使用真实 draw.io 引擎导出图片并实际查看全图及局部，修正文字、走线和裁切问题；回读非压缩 XML 核对结构仍在。
4. 检查 Markdown 本地链接与锚点、差异空白及本轮范围。既有契约和 Mermaid 无变动时不重复其运行记录。

这些检查不执行 Harness 服务、故障或性能实验。
