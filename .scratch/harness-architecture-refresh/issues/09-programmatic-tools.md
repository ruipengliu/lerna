# 09: 受限程序化工具的执行与恢复合同

**What to build:** 设计一段获准程序如何在受限执行宿主内完成有限工作，逐次经过真实出口的准入，并在取消或恢复后解释每项效果与费用。

**Blocked by:** 03：最终工具参数准入与完整效果交付；07：扩展暂存装配、配置竞争与实例就绪。

**Status:** ready-for-agent

**Progress:** completed

- [x] 程序化能力归 Executor driver，固定代码、运行配置和输出版本；每次外部效果、模型请求及子委派分别准入和关联。
- [x] 明确文件、网络、凭证、子进程、时间与输出限制；平台能力不足时关闭相应能力，不以 VM 名称代替隔离证据。
- [x] abort 回执与 cell 或子进程实际停止分别记录；恢复不得依赖不可信对象反序列化或重放未知效果。
- [x] 若编译为原有限计划则沿既有计划实验；交互式 cell 使用独立冻结对照，不能复用不同因素的统计分母。
- [x] 给出越界访问、DNS/重定向、符号链接、取消、恢复及合法程序正例的验收设计，费用覆盖全部尝试和维护成本。
