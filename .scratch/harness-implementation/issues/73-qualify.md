# 73: 用独立保留材料判定发布资格

**What to build:** 执行最多五候选筛选、冻结一个再确认，记录反馈污染和新材料；绑定精确候选，全部适用门槛满足才具资格。

**Blocked by:** 72：从运行证据提出改进候选；49：比较候选并验证统计适用性；44：构建多步与正确不执行基准

**Status:** ready-for-agent

**能力映射:** C9、C8、C7

**规范依据:** 评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 每轮开发/验证最多筛选 5 个候选，冻结其中 1 个及精确资产后才触发独立保留确认；记录材料来源族、反馈及每次使用。
- [ ] 保留结果一旦参与选择或修改，后续确认换新来源族并建立可比较基线；公开回归夹具和改名重提不当新保留证据。
- [ ] 同计划基线/候选使用独立重置状态、相同目录/预算/评分器及受控环境，校验全部适用绝对质量、契约、权限与数据硬门槛。
- [ ] 默认主改善指标为单步首次正确率，适用配对差值 95% 区间下界>0；单步/多步成功点分不降，平均 token 与 p95 延迟≤基线 110%，零/缺失基线按预定绝对限额。
- [ ] 缺证据、不可比较、推断不适用或任一硬失败均不授资格，冻结记录不能用于另一份产物，候选与基线变化重新核验。
- [ ] 资格和评测交接持久恢复，核对原操作而不复制样本；受控夹具可验证管理状态机但报告明确不是实际改善证据，正式结论由完整评测取得。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
