# 83: 验收联网问答专项质量

**What to build:** 独立运行固定/实际联网两组，逐类验收答案≥90%、引用支持与覆盖各≥95%，记录真实来源和裁决。

**Blocked by:** 45：构建联网问答证据与判定集；65：替换搜索与内容获取 Adapter；48：恢复、取消和重新判读评测；62：替换 Brain 策略与 Model Adapter

**Status:** ready-for-agent

**能力映射:** C1、C2、C3、C4、C8；V1

**规范依据:** 专项验收、持久化替换与实施交接；评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 固定 400 例和实际联网 120 例分别运行真实模型，各自均分四类并逐类判定完整答案≥90%，两组独立报告。
- [ ] 关键事实引用支持和覆盖分别≥95%，按组/类别对适用样本等权，保存逐例分子分母；无适用项不填 100%，遗漏必要事实不提高覆盖。
- [ ] 实际联网经真实网络取得材料及时间，获取失败注入明确标注；固定资料回放不代替联网证据，禁止伪造已取得来源。
- [ ] 独立复核者完成事实、引用与限制核验及争议裁决，辅助模型不独自放行；来源变化按采集时刻判读。
- [ ] 每任务模型≤8/token≤131072、新操作≤16/辅助查询≤64、固定 180 秒/联网 300 秒，纠错、重发和并发沿共同上限。
- [ ] 记录同候选版本、真实证据、权限检查和完整结果；不满足门槛或裁决未完明确 FAIL/INCOMPLETE，不能用 API 分数代替 V1。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
