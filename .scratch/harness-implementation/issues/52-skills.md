# 52: 导入用户 Skill 并用于任务

**What to build:** 按固定格式快照导入普通内容包，按需加载并锁定版本；引用及脚本分别处理，内容不增权或自动执行。

**Blocked by:** 50：准备并激活受信能力插件；18：让适用记忆改变回答和行动

**Status:** ready-for-agent

**能力映射:** C1、C2、C6、C7

**规范依据:** 插件、Skill 与 Agent 扩展生态；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 普通 Skill 内容目录无需改写成插件工程即可导入，生成伴随登记和全文件内容快照，格式固定到已确认 agentskills 修订。
- [ ] 名称/描述及目录按参考 profile 校验：ASCII 小写、数字和单连字符，名称 1–64、描述 1–1024，目录同名；正文/描述允许中文，超参考名称范围显式诊断不静默改名。
- [ ] 先发现名称与用途，选中后在任务预算/位置范围加载正文与资源，固定本次 Skill 版本并实际影响任务步骤；同名来源显式消歧。
- [ ] allowed-tools 等建议不授予权限，正文/资源不执行脚本或安装钩子，未知可选元数据无新增执行语义。
- [ ] 用户本地改动形成新候选，经验证激活后供新决策使用，旧任务继续旧快照；可执行资产另经运行器与代码发布权限处理。
- [ ] 验证内容越界、缺资源、同版本变内容、私有 Skill 出口、冲突和脚本不支持；源删除及权限收紧沿来源生命周期失效。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
