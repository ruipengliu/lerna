# 39: 在端侧完成私有推理与交付

**What to build:** 云端委派受限步骤，由端侧模型使用私有记忆并在端侧呈现；无获准处理能力时等待，不隐式上云。

**Blocked by:** 38：检索端侧数据并只返回许可投影；28：委派子任务并收集结果；32：从 UI 回应任务及授权等待

**Status:** ready-for-agent

**能力映射:** C1、C2、C5、C7；A3、A4

**规范依据:** 端云记忆驻留与联合检索；大脑循环与多 Agent 协作；端侧 UI 交互与协议扩展。共享实施及报告约束见本工作包规格说明。

- [ ] 云端父任务委派受限子目标给端侧 Task Owner，端侧在允许位置调用模型及私有 Memory，形成实际答案或行动。
- [ ] 严格留端答案直接呈现到获准端侧 UI；云端只获得允许控制状态，若命中状态也敏感则统一回应，不声称读过私有论据。
- [ ] 有限披露任务另行展示批准投影可返回云端，随后保存/再转发仍分别授权；双方预算及委派限制不扩大。
- [ ] 本地模型/感知能力不足、端侧失联、来源删除或任务取消时保持对应等待及核对，不改用未获准云模型。
- [ ] 检查云端数据库、索引、模型请求、消息、日志及评测出口，原始数据和不允许派生结果均未离端；证明私有信息实际改变端侧输出。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
