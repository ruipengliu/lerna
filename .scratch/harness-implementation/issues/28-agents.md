# 28: 委派子任务并收集结果

**What to build:** 父任务串并行委派内部 Agent，持久分配预算与收缩授权；核对重复提交、结果冲突、取消和必需分支失败。

**Blocked by:** 26：断连重启后恢复可靠端云操作；14：让大脑选择 API 并完成任务

**Status:** ready-for-agent

**能力映射:** C1、C5、C6、C7；A1、A3、A4

**规范依据:** 大脑循环与多 Agent 协作；决策准入、交互与协作恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 父任务经有限提案委派串行及并行内部 Agent 子任务，每个子任务拥有独立 Task Owner、输入/结果 Schema、期限、必需性与依赖。
- [ ] 父端持久预留预算与提交意图，子端幂等受理并受收缩授权约束；提交回包丢失核对原操作，不创建第二子任务或授第二份额度。
- [ ] 子结果保留来源、可见证据、覆盖及效果状态，父端按自身目标核验；冲突不按多数覆盖，子完成标签不直接决定父终态。
- [ ] 必需失败阻止依赖分支，独立分支可继续；父取消传播至所辖子任务，失联或未知效果不虚构停止，终态前处置全部所辖工作。
- [ ] 协作消息以 SubmitUpdate 追加受信来源事实，不能直接修改另一任务权威；检测可见依赖循环，其余以期限和无进展约束。
- [ ] 验证跨进程重启、并行预算、取消、冲突结果与迟到关联；普通远程工具调用仍不强制产生子任务，子任务不默认脱离父任务。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
