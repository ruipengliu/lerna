## Agent Brief

**Category:** enhancement

**Summary:** 受信管理保存凭证，受信 Driver 按精确目标绑定使用；持久密文、独立密钥与实际目标请求构成完整验证切片。

**Current behavior:** Execution 可在当前 Harness 授权下调用受信 Driver，但尚无加密第三方凭证引用或受控解引用路径。

**Desired behavior / Key interfaces:**

- CredentialBroker 保存引用与主体、Driver、服务、账号、用途、位置及期限；普通使用接口不返回明文、回调或自选目标，而调用构造时固定的受信出口。管理与使用是不同权限，现有授权通过消费方接口接入。
- Store 只保存有上限的密文及元数据，通过修订比较防止并发覆盖；SQLite 是参考 Adapter。KeySource 从独立受限文件供应版本化主密钥，先持久预留 nonce/用量再加密，崩溃和数据库回滚不能重新使用已保留 nonce。主密钥文件自身回滚/同宿主被控制不属于文件权限的保护范围，明确说明。
- 使用 Go 标准 AES-256-GCM；认证附加数据绑定可信引用、完整目标绑定、格式/记录版本及期限。每密钥最多 2^20 次加密，单凭证最多 4096 字节；默认最多 64 条凭证，每次操作有界，所有异常只返回固定原因码。
- 主密钥文件使用独立 0700 目录和 0600 文件，拒绝不安全权限、符号链接及错误格式；密钥按版本保留，管理入口有界轮换密文、可断点继续，不提前删除旧密钥。凭证数据库不能作为主密钥位置。
- Driver 通过精确绑定的 Broker.Use 发往固定模拟服务；目标账号/用途/驱动不由模型载荷覆盖。固定出口输出经过 Schema/字段白名单转换，不转发目标原始正文或错误，构造恶意反射秘密的目标仍不能使秘密进入普通结果。

**Acceptance criteria:**

- 已约定测试接口：CredentialBroker、Store、KeySource、Harness 授权 Adapter、受信执行出口。验证真实 SQLite 重开、密文与权限检查、实际 HTTP 模拟目标效果、拒绝路径未发送请求、正常独立调用继续。
- 验证引用/主体/账号/服务/Driver/用途/位置错绑、过期/缺失/钥匙不可用、密文或 AAD 篡改、nonce 并发唯一及耗尽、轮换中断恢复、明文和错误出口；不以返回固定成功代替业务效果。
- 提供本地受信管理 CLI 和命名 profile，报告固定配置、版本、依赖、实际结果及可信宿主限制；全量回归并独立双轴审查，提交当前分支。

**Out of scope:** 第三方 OAuth 自动续期、OS keychain/KMS 具体后端、恶意宿主内存隔离、跨节点凭证同步、完整防备份回滚设施；不扩充公开下载明文接口，不调用用户真实 API 凭证。
