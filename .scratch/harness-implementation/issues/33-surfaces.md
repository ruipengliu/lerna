# 33: 恢复多端多窗口的 UI 状态

**What to build:** 正确路由 surface，按基版本应用补丁；断连、末次增量丢失和窗口重开恢复快照，旧消息不能重新激活界面。

**Blocked by:** 31：呈现并提交无任务 UI 交互

**Status:** ready-for-agent

**能力映射:** C5、C6、C7；A4

**规范依据:** 端侧 UI 交互与协议扩展；恢复状态与故障检查表。共享实施及报告约束见本工作包规格说明。

- [ ] 同一账号多个模拟端、同端多个 surface 和同任务多处呈现均以 endpoint/surface/component 正确路由，不串发输入。
- [ ] SurfacePatch 仅在 base_revision 匹配时原子应用，否则请求权威快照；临时状态流通过版本通告/周期核对发现最后增量丢失。
- [ ] 断连后获取当前快照、有效等待项及已提交操作结果；窗口关闭后任务可继续，重开不复用旧版本空间。
- [ ] 旧 surface 或旧连接消息不重新激活失效界面，必要迟到业务结果仍保留供核对；本地草稿不反向覆盖权威快照。
- [ ] 多个模拟 Renderer 声明不同组件能力，验证降级/拒绝、快照大小及慢消费者背压，展示实际应用版本与业务结果的区别。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
