**What to build:** 隔离命名空间中持久调度样本，由独立 Evaluator 评分；首次与最终结果分开，保留全部分母及版本、预算。

**Blocked by:** 14：让大脑选择 API 并完成任务；40：按任务和操作查询运行事实

**Status:** ready-for-agent

**能力映射:** C8、C1、C4、C7

**规范依据:** 评测接口、参考基准与发布判定；运行观测、能力评测与受控自进化。共享实施及报告约束见本工作包规格说明。

- [ ] Evaluation.Start 持久冻结计划、版本、初始状态、目录、预算、样本与评分器，再以原操作交接隔离 Harness 任务，提供 Get/LookupOperation。
