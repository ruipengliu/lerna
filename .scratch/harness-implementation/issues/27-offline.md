# 27: 同步授权并落实有限离线运行

**What to build:** 快照接增量同步策略和撤销，区分接收与应用；授权到期、离线重启和时间异常停止新受限工作。

**Blocked by:** 26：断连重启后恢复可靠端云操作

**Status:** ready-for-agent

**能力映射:** C5、C7；A3、A4

**规范依据:** 授权生命周期、凭证与控制接口；端云任务所有权与恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 授权方提供受控视图的一致分页快照与后续变更，接收方原子应用策略/撤销及游标；接收回执与已应用状态分别展示。
- [ ] 可离线动作使用有限、绑定接收方且可本地核验的授权及已分配额度；要求即时在线核验的动作失联等待。
- [ ] 在线建立时间锚点，结合单调时间及可检测时钟/休眠异常校验；到期、回拨或不确定时停止新受限动作，不清除已发生效果。
- [ ] 依赖远端授权的离线重启默认重新核验；本地权威可在受信本机恢复，不要求外部云服务或把持久剩余时长当作有效证明。
- [ ] 祖先撤销、策略收紧、通知丢失及游标过期触发正确停止/快照恢复；离线撤销未送达明确显示 pending，不宣称即时生效。
- [ ] 额度交付或消耗未知不回收复用，旧备份和克隆状态隔离；验证当前签名合法但已知撤销仍被拒绝。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
