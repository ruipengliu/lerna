## Agent Brief

**Category:** enhancement

**Summary:** 将受控授权状态同步接入实际端云执行，使有限离线授权、已分配额度与可信时间共同约束每次新动作，并可核对撤销的接收和应用进展。

**Current behavior:**

GrantAuthority 已验证签名、接收方与出示节点绑定、当前授权及祖先限制、已知撤销、策略和额度；ReserveUse 按原操作保存预留。ConfirmApplied 是受信接收适配器的确认入口，要求调用方先原子应用状态及游标。授权 Service 使用受信 Clock 和持久 LastTime 拒绝可见回拨。可靠 WebSocket 已支持调用意图持久保存、接收前缀、原消息补投与原操作恢复，但尚未连成策略/撤销同步及有限离线执行链路。

**Desired behavior:**

授权权威提供受当前披露策略限制的 ReadSnapshot/ReadChanges 视图。分页绑定权威、获准范围、快照修订边界及分页位置，分页期间发生的修改通过边界后的连续变更接续；不能将不同边界或不同视图拼接。同步包含适用策略、授权链限制、删除和撤销事实，不能用副本修改覆盖权威，也不能通过普通同步建立新信任根。

接收端持久接收与应用分开：在同一本地提交中应用策略/撤销及已应用游标，成功后才报告已应用。授权方已记录、消息已持久接收、接收方已应用和仍待送达分别可查询。通知丢失、重复、乱序或迟到确认不推进错误修订；游标或视图失效、缺口不可接续时重取获准快照。恢复过程不得清空已知撤销后暂时放行工作，所有通知、分页和覆盖报告持续受披露约束。

实际执行入口明确区分允许有限离线的能力与要求执行前在线核验的能力。离线动作必须持有可本地核验、绑定接收方和出示节点、资源/用途/动作/期限受限的授权及已分配额度，同时满足当前已知祖先限制、策略、任务资格和控制意图。在线必需动作失联等待；未送达的远端撤销标为 pending，不宣称离线端立即停止。已知撤销或策略收紧生效后，即使签名仍合法也拒绝新的受限动作。

在线验证建立本进程时间锚点及最晚执行期限，期限不超过授权到期与最大离线窗口，并计入允许的不确定性。结合单调经过时间和可检测的墙钟偏差、回拨及休眠异常，在每次新动作、续期和资格变更时检查；无法证明有效则停止新受限工作并等待重新验证，不能因重连、长连接或更新本地剩余时长延长授权。远端授权在离线进程重启后默认等待重新建立时间及授权状态；本地权威可在受信本机重新验证，无须外部云服务。

额度按接收方独立且不重叠分配，实际消费与原操作关联，任务预算不能替代授权额度。重复投递不重复消费；额度交付、消费或外部效果未知时保留未结算记录，不因超时、断连、缩短期限或降低额度就回收复用。旧备份或克隆恢复须隔离并重新核验，不能仅依赖旧数据库内的有效签名、剩余额度或时间水位继续执行。停止新工作不清除已发生效果，已发出动作沿既有取消与效果核对流程受控收尾。

**Key interfaces:**

- 授权权威的 ReadSnapshot/ReadChanges 与接收应用端口：受控一致视图、有限分页/变更、删除与撤销、原子应用和游标；不是任意 Store 远程读取。
- GrantAuthority.Verify、ReserveUse、UsePermit 与 ConfirmApplied：复用身份绑定、祖先检查、原操作额度与应用确认，补齐接收端事实及离线准入；同步不得复制签发私钥或放宽上级限制。
- WebSocket Host/Peer 与授权协议/SDK 端口：承载获准授权同步与进展查询，复用有限传输、认证和恢复语义，保持持久化回执与应用确认独立。
- Execution 的启动与恢复边界、任务资格和控制端口：每次实际新动作检查离线条件；已开始动作继续核对原效果，无关健康工作可继续。
- 时间与安装恢复边界：本进程在线锚点、单调经过时间、可检测异常、远端重启门禁及受信本地权威恢复；不将普通持久文件当作防回滚证明。
- 部署配置：授权/证书/会话有效期、最大离线窗口、时钟不确定性、轮换重叠期，以及快照/变更保留、页大小、队列、字节、重试和 I/O 上限均有限且相互校验；缺少必要配置拒绝启用。
