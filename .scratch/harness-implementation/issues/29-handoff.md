# 29: 协作移交 Task Owner

**What to build:** 源端准备并封存后激活唯一目标，转移恢复资料；逐窗口崩溃与迟到结果下无双拥有者，失联不自动抢占。

**Blocked by:** 28：委派子任务并收集结果；05：暂停、取消和恢复任务；27：同步授权并落实有限离线运行

**Status:** ready-for-agent

**能力映射:** C5、C7；A3、A4

**规范依据:** 端云任务所有权与恢复；恢复状态与故障检查表。共享实施及报告约束见本工作包规格说明。

- [ ] 同一 task_ref 从源 Task Owner 协作移交到唯一目标，保留任务事实、工作、操作、等待项、委派关系、路由及接纳水位。
- [ ] 源端停止新调度并确认旧执行资格不再能启动新动作；无法证明隔离时等待，不能只拒绝旧库写入却放任外部启动。
- [ ] 目标准备快照时无执行权，源端 SEALED 与唯一激活 Outbox 原子提交，确认封存后才发送绑定双方、世代、版本与摘要的凭据。
- [ ] 目标校验后幂等激活新世代；封存/激活提交未知按原提交核对，目标永久不可达时源端不自动重新 ACTIVE。
- [ ] 逐一在准备、封存、激活及回包窗口杀进程/丢包，证明不存在双调度拥有者；冻结期间迟到事实可持久转交并核对。
- [ ] 旧备份或并行身份克隆不当作普通重启，先隔离并核验权威；报告不支持无排他证据的自动故障接管。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
