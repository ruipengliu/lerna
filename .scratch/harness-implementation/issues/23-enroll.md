# 23: 登记节点并验证双向 TLS 身份

**What to build:** 通过受信管理路径签发公钥绑定证书，校验真实节点与代理主体；禁用、轮换及长连接失效检查保持有效。

**Blocked by:** 06：签发、派生和撤销受限授权

**Status:** ready-for-agent

**Implementation:** completed

**Category:** enhancement

**能力映射:** C5、C6、C7；A3、A4

**规范依据:** 授权生命周期、凭证与控制接口；内部契约与外部协议映射。共享实施及报告约束见本工作包规格说明。

- [x] 本地受信管理入口核对绑定节点公钥、目标命名空间及有限期限的加入请求，交付证书；节点私钥留在所属节点，首次信任根通过受信路径配置。
- [x] 实际 TLS 对端验证链与目标身份，证书字段精确映射受信登记；节点仅在已签发代理关系内代表用户，不能自报任意主体。
- [x] 业务调用重新检查节点登记和失效状态，已建立连接及恢复 TLS 会话不能跳过禁用检查，不自动采信代理注入身份头。
- [x] 节点证书轮换重新签发依赖摘要的材料；失钥走受信重登记，签发密钥重叠期有界，发现消息不能创建新信任根。
- [x] 用两个独立节点目录验证加入、错绑证书、跨命名空间冒用、禁用和轮换；登记及禁用记录按版本持久恢复。

**Category:** enhancement

**Summary:** 建立可持久恢复的运行节点登记与真实双向 TLS 身份验证，将当前节点资格及受信代理关系接入业务调用，并完成禁用、证书轮换和受信重登记的验证。

**Current behavior:**
前置 06 的完成记录已确认其限定范围完成。按运行节点、主体、Grant、证书绑定、认证及持久恢复概念检查了授权核心、SDK、Protobuf、本地绑定、SQLite 适配、JOSE 适配和验证 profile：现有 Service.Authenticate 验证本地凭证；authlocal 是受信进程内绑定，不是网络认证。GrantAuthority.Verify 已核对命名空间、主体、接收方、代理出示者及证书摘要，并检查当前授权、祖先撤销和策略；GrantPresentation 明确要求由认证对端后的受信宿主构造。

现有 grants profile 使用本地生成并校验链的证书夹具，明确不证明真实 mTLS、节点登记或轮换。未发现生产节点登记、TLS 对端到受信身份的映射或节点禁用检查实现，因此不是已实现的重复请求。未发现历史拒绝记录。此次验证是增强功能的静态代码与规范核查，没有运行尚不存在的登记功能，也未重跑前置 06 的历史验收。

维护者已接受 enhancement 分类、保持 ready-for-agent 并补齐实施简报；这不表示本票已实施。原验收范围保持，普通实现选择由执行者依据既定架构完成，无需重新选择协议或外部身份平台。

**Desired behavior:**
首次登记经本地受信管理入口核对节点公钥请求、目标命名空间、可代理主体及有限期限，确认提交后交付证书。请求须证明持有对应私钥；私钥在所属节点生成并保留，管理端只接收必要的公钥材料。首次信任根通过受信管理路径配置，新节点不必先通过尚未具备证书的正常 mTLS 入口。登记、禁用及轮换仅由当前有权管理主体操作，普通业务载荷或发现消息不能修改登记或建立信任。

真实 TLS 连接两端验证证书链、用途、期限和目标节点身份，再将证书字段及实际叶证书摘要精确映射到受信登记。证书身份编码和映射规则在实现时固定并以正反例验证；显示名称、请求自报主体和代理注入身份头不能建立身份。节点身份、原始请求主体和接收方身份分别保留。节点代表用户时，当前登记允许该代理关系且受信签发材料绑定该主体、实际出示节点和目标接收方；证书合法本身不授予业务权限。

受信认证结果接入既有 GrantPresentation 和业务授权路径，每次受限业务调用重新检查登记版本、禁用、有效期及适用代理关系，再按既有 Grant 和策略判定。长连接、流内后续调用以及 TLS 会话恢复均不得沿用过期资格。当前登记不可核实时拒绝新受限工作；不得退回本地凭证或浏览器认证。业务动作已开始时保留其事实及原收尾语义，禁用不冒充已取消实际效果。

入口将已验证的出示关系绑定到原操作；本地恢复依据受信持久记录重新核验当前资格，不伪造旧 TLS 连接。持久登记和管理回执按版本更新，遵守当前权限检查、原操作去重、新操作版本比较及原子提交的既有顺序。签发准备成功但提交失败或未知时不得交付未确认资格；按原操作核对，不能生成重复登记或隐式恢复禁用节点。

有效节点可在既有权限内申请有限轮换；失钥或疑似泄露走受信重登记并撤销旧资格。节点证书摘要变化后，经有权签发流程重新签发依赖摘要的授权材料；保留原业务操作、语义、祖先限制、剩余期限及额度，不以重签增加预留、退还未知消费或扩大权限。明确旧证书和旧材料何时失效，并在连接、调用及恢复路径一致执行。证书签发与授权签名使用各自受信密钥映射，不混淆两种用途；适用签发密钥轮换的验证重叠期必须有限，原期限和撤销继续有效，信任根替换仍经受信管理关系。

**Key interfaces:**
- 节点登记管理契约：受信登记、读取、禁用、轮换及原操作核对，表达命名空间、节点公钥绑定、代理主体、认证材料版本、有效期和失效状态；复用既有管理权限、错误及操作恢复约定。
- IdentityVerifier / 认证适配：消费真实 TLS 验证结果和当前登记，输出受信节点上下文；业务参数不能构造或覆盖它。为后续 gRPC 与 WebSocket 绑定提供可复用的调用前核验能力，不要求本票实现完整远程协议。
- GrantPresentation / GrantAuthority：从实际对端和受信代理关系取得身份及证书摘要，继续执行现有授权核验；补足受控重签所需行为，保持原操作与额度不变量。
- 持久登记与信任配置：沿用项目的存储及原子提交模式，保存版本、失效状态和可恢复管理结果；与现有 SQLite 数据兼容，不通过删除旧库升级。
- 部署配置：受信根、签发密钥及用途映射、证书和请求期限、允许时钟偏差、轮换重叠期、记录与材料大小、并发和 I/O 限制均显式有界；缺少必需配置拒绝启用。优先使用 Go 标准库及已有依赖，实际版本和配置写入报告。

**Acceptance criteria:**
- [x] 使用两个独立节点目录和独立私钥，经受信本地管理入口完成登记，并通过实际网络 TLS 握手与受控业务请求验证双向身份；直接构造 GrantPresentation 或只调用证书 Verify 不能替代此证据。
- [x] 首次请求绑定公钥、命名空间及有限期限，验证私钥持有证明；篡改、重放为不同登记、越权管理、跨命名空间登记和超限输入均拒绝，无部分登记或未确认证书交付。
- [x] 错误信任根、目标节点、证书用途、未生效或过期证书、合法链但错绑登记的证书均被拒绝；证书身份映射无歧义，不能靠相同显示名称冒用节点。
- [x] 实际请求可调用一个既有受控业务行为，并核对真实结果；任意自报用户、命名空间、接收方、证书摘要或代理身份头不能覆盖受信上下文。缺少或错绑代理授权时拒绝，合法节点证书不绕过业务策略。
- [x] 同一连接上先成功调用，再持久禁用节点或撤销代理资格，后续调用被拒绝；节点证书到期和授权到期也生效。新连接与恢复 TLS 会话同样拒绝失效资格，核验报告明确是否实际发生会话恢复，不能把完整握手当作恢复测试。
- [x] TLS 握手后、业务调用前发生禁用时仍拒绝；当前登记不可读时不放行新受限工作。并发禁用与调用的准入顺序可核对，已开始的实际效果仍按原业务契约处理。
- [x] 节点证书轮换后，新证书配合经授权重签的材料可调用；旧材料不能在新证书上重放。旧证书及材料按明确期限和失效规则处理，长连接和恢复会话不例外。
- [x] 重签保留原操作语义、接收方及祖先限制，不延长原业务期限、不扩大范围、不重复预留或释放未知额度；已撤销授权不能通过轮换恢复，重复或回包丢失可按原操作核对。
- [x] 失钥节点经受信重登记取得新资格，旧资格持续失效；未经受信管理的发现消息、身份头、证书内地址和未知密钥编号均不能新增信任根。
- [x] 适用签发密钥轮换覆盖有界重叠期内及结束后的验证，旧材料仍受期限和撤销约束；证书签发密钥与授权签名密钥的用途不会互相替代。
- [x] 登记、禁用及轮换在真实 SQLite 重开、并发版本冲突、签发准备后中断和提交成功回包丢失后保持一致；原管理操作恢复同一结果，旧修订不能覆盖禁用。业务恢复从受信持久绑定重新核验，不依赖已消失的连接。
- [x] 节点私钥只保存在所属节点的受限位置，签发私钥仅由获准签发方使用，不进入普通协议、模型输入、日志或错误文本；握手、管理请求和认证检查均有资源上限，超限与不可用有明确失败结果。
- [x] 提供具名可重复验证入口及配置、环境、版本、依赖、执行方法、原始结果与限制记录；分别报告真实 TLS、业务绑定、会话恢复、轮换和持久恢复证据，运行 06 及受影响本地授权/业务路径的必要回归，未运行或失败不得记为通过。

**Out of scope:**
- 24 的完整跨进程 gRPC 能力执行与 Exchange、25 的完整 WebSocket 协商及推送，以及后续可靠传输和授权同步；本票仍必须交付真实 mTLS 到受控业务调用的最小完整验证路径。
- 浏览器登录、Cookie/CSRF/Origin 会话实现、外部身份平台、公共自动注册、外部证书管理平台、任意代理链或 TLS 终止后的身份转换。
- 无限离线认证、跨节点全局即时撤销、防御已控制宿主、硬件密钥设施或普通备份文件的防回滚保证；当前登记不可核实不得以这些未实现能力为由放行。
- 第三方凭证加密及主密钥迁移、任务所有权移交、资源接管和第二耐久后端。不得借节点轮换改变既有业务身份、消费或取消语义。
