# 31: 呈现并提交无任务 UI 交互

**What to build:** 模拟 Renderer 展示聊天、表单/卡片和通知，正式动作可靠提交到登记处理模块；无需伪造 Task。

**Blocked by:** 30：通过浏览器会话访问受控入口

**Status:** ready-for-agent

**能力映射:** C6、C7；C5；A4

**规范依据:** 端侧 UI 交互与协议扩展；原生接口与消息目录。共享实施及报告约束见本工作包规格说明。

- [ ] 模拟 UI Adapter/Renderer 在同一通道呈现聊天输入、结构化表单/卡片和通知动作，至少一个完整交互无 task_ref。
- [ ] 登记类型、版本、Schema、允许事件及受控处理模块；SubmitAction 使用稳定操作，EmitUIEvent 仅处理明确无业务变更的临时事件。
- [ ] 正式输入经当前权限和目标校验后可靠转交，原逻辑操作身份保持；查询动作结果区分已持久接收、已受理与业务完成。
- [ ] 未知必需控件/事件拒绝或采用已声明等价降级；呈现回报、关闭窗口和文字 confirmed 不自动等同批准或取消业务。
- [ ] UI 草稿、附件及正文分别受披露和保留限制；输入回包丢失可按原操作恢复，不依赖 UI 缓存成为唯一记录。
- [ ] 验证未登记事件、伪造目标、敏感输入越界及高频临时事件，报告模拟 Renderer 范围而不声称真实手机支持。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
