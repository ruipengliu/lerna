## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement

**Summary:** 将授权来源的本地提取、候选治理、自动保存及持续触发接入既有受控任务与Memory，在来源约束内积累可追溯、可跨任务使用的记忆。

**Current behavior:** Memory已具备当前授权的Get/Query、Put/Correct/Delete、原操作核对及来源修订；受控任务、能力调用、产物和Context支持预算、取消、持久状态与来源治理。尚无从外部或已有获准来源提取候选的完整流程，没有独立提取/持续扫描登记，也未将提取候选、保存结果和扫描位置纳入来源生命周期与原操作恢复。

**Desired behavior:**

- 以已登记的处理能力或受控任务读取获准来源并提取；来源内容、工具返回与模型输出均为数据，不能修改策略、扩大读取范围、启动后台监听或发布Skill。不得在提取模块另建不受Core管理的执行循环。
- 分别检查来源读取、允许位置的提取/处理、候选保留、长期保存及结果披露。宿主可信身份和策略决定允许范围，调用者只能收缩；模型/规则声明、现有读取权或一个有效调用凭据都不能自动授予其他权限。
- 产生有类型、固定来源修订及定位、提取方式、置信依据与适用条件的候选。显式偏好与基于证据的推断分别表达；不把置信数值或模型自述当作来源事实。候选不能因生成成功就成为已保存记忆。
- 派生内容继承所有来源的存储、计算、用途、披露与保留交集，允许增加更严格限制。交集为空、来源不可访问或无法证明输出满足限制时明确等待/拒绝，不能忽略该来源、移到云侧处理、调用远程Embedding或把“已脱敏”作为放宽依据。
- 在已有保存授权内可自动调用Memory保存，保留原候选与原Memory操作的关联；超出保存权限时仅在另有候选保留权限的范围保存暂存内容，否则不落盘或通过受控交互等待。不能默认永久保存拒绝的候选。
- 有权投影或转换只产生被许可字段/结果；所有出口包括正文、受控引用解引用、工具参数、附件、日志、通知和评测材料遵守同一约束。不得声称规则能证明任意自然语言不存在推断泄漏；无法确认的输出不得外发。
- 持续扫描显式登记来源范围、触发条件、连续读取/提取授权和有限单轮预算。每次触发及关键释放点复查当前权限；撤权、过期、取消或来源删除停止新工作。一次性读取或保存授权不升级为扫描授权。触发登记与任务提交保留可恢复关联，不能在重复触发/重启后重置预算或生成替代副作用。
- 来源纠正、删除、用途收紧使对应候选及已保存派生内容先失效，再按实际来源重建或清理；混合来源不能只去掉标签而保留受限推断。清理责任、实际完成与未接入范围分别记录，复用19的有界失效/确认/恢复约束，包含候选缓存和受控运行材料。
- 提取、暂存及保存沿既有受控任务/能力操作身份恢复。重复触发、保存提交后回包丢失、失败、取消和进程退出均核对原状态；未知保存结果不能以新操作重新入库。取消已经发生的保存只保留事实并按当前授权后续处理，不伪称撤回。
- 单机参考路径采用实际本地规则提取和独立数据目录/服务边界，展示偏好与推断两类输出以及后续任务实际使用。提取器/来源/触发/存储依赖接口，模型Adapter按实际支持位置声明；本票不借用18尚未获准的额外模型预算。本地能力不足必须形成可查询等待/不支持状态。
- 用预先固定的有标注来源集验证提取质量，包含未支持输入、无证据推断和来源内指令。报告具体数据集范围、正确/错误/缺失结果、覆盖率与限制；执行契约通过不等于泛化提取质量通过，规则结果不作为模型效果证据。

**Key interfaces:** 受控任务与能力操作；当前授权/来源策略；Memory Get/Query、Put/Correct/Delete及LookupOperation；受控候选产物与来源依赖；消费方定义的Extractor、触发登记及候选状态接口。保持Go接口依赖，SQLite/本地文件作为参考实现，不引入必需的外部数据库、队列或模型服务。

**TDD seams:** 根据用户持续授权，使用真实授权服务与受控任务/SDK、实际来源修订读取、本地提取器、SQLite候选/触发/Memory持久状态及真实文件出口作为边界。精确故障注入只用于提交回包未知、取消/撤权竞争、出口拒绝和进程退出；通过实际产物与原操作核对证明效果。质量用固定标注样本与实际提取结果比较，不能仅测试内部调用次数或固定成功桩。

**Acceptance criteria:**

- [x] 已授权来源经真实受控能力/任务读取并在允许位置完成偏好和推断提取；候选包含正确来源修订、类型、置信依据及适用条件，授权内自动保存且被后续独立任务实际使用。
- [x] 缺少读取、提取、保存、候选保留、持续扫描或披露任一所需权限时，在相应效果前阻止；来源指令、模型输出和“已脱敏”声明不能升级权限。
- [x] 混合来源约束取交集且敏感输出可更严格；验证禁止离端数据不进入远程模型/Embedding、日志、工具参数、附件、通知或评测材料；本地能力不足显式等待。
- [x] 持续触发登记持久、单轮有界、当前授权逐次复核；重复触发只恢复原工作，单次请求不会产生隐含后台监听，取消/撤权后没有新扫描效果。
- [x] 来源纠正、删除和用途收紧阻止旧候选/派生记忆的新使用并实际清理受控内容；混合来源整体失效，恢复或重建不复活旧内容，范围报告不越过实际消费者确认。
- [x] 候选保存、Memory提交回包丢失、确认前后退出及重启均沿原身份核对；不重复入库、不新增替代操作，未知状态不算完成，取消已发生效果不伪称撤回。
- [x] 固定标注集输出实际提取质量及覆盖限制，另报告脚本/故障契约结果；包含未支持输入、证据不足与来源指令反例，不以流程通过冒充模型或泛化质量。
- [x] 提供具名SDK/CLI/profile和真实进程验证入口，记录版本、依赖、配置、执行位置、数据集、命令、结果与限制；完成相关完整回归、整票verify和双轴审查后方可交付。
