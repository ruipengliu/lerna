## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement

**Summary:** 将可替换的真实内容获取接入既有受控任务与能力调用，在授权和预算内交付带来源、时间、状态及受控正文的证据。

**Current behavior:** Core、Brain、Execution、SDK、受控 Content 和 Task Context 已支持正式调用、授权、预算、原操作恢复及来源约束。现有 HTTP 出口只用于指定凭证目标或模型服务，没有通用内容获取、授权重定向、获取证据和受控上下文交付的完整路径。

**Desired behavior:**

- 用户任务通过已登记获取能力沿正式 Core/Brain/Execution/SDK 接口工作；获取器由消费方接口注入，HTTP 与固定重放 Adapter 可替换，不另建绕过 Core 的执行循环。
- 宿主可信授权决定来源范围、处理位置、用途、尺寸、时间及保留上限；调用者只能收缩。请求 URL、网页、返回头、模型输出不能授予额外来源、凭证、长期保存或后台扫描权。
- 初始请求、每次重定向及实际网络连接均保持获准目标约束；有限跳转数、总时限和响应大小生效。网络地址解析、拨号和代理不能绕过允许范围；本地夹具地址须明确获准，不能因支持测试就默认放开所有内网目标。跨目标不自动转发凭证或其他敏感头部。
- 对真实响应记录请求目标、实际最终来源、获取时间、媒体类型、状态、受控正文/引用和可核对摘要。获取时效、来源缺口和适用范围保留；明确取得的片段/转换与完整原始响应的区别，不能凭猜测补全未取得内容。来源自称公开、脱敏或可长期保存不放宽宿主约束。
- 超时、取消、拒绝、不可访问、过期、响应过大、未支持媒体类型及重定向失败均有可查询结果，不作为成功正文交付。部分字节不冒充完整来源；默认无无限重试、无限解压或隐藏抓取。每次实际尝试和重定向消耗均计入原任务可执行预算，失败不能退款后无限重试。
- 已取得材料进入 Task Context 时携带来源、时间和缺口，网页内指令仅作为不可信数据，不改变运行授权。调用/披露出口继续执行当前用途和位置检查，禁止将受限正文、敏感 URL 或响应头泄漏到错误、日志、附件或报告。不得自动保存为长期 Memory。
- 任务恢复所需正文仅在独立保留授权和有限期限内通过受控 Content 保存。没有保留条件时明确不可恢复或需要另行获准获取，不能伪造已持久结果，也不能用一次新抓取冒充原来源的正文/时间。重复调用、取消及进程退出沿原操作核对，已发生获取及其预算保持真实记录。
- 单机参考采用 Go、SQLite 和本地受控文件，不引入必需外部数据库、队列或模型服务。本地真实 HTTP 夹具验证故障与权限；固定重放、实际网络服务及公共来源真实联网分开标注。实际联网需通过本票 Adapter 获取，不能用浏览器工具或录制响应替代其执行证据。

**Key interfaces:** 正式能力声明与动态参数 Schema；Core/Brain 的原任务预算和执行绑定；Execution 调用及原操作恢复；Content 当前授权/来源策略、受控保存和读取；Task Context 证据引用；消费方定义的获取 Adapter 与可信网络/来源策略。数据库、HTTP 客户端和解析组件留在 Adapter，不让业务依赖具体实现。

**TDD seams:** 依用户持续授权使用真实 Core/SDK/授权/Content、实际 HTTP 服务、SQLite 与文件持久化边界。故障注入只用于明确网络失败、回包或确认窗口、权限竞争和进程退出；结果用真实请求、正文/引用、原状态与任务用量核对，不只断言内部调用次数。公共联网验证使用公开非敏感材料、有界请求，不使用 .env 凭证或付费模型。

**Acceptance criteria:**

- [x] 用户任务经正式能力取得实际网络响应并交付受控证据；实际来源、时间、媒体类型、状态、正文/引用及摘要可核对，Task Context 使用仍保留证据来源和缺口，Memory 无自动新增。
- [x] 请求和每次重定向受当前来源/位置/用途及网络范围约束；验证越权目标、地址/跳转绕过、撤权、敏感头转发和网页内指令反例，禁止效果在发生前阻止。
- [x] 尺寸、时间、跳转和任务用量有可执行上界；超时、拒绝、过期、取消、不可访问、未支持类型及超限内容分别表达。失败/部分内容不能冒充成功，实际尝试及失败均计入原预算。
- [x] 保留和披露独立受权；材料及受控引用的使用遵守原限制，日志、工具参数和报告不泄漏未获准内容，不自动把来源可读权升级为长期保存权。
- [x] 重复、取消、回包未知及真实进程中断后恢复沿原操作/证据身份进行，不重置预算、不伪造原获取时间、不静默用新抓取替代旧证据；未知和不可恢复状态如实可查询。
- [x] 可替换 Adapter 分别运行固定资料重放与实际联网小型验证；公共联网保留采集时间、配置、来源、结果/失败及允许留存的证据，真实网络失败不改写为离线成功。
- [x] 提供具名 SDK/CLI/profile、有界失败夹具及真实进程验证入口，记录版本、依赖、配置、位置、预算、方法、实际结果和限制；完成相关回归、全仓验证与双轴审查后交付。

**Out of scope:** 搜索排名、答案综合（22）、完整 V1 质量门槛（83）、任意媒体格式、浏览器渲染、认证网站登录和全站爬虫。这不豁免真实网络获取、重定向治理、受控证据、任务预算及恢复要求。
