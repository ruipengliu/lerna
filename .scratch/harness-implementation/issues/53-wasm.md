# 53: 运行受限 Wasm 计算能力

**What to build:** 按既定 wazero/ABI 和额度执行纯计算，验证 start 段、取消及超限；默认无宿主目录、网络、环境与子进程。

**Blocked by:** 50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C6、C4、C7；A2

**规范依据:** 扩展清单、运行器与激活恢复；评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 已验证插件经正式能力入口运行纯计算 Wasm，固定 wazero v1.12.0、已确认提交、Interpreter/Linux amd64 与版本化 Harness ABI，按需明确启用 WASI Preview 1。
- [ ] 默认无宿主目录、环境继承、网络及子进程；仅提供声明的受控 ABI，不能把只读挂载视为隔离或把任意原生脚本当可执行。
- [ ] 验证模块≤8 MiB、每 memory≤1024 页、每节点≤2 guest/1 编译工作，输入输出各≤1 MiB、日志≤64 KiB、准备队列≤16，默认关闭编译缓存。
- [ ] 实例化加执行≤30 秒且不超过任务剩余期限，显式 WithCloseOnContextDone(true)，start 段同样受控；每调用新 guest，取消实例不复用。
- [ ] hostcall 限制参数/分配/输出并传递期限，永久阻塞回调不进入支持范围；guest 时间/随机源不用于授权和密钥判断。
- [ ] 实际验证无限循环、start 执行、内存/输出超限及禁止宿主访问，记录不能保证宿主 RSS、编译 CPU 或任意 Go 回调强杀的边界。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
