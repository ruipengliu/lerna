**Category:** enhancement

**Summary:** 提供有版本、有授权、可恢复的记录级删除，立即阻止当前及历史内容的新使用，清理受控派生内容，并按实际控制范围报告完成度。

**Current behavior:** Memory 已支持受控 Put/Correct、精确修订读取、查询原结果绑定、原操作回执及集合变更；ContextAssembler 和派生产物会复核当前来源权限/修订。尚无删除修订、删除后历史回执的最小化处理、可恢复派生清理和备份隔离证明。已有产物清理机制可以复用，但不能替代 Memory 删除决定。

**Desired behavior:**

- Delete 携带原操作身份、记录引用、预期修订和明确用途，由受信主体的当前记录级删除权限决定。与创建/纠正使用一致的身份、去重和未知提交核对规则；不得由客户端携带的策略引用或可写范围扩大删除权限。
- 单一本地原子提交更新记录的删除修订、必要墓碑/集合水位、原操作状态和可补读失效变更。与 Correct 竞争时仅符合预期版本的一方提交；删除记录身份不得重新用于另一条记忆。提交前未知与已提交后清理未知分别表达。
- 权威删除提交后，普通查询、精确历史 Get、已绑定查询重放、上下文恢复和派生读取不能释放旧正文。当前授权优先，未授权主体不能区分存在、缺失或已删。删除元数据及查询状态本身也受权限/保留策略控制。
- 清理受控正文和派生内容，不能仅隐藏当前列表。上下文快照、索引、显式副本和混合摘要都有可追踪来源依赖；混合内容先整体失效，再由仍获准来源重建。尚不存在的索引/摘要模块不预建，但不得忽略现有上下文、产物与运行证据中的敏感载荷。
