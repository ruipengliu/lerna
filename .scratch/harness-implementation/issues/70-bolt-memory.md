# 70: 在 bbolt 上使用与同步记忆

**What to build:** 持久运行 MemoryStore 的读写、同步和删除路径，验证快照产物、索引重建、隐私限制及重启。

**Blocked by:** 67：在 bbolt 上运行并恢复任务；37：同步获准记忆并恢复离线修改；39：在端侧完成私有推理与交付

**Status:** ready-for-agent

**能力映射:** C2、C5、C7；A2、A3

**规范依据:** 记忆数据契约与生命周期；端云记忆驻留与联合检索；专项验收、持久化替换与实施交接。共享实施及报告约束见本工作包规格说明。

- [ ] bbolt MemoryStore 经正式路径完成带版本读写、端云同步、联合检索和端侧私有使用，维持单一 Memory Authority 与数据位置限制。
- [ ] 记录修订、回执、变更、删除/同步水位同次提交；重复原操作和未知提交可核对，不从旧回执恢复被删正文。

- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
