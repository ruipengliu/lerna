# 50: 准备并激活受信能力插件

**What to build:** 从本地不可变资产解析清单与依赖，验证后按激活修订发布完整绑定；冲突、越界资产和无授权自检拒绝。

**Blocked by:** 13：在千级目录中检索准确版本

**Status:** ready-for-agent

**能力映射:** C6、C7；A2、A4

**规范依据:** 插件、Skill 与 Agent 扩展生态；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 从本地目录/离线包准备一项受信编译组装能力插件，解析版本化清单，验证精确资产、接口/Schema、依赖及运行条件后激活，使正式能力请求实际使用它。
- [ ] 导入生成不可变快照，拒绝路径越界、越界链接、解包超限、摘要不符和同版本不同内容，不执行安装钩子或自动编译宿主。
- [ ] 必需依赖缺失/循环/冲突拒绝，可选依赖未满足撤去对应贡献；同能力多个实现显式选择，不按安装顺序抢占。
- [ ] 权限请求不是授权；Validate 行为测试只访问获准夹具，运行位置/隔离限制不满足不能降级或激活。
- [ ] 资产和运行器就绪后，ExtensionStore 原子保存激活修订、贡献绑定、回执及 Outbox；目录投影未应用对应修订不暴露半套新能力。
- [ ] 准备/验证/激活通过管理入口按当前授权、稳定操作和预期版本核验，查询结果未知能恢复；当前受信 Go 模式不宣称强隔离。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
