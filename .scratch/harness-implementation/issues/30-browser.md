# 30: 通过浏览器会话访问受控入口

**What to build:** 同源 HTTPS 一次性登录码换会话，浏览器 WebSocket 校验 Origin/CSRF 与失效；节点认证失败不降级。

**Blocked by:** 26：断连重启后恢复可靠端云操作

**Status:** ready-for-agent

**能力映射:** C6、C7；A4

**规范依据:** 授权生命周期、凭证与控制接口；端侧 UI 交互与协议扩展。共享实施及报告约束见本工作包规格说明。

- [ ] 受信 CLI 生成一次性短期登录码，通过同源 HTTPS POST 换服务端不透明会话；码不进入 URL 或长期配置。
- [ ] Cookie 设置 Secure、HttpOnly 和适用 SameSite，登录和变更入口限制速率/重放并校验 CSRF；错误 Origin 的 WebSocket 升级拒绝。
- [ ] 浏览器连接绑定真实主体及作用域，后续调用和推送复核会话；登出、过期或用户禁用使已有连接停止新受限操作。
- [ ] 原生 mTLS 与浏览器会话使用互斥认证配置，节点认证失败不能退回 Cookie 模式，自报节点/用户不能覆盖身份。
- [ ] 通过实际浏览器或等效协议集成测试验证一次性消费、跨源、会话失效和权限过滤；生成会话仅授权既定范围，不展示原始密钥。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
