# 62: 替换 Brain 策略与 Model Adapter

**What to build:** 两种实际决策策略和独立模型接入分别验证，保留能力差异、版本及位置约束，替换后任务恢复仍成立。

**Blocked by:** 51：升级、停用和回滚固定版本扩展；18：让适用记忆改变回答和行动

**Status:** ready-for-agent

**能力映射:** C1、C6、C7；A1、A2

**规范依据:** 大脑循环与多 Agent 协作；决策准入、交互与协作恢复；能力里程碑与实施依赖。共享实施及报告约束见本工作包规格说明。

- [ ] 提供与默认 Brain 独立的实际决策策略，通过同一 Brain.Decide 完成相同目标；不能将两个配置、脚本空成功或仅换供应商计作两种策略。
- [ ] 另用独立 Model Adapter 经 Model.Generate 接入，分别记录模态、结构化输出、用量、上下文及真实处理位置差异，不宣称供应商等价。
- [ ] 共同用例覆盖任务理解、有限提案、非法输出、陈旧事实、预算、取消和必要等待；不要求逐字相同答案或隐藏思维链。
- [ ] 每次决策固定 Brain、模型、Skill 与组装版本，升级仅影响下一段未固定工作；既有操作、控制及未结算用量保留恢复。
- [ ] 新实现不兼容工作信息版本时明确迁移或等待，不丢弃关键约束；位置筛选和失败回退均不扩大数据披露。
- [ ] 分别提供 Brain 替换证据与 Model 替换证据及小型真实模型对照，完整质量报告由正式评测票取得。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
