# 66: 用独立评分器比较相同运行

**What to build:** 不同组件的证据进入共同评测，替换评分实现形成新判读版本；可比较条件及缺失证据明确表达。

**Blocked by:** 48：恢复、取消和重新判读评测；49：比较候选并验证统计适用性；50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C8、C6、C7；A2

**规范依据:** 评测接口、参考基准与发布判定；能力里程碑与实施依赖。共享实施及报告约束见本工作包规格说明。

- [ ] 不同 Brain/Execution 等组件的受控证据通过共同 Evaluation/Evaluator 契约评分，来源和版本完整可追溯。
- [ ] 实现独立评分器对相同记录重新判读，形成新评分器版本与报告；原逐例证据及既有分数保留，不以覆写掩盖差异。
- [ ] 用有独立真值的代表性样本验证参数、效果、首次错误和不可评分的一致性；开放答案保留独立复核/裁决边界。
- [ ] 不同评分规则或预算的报告不可直接作为同计划改善证据；配对条件、缺失证据和统计适用性明确表达。
- [ ] 新评分器无业务执行或发布权限，不能读取授权外资料，端侧受限评分可留端并只返回许可结果；重放不再发动作。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
