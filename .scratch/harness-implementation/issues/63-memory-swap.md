# 63: 替换记忆检索与组织实现

**What to build:** 独立 Memory 实现经相同访问和上下文路径使用，验证修订、删除、联合查询及个性化；不以换数据库代替策略替换。

**Blocked by:** 38：检索端侧数据并只返回许可投影；50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C2、C6、C7；A2、A3

**规范依据:** 上下文、记忆与同步；端云记忆驻留与联合检索；能力里程碑与实施依赖。共享实施及报告约束见本工作包规格说明。

- [ ] 提供独立的 Memory 检索/组织实现并通过相同访问契约接入真实任务，与默认实现运行同一数据及个性化目标；不只换 Store 或加一层包装。
- [ ] 共同测试验证类型/来源/版本、受控 Query/Get、冲突和部分覆盖，排序分数差异不能影响权限或被当同一置信尺度。
- [ ] 纠正、删除及策略收紧使派生索引和上下文失效，异步重建期间不能泄露旧数据，回执按当前限制返回。
- [ ] 独立端云部署下复用联合检索与允许投影，隐藏存在性、数据驻留和计算位置约束保持，离线不能假零命中。
- [ ] 展示替换前后回答和动作差异及适用质量范围，保留共同语义证据；后端耐久替换与 Memory 策略替换分别统计。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
