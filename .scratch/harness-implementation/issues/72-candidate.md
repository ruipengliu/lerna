# 72: 从运行证据提出改进候选

**What to build:** 生成带来源、精确资产及影响范围的 Skill/策略/Agent 配置候选或可审查代码补丁；不直接激活或改评分规则。

**Blocked by:** 48：恢复、取消和重新判读评测；52：导入用户 Skill 并用于任务；51：升级、停用和回滚固定版本扩展

**Status:** ready-for-agent

**能力映射:** C9、C8、C6、C7

**规范依据:** 运行观测、能力评测与受控自进化；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 从可授权访问的运行失败/经验与评测结果生成 Improvement Candidate，记录问题、来源、产物类型、精确摘要、预期改善和影响范围。
- [ ] 至少实际产出一项 Skill/执行策略/Agent 配置候选，经既有扩展准备生成可评测版本；代码类输出可审查补丁，不自行激活或修改发布权限。
- [ ] 候选生成者只读取获准开发/验证材料与汇总，不读取保留答案、评分内部状态，也不能改强制策略、验收门槛或自身授权。
- [ ] 候选及来源引用以 EvolutionStore 原子登记，Propose 重复返回原对象，提交不明核对原操作，内容变化形成新精确版本。
- [ ] 端侧资料及派生候选继承位置、用途、保留和删除限制，普通授权内记忆更新仍沿 Memory 生命周期，不强迫进入发布评测。
- [ ] 演示一个实际可评测候选及一个越权/来源不可用拒绝，生成成功不声称已改善或已具发布资格。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
