# 64: 替换独立 API Adapter

**What to build:** 第二种外部接口形态通过独立 Adapter 完成相同代表能力，以共同状态和故障套件验证替换。

**Blocked by:** 11：恢复异步与未知效果调用；50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C4、C6、C7；A2

**规范依据:** 执行接口、资源控制与故障验证；能力里程碑与实施依赖。共享实施及报告约束见本工作包规格说明。

- [ ] 提供第二种外部接口形态不同的有状态模拟后端，用独立 Adapter 映射到与默认实现相同代表性能力；实际改变并核对业务状态。
- [ ] 两个实现复用 Schema、资源前提、重复操作、取消和效果核对共同套件，分别声明幂等、句柄及停止差异。
- [ ] 通过外部生效后丢回包、异步句柄不可核对、过期幂等及权限拒绝验证，不用本地去重补造外部 exactly-once。
- [ ] 新 Adapter 保持当前授权、秘密引用、数据位置和资源控制，已固定操作不随版本切换改写。
- [ ] 第二实现只需覆盖代表契约，不重复全部千级目录充数；报告不同接口形态与独立实现证据，不以实例数当替换。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
