# 02: 初始化本地身份、策略与授权

**What to build:** 从本地管理入口建立身份和有限持续授权，持久处理管理操作与接纳窗口，拒绝越权、重复变更和过期首次提交。

**Category:** enhancement

**能力映射:** C5、C7；A4

**规范依据:** 身份、授权与用户控制；授权生命周期、凭证与控制接口；恢复状态与故障检查表。共享实施及报告约束见本工作包规格说明。

- [x] 单机无独立身份服务即可经受信管理入口建立管理员、命名空间、资源策略及有限持续授权；没有授权的入口默认拒绝，自报用户或 Agent 名称不能建立身份。
- [x] 策略表达受信资源选择器、动作、用途、位置、期限与管理范围；未知必需限制、无法证明范围包含、超限求值不得产生允许结果。

- [x] 操作 SDK 与接纳处理实现受信作用域及接纳窗口绑定；关闭水位先于明细清理落盘，重启或重连不能使旧操作重新首次接纳。

## Agent Brief

**Category:** enhancement

**Summary:** 建立可单机初始化的本地身份、策略和有限持续授权，通过真实 SQLite 原子提交及接纳窗口管理，提供可重复验证的准入、去重与恢复闭环。

**Current behavior:**
前置 01 已完成 SDK 契约样例及其限定范围的验收。现有 SDK、协议校验、Schema 注册集、内存夹具和验证报告可以作为扩展基础，但没有身份认证、策略判定、SQLite 授权存储或耐久接纳窗口实现。分诊已按认证、授权、策略、授权记录及接纳窗口等概念检查源码、协议和依赖，未发现对应实现或相关拒绝记录。维护者已确认 enhancement 分类、保持 ready-for-agent，并同意下述执行边界。

**Desired behavior:**
受信本地 CLI 或嵌入宿主可以在无外部身份服务的条件下初始化管理员、命名空间和资源管理范围，登记受信主体，管理策略及本地有限持续授权。业务入口根据真实认证上下文和当前策略作出判定，自报名称、猜中操作标识或持有旧回执均不能建立身份或取得权限。

管理变更经过“认证及当前授权检查 → 原操作语义核对与去重 → 新操作版本比较 → 原子提交”。授权变更及回执保存在真实 SQLite 文件中，提交后回包丢失能够按原操作核对；操作身份绑定受信作用域及接纳窗口，窗口关闭或明细清理不能使旧操作重新首次接纳。持续授权仅允许有效期和范围内的新操作，不要求每次重复确认，也不表示无限有效。

本票使用可导入的 Go 接口及本地参考入口，不依赖外部基础设施。现有契约夹具保留其证据边界；新增授权管理消息与真实持久化回执不得假冒夹具结果，也不得将管理提交完成解释为任务执行完成。

**Key interfaces:**
- 本地初始化与身份登记入口：由受信安装/宿主路径建立初始管理身份；正常业务请求不得调用初始化来覆盖已有身份、策略或管理权限。
- `IdentityVerifier.Authenticate`：从受信本地认证材料或宿主绑定得到认证上下文，保留主体、命名空间及适用代理关系；普通业务字段不能替换此上下文。
- `Authorizer.Evaluate`：消费认证上下文、受信资源描述、动作、用途、位置、时间及策略/授权状态，返回明确判定与必要限制；不隐式执行管理变更或消费单次许可。
- 本地策略及授权管理入口：提供本票所需的策略更新/查询、有限持续授权建立/查询和管理操作核对，限定签发及管理权限；普通执行授权不隐含签发权。后续 `GrantAuthority` 扩展跨节点材料、派生及撤销能力。
- `AuthorizationStore`：以消费方定义的加载、原子提交及提交核对接口封装策略、授权、管理操作、回执和必要变更记录；SQLite 连接、事务和驱动错误不进入领域接口。只落实本票必需方法，未实现的同步/订阅能力不能伪装成功。
- 操作身份与接纳端口：生成并核验绑定受理权威作用域、窗口世代及随机部分的不透明 operation_id，管理持久关闭水位和受控清理；不能信任请求自报窗口或通过替换窗口复活原身份。
- 验证 profile：沿用已有具名用例和报告入口，分别记录契约、实际准入及真实 SQLite 恢复证据，保留预期、实际、依赖版本、环境、命令和限制。

**Acceptance criteria:**
- [x] 可在单机受信环境初始化管理员、命名空间及资源管理范围，关闭后重开仍能读取；重复或并发初始化不会静默覆盖既有信任和管理权限，普通业务入口不能借初始化提权。
- [x] 受信主体可完成获准管理操作；未认证调用、自报用户/Agent、未获授权的跨主体或跨命名空间调用被拒绝，且不得泄露已有操作回执、授权记录或隐藏资源信息。
- [x] 资源选择器沿既定参考语言表达精确引用、枚举集合及受信登记的资源树范围，结合动作、用途、位置、期限和管理权限判定。硬性禁止不被其他允许条目覆盖；未知必需条件、请求自报资源归属、无法证明包含关系及超出明确求值预算均不能产生允许结果。
- [x] 本地有限持续授权支持范围内多次独立操作；到期、当前策略已禁止或其他当前资格失效时拒绝新受限操作。签发权限与普通执行权限分开，授权和必需期限配置缺失、非法或无限时拒绝启用相关功能；不声称已支持单次许可消费或配额预留。
- [x] 管理变更、对应回执及必要变更记录在同一 SQLite 原子边界提交。并发使用同一预期修订的不同操作不会丢失更新；原操作成功后使用原请求重试，即使当前修订已推进，仍在当前权限允许时返回原结果，不误报新操作版本冲突。
- [x] 同命名空间的原 operation_id 在重试与结果核对中保持，主体变化不另建一个可重复执行的同名身份；当前权限检查先于回执披露，相同身份配不同操作类型或语义载荷拒绝。新业务变更使用新操作身份。
- [x] 操作身份绑定受信的受理作用域及窗口，跨作用域或篡改窗口拒绝；有效窗口内首次接纳的操作可持久核对，窗口关闭后已接纳操作仍按当前权限及记录保留规则核对，无既有记录的旧窗口操作明确返回过期或不再接纳。
- [x] 关闭水位先于明细清理落盘；仅在满足记录保留及恢复义务后清理。用真实 SQLite 文件和进程重启验证关闭后、清理中断后及明细已清理后，旧操作均不能重新首次接纳，重建调用上下文也不重置关闭水位。
- [x] 用真实文件库验证提交前中断无部分变更、提交成功但回包丢失可核对原结果、重试不重复变更。通过公开管理及核对接口观察持久状态，不能仅以日志、内存替身或断言被调用次数作为恢复证据。
- [x] 时间来源可替换并可测试；受信本地权威重启后重新核验本地策略与时间，无需外部云服务。检测到时间不可信时停止依赖期限的新准入，不用持久化剩余时长或请求时间戳推导授权仍有效。
- [x] 本票所需固定管理消息和错误沿既定 Protobuf 来源扩展，SDK 与真实处理入口使用一致语义，保持 01 契约样例回归通过；不以现有仅含结构校验的入口或夹具去重代替身份验证、授权与耐久提交。
- [x] 新增可重复验证 profile，覆盖允许操作、跨主体拒绝、持续授权复用、到期、身份冲突、版本竞争、回包丢失与清理恢复，记录实际 SQLite 驱动/运行版本及锁定依赖。必需项未实现、未运行、不支持或失败不汇总为通过。
- [x] 对跨节点签发/验证、委派、单次消费、任务控制、浏览器登录等尚未实现的请求明确报告不支持，不降级成宽泛本地持续授权，也不提前声明远端应用、真实任务执行或外部副作用保证。

**Out of scope:**
- ES256/JWS 跨节点材料、完整派生/祖先撤销与配额预留生命周期，交由后续授权票扩展；本票仍须落实当前本地身份、策略及授权状态的准入约束。
- 节点加入、mTLS、真实 gRPC/WebSocket 服务、浏览器会话、登录码及 UI 授权等待流程；受信本地入口不宣称提供这些认证绑定。
- 单次许可在执行或记忆处理端的原子消费、任务预算、暂停/取消/接管及在途动作控制。
- 第三方凭证加密存储、密钥轮换、外部身份平台与第二耐久后端；保留相应接口替换边界，不预建实现。
- 完整任务运行时、真实模型/业务 API 调用或全系统安全资格；本票证据仅覆盖已执行的本地身份与授权能力。
