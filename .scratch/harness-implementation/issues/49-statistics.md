# 49: 比较候选并验证统计适用性

**What to build:** 实现固定权重的配对族重采样与仿真校验；不满足假设返回 INFERENCE_UNAVAILABLE，质量、成本和延迟分别判断。

**Blocked by:** 42：运行冻结计划并生成评测报告

**Status:** ready-for-agent

**能力映射:** C8、C9

**规范依据:** 评测接口、参考基准与发布判定；能力评测统计与版本比较研究。共享实施及报告约束见本工作包规格说明。

- [ ] 从冻结计划及基线/候选逐例配对事实计算固定目录宏/微平均、每 API 分母和配对四格结果；点分门槛与统计改善分别判定。
- [ ] 适用条件成立时按 API 分层、意图/状态族整体 paired bootstrap，保持族内变体、API 权重及配对，10000 次重采样并保存种子和双侧 95% 百分位区间。
- [ ] 以已声明数据生成机制仿真和边界数据验证算法，检查跨 API 来源相关、小样本、高成功率和退化结果；不适用标 INFERENCE_UNAVAILABLE，不换逐行二项区间。
- [ ] 主改善指标固定单步首次正确率，差值区间下界大于 0 才支持改善；单步/多步成功点分不得低于基线，不将其表述为统计非劣。
- [ ] 平均 token 与端到端 p95 延迟分别≤基线 110%，同时满足硬预算；零/缺失基线只用事先声明的绝对限额，缺限额返回不可判定。
- [ ] 不同评分器、预算或环境变化拒绝伪配对比较；固定得分达标不自动声称泛化或改善，保留计划及方法版本和局限。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
