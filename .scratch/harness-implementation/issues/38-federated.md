# 38: 检索端侧数据并只返回许可投影

**What to build:** 查询在获准数据位置执行，有界合并可见结果；严格留端内容及存在性不泄露，离线与零命中区分。

**Blocked by:** 27：同步授权并落实有限离线运行；19：删除记忆并使派生内容失效

**Status:** ready-for-agent

**能力映射:** C2、C5、C7；A3、A4

**规范依据:** 端云记忆驻留与联合检索；记忆数据契约与生命周期。共享实施及报告约束见本工作包规格说明。

- [ ] 一个端侧、另一模拟端与模拟云使用独立数据库/内容路径，经实际协议向获准数据位置执行有界查询并合并允许结果。
- [ ] 路由先判断查询文本可披露范围，节点再检查数据权限；默认目录不登记严格私有记录的标题、关键词、计数或命中存在性。
- [ ] 严格留端结果供本地获准处理，有限披露只返回指定字段/计算结果/受控引用；云端 Get 不能绕过投影读取正文，接收权不等于保存权。
- [ ] 分别表达可见范围零命中、部分不可达、预算不足和新鲜度，不暴露隐藏范围；不同后端分数不直接当同一置信尺度。
- [ ] 缓存、重排、Embedding、模型输入、Outbox 和工具参数都检查位置；无合适处理能力等待，不能为改善召回上传原文。
- [ ] 以实际出口检查证明云端无禁止正文及派生载荷，策略收紧停止新外发并传播失效；不宣称消除所有时序侧信道。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
