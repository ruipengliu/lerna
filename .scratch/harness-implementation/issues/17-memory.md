- Query 先在获准范围内处理和筛选，再组织结果、数量及覆盖状态。文本、类型及元数据查询有输入/扫描/结果/正文大小/时间硬上限；精确 Get 不以最新版本替代指定历史。零命中、获准范围部分不可用和预算不足分别表达；隐藏记录不影响外部可见标题、计数或错误。
