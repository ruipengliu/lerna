# 44: 构建多步与正确不执行基准

**What to build:** 核验至少 max(2000,K) 个多步任务及 1000 个边界任务，满足逐 API 覆盖、路径长度与四类边界要求。

**Blocked by:** 43：构建并核验千级单步基准

**Status:** ready-for-agent

**能力映射:** C1、C4、C7、C8

**规范依据:** 评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 生成并独立核验至少 max(2000,K) 个多步任务，每项 API 至少出现在 4 个任务，每任务至少 2 项 API、正确路径 4–6 个业务动作，全部条件同时满足。
- [ ] 每任务真值允许多条语义等价路径，核验最终业务状态及全程禁止副作用；一个任务只计一次，不复制步骤扩大成功分母。
- [ ] 另生成至少 1000 个正确不执行任务，无匹配、缺必要信息、权限不足、约束冲突各至少 250，预定澄清/等待/拒绝。
- [ ] 正确不执行独立计分，禁止动作硬失败；不能并入可执行任务抬分，多步成功也不被单步分数抵消。
- [ ] 数据用途按来源族隔离，固定版本及审核；覆盖检查器报告每 API 出现次数、路径长度、边界分类与缺口。
- [ ] 多步预算及正确不执行单步预算写入不可变计划；以独立判定夹具验证错误路径、错写后补救和缺失效果不会计成功。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
