# 76: 因证据失效撤销后续发布资格

**What to build:** 源数据删除、用途收紧或证据过期后阻止新晋级，按产物依赖处置已激活内容，保留获准历史事实。

**Blocked by:** 75：检测退化并停止或回滚候选

**Status:** ready-for-agent

**能力映射:** C9、C8、C2、C7

**规范依据:** 运行观测、能力评测与受控自进化；评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 评测计划、样本、报告和候选保留受控来源/派生关联，来源删除、用途收紧、授权失效或到期触发可恢复失效通知。
- [ ] 已缺少关键证据的报告不支持新晋级或发布，待执行 Promote 重新检查精确候选及依据，不能因旧资格缓存继续激活。
- [ ] 当前激活产物按实际内容依赖和风险停止/下架或重建，不能将全部源删除简单等同代码回滚，也不能为继续发布恢复禁止正文。
- [ ] 最小获准历史保留原评测/发布曾发生事实，正文清理和证据不可复核状态分别报告，统计摘要仍检查披露及留存。
- [ ] 通知重发、跨 Store 交接不明、发布与删除竞争、离线节点恢复和旧备份均按原身份及水位核对，不重新制造一次发布。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
