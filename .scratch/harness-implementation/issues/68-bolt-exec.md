# 68: 在 bbolt 上执行与接管资源

**What to build:** 用独立持久 ExecutionStore 跑实际调用、单次消费、未知效果和资源控制，复用相同故障断言。

**Blocked by:** 67：在 bbolt 上运行并恢复任务；12：接管并恢复共享资源

**Status:** ready-for-agent

**能力映射:** C4、C5、C7；A2

**规范依据:** 执行接口、资源控制与故障验证；专项验收、持久化替换与实施交接。共享实施及报告约束见本工作包规格说明。

- [ ] 在 bbolt ExecutionStore 上经正式入口完成代表性 API、异步核对及资源接管，使用真实独立模拟状态证明执行和效果。
- [ ] 接纳、单次许可消费、启动可能发送状态、资源控制版本及工作/报告 Outbox 保持各自规定的原子边界。
- [ ] 按相同操作及内部提交核对重复和未知结果，旧 Worker、旧控制请求及过期接纳窗口拒绝，不能借后端替换重置消费。
- [ ] 复用 SQLite 的执行/取消/接管故障套件，在外部生效后、报告持久化前后和同步错误处重启验证无重复变更。
- [ ] 固定后端同步与有界事务配置，停止不可靠新变更后保留恢复事实；分别报告持久能力与目标系统的幂等/取消边界。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
