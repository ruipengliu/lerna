# 01: 运行 SDK 契约验证样例

**What to build:** 用 Go SDK 完成任务消息往返、动态 Schema 校验和正反例报告，锁定生成工具及依赖，后续票扩充同一入口。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

**Implementation:** completed

**能力映射:** C1、C5、C6、C8；A1、A4

**规范依据:** 内部契约与外部协议映射；原生接口与消息目录；标识模型简化评估。共享实施及报告约束见本工作包规格说明。

- [x] 贡献者从可导入 Go SDK 发出样例任务请求，经明确标注的契约夹具取得响应并运行正反例断言；报告区分契约样例与真实任务运行。
- [x] 固定消息以 Protobuf 为唯一结构来源；动态 JSON 使用已登记的 JSON Schema 2020-12 资源集，拒绝重复键、非法 presence/null、精度越界整数、未知必需类型与不受控远程引用。
- [x] 操作沿用 operation_id，消息关联沿用 message_id/reply_to，内部 change_id 不进入公开任意写库接口；给出原消息重发、同操作新消息和新业务操作的可执行区别。
- [x] 固定已确认规范目标、生成器、Schema 验证器和实际 Go 补丁版本，至少满足 Go 1.25.0；生成和编译可复现，供应商及存储类型不进入领域接口。
- [x] 验证入口可接纳后续票的能力 profile、输入输出及错误/权限/恢复夹具，输出未实现、未运行、通过、失败和不支持，不能将生成成功当作互操作成功。
- [x] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。

**Key interfaces:**
- 可导入的 Go SDK：提供样例任务请求、响应和调用入口，消费方不依赖具体模型供应商或存储实现；契约夹具身份在样例及报告中可见。
- 固定消息与 Envelope：由 Protobuf 唯一定义结构，使用 message_id/reply_to 关联消息，operation_id 表达逻辑变更意图；对外不暴露基于 change_id 的任意存储写入接口。
- 动态载荷与 Schema 注册集：以 schema_id、schema_version 和内容摘要绑定 UTF-8 JSON 载荷，按 JSON Schema 2020-12 及既定跨语言约定验证，不在调用期间任意解析远程引用。
- 验证入口与报告：接纳具名能力 profile、输入、预期输出或拒绝条件；后续可加入错误、权限和恢复夹具。报告保留用例结果及运行证据，明确表达未实现、未运行、通过、失败和不支持。

**Acceptance criteria:**
- [x] 独立消费样例可导入 Go SDK，完成任务请求与响应的实际 Protobuf 编解码往返；响应有自身 message_id，reply_to 正确指向请求。夹具可重复运行且明确标记为契约样例。
- [x] 固定消息和信封以 Protobuf 为唯一结构来源，必要字段显式区分 presence；动态载荷使用已登记且版本、摘要匹配的 Schema 资源集，不维护第二份等价固定消息 Schema。
- [x] 正反例覆盖合法载荷、重复 JSON 键、缺失与 null 的区别、非法字段组合、精度越界整数、未知必需类型以及未登记或不受控的远程引用；按 Schema 约定验证精度敏感整数的十进制字符串表示。每项明确预期接受或拒绝，预期拒绝被正确观察到才算该负例通过。
- [x] 可执行用例区分原消息重发（消息与操作身份均保留）、同一操作的新消息（新 message_id、原 operation_id）和新业务操作（新 operation_id）；相同操作身份携带不同语义载荷被夹具判为冲突。此验证不宣称具有持久化去重或外部副作用 exactly-once 保证。
- [x] 固定适用的已确认规范目标、生成工具、Schema 验证器、实际 Go 补丁版本及依赖；Go 不低于 1.25.0。按记录的方法可重现生成和编译，供应商和存储具体类型不进入领域接口。
