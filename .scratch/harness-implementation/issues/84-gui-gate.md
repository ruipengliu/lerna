**Blocked by:** 46：构建 GUI 两种观察模式基准；48：恢复、取消和重新判读评测；62：替换 Brain 策略与 Model Adapter

- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
