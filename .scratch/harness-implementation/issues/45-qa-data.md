# 45: 构建联网问答证据与判定集

**What to build:** 形成固定 400 例和实际联网 120 例的四类材料，固化事实、引用支持/覆盖标准与独立争议裁决流程。

**Blocked by:** 21：获取内容并交付可核对证据

**Status:** ready-for-agent

**能力映射:** C3、C8；V1

**规范依据:** 专项验收、持久化替换与实施交接；评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 固定证据 400 例、实际联网 120 例，两组各均分可回答、证据不足、来源冲突、获取失败四类；固定材料带版本快照，联网材料记录实际获取时间及获准证据。
- [ ] 每例独立定义完整答案核对表、预期关键事实及适用引用，不能仅评分模型主动写出的容易事实；遗漏必要事实不能提高覆盖率。
- [ ] 引用支持以需支撑的已答关键事实为分母，覆盖以预期需依据的事实为分母；逐例保存分子分母，各组/类别对适用样本等权，无适用项不填 100%。
- [ ] 开放答案有独立复核与争议裁决流程，辅助模型不独自放行；未裁决或必需证据缺失明确不完整。
- [ ] 真实联网获取失败可按计划注入拒绝/超时并标记，不能全用离线桩；资料变化依据实际采集时间判读，不事后换类别。
- [ ] 冻结每任务模型 8 次/token 131072、新操作 16/辅助查询 64、固定 180 秒/联网 300 秒及共同纠错/并发规则；维护开发/验证/保留来源族分离。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
