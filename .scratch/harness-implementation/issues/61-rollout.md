# 61: 逐节点应用扩展版本

**What to build:** 端云分别准备和激活，展示实际应用与待联系状态；部分升级及重连不改绑在途工作或扩大权限。

**Blocked by:** 51：升级、停用和回滚固定版本扩展；27：同步授权并落实有限离线运行

**Status:** ready-for-agent

**能力映射:** C6、C5、C7；A3、A4

**规范依据:** 扩展清单、运行器与激活恢复；端云任务所有权与恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 管理者按精确锁定结果向多个端/云节点准备和激活扩展，逐节点返回已准备、已激活、失败或待联系，不提供虚假全局原子升级。
- [ ] 激活前复核信任、权限、运行器、位置和依赖，节点本地绑定与 Outbox 原子提交，投影应用当前修订前不接新工作。
- [ ] 离线节点只在原版本仍获准且资格有效时继续；重连核对原管理操作及实际修订，不因为管理指针改变就认为已升级。
- [ ] 已固定决策和调用保留旧版本，跨节点协作不兼容明确等待/拒绝；停用、回滚不清除旧操作及消费。
- [ ] 以多进程真实通道验证部分准备、激活回执丢失、节点重启、权限中途变化及迟到旧消息，呈现管理意图与节点实际生效差别。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
