# 56: 通过 MCP stdio 调用工具与资源

**What to build:** 出站适配固定目标版本并关闭旧握手回退；持久关联结果、核对和取消，不将工具完成包装误判为成功。

**Blocked by:** 50：准备并激活受信能力插件；11：恢复异步与未知效果调用；15：绑定目标使用加密凭证

**Status:** ready-for-agent

**能力映射:** C4、C6、C7

**规范依据:** 内部契约与外部协议映射；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 固定 MCP 目标 2026-07-28 与 Go SDK v1.7.0/已确认提交，stdio 客户端连接独立工具/资源对端并映射到受控 Capability Catalog 和执行入口。
- [ ] 仅协商目标版本，在业务调用前验证结果，并定向关闭发现失败后的旧握手回退；锁定补丁及规范摘要，不只检查最终版本。
- [ ] 工具结果包装、业务失败、执行效果和资源内容分别解释；远端缺少幂等/核对能力时明确限制，返回 completed 不自动等同成功。
- [ ] 本地原操作与远端请求/目标身份关联持久化，取消是独立控制，连接断开不伪造取消或未执行，SDK 不隐藏副作用重试。
- [ ] stdio 启动明确受信环境及所需凭证使用，长期秘密不进入 Brain 或普通扩展参数；独立进程本身不声称强隔离。
- [ ] 覆盖发现、资源读取、调用失败包装、版本拒绝、回包丢失及取消不支持，独立夹具不只与本 Adapter 自连；Tasks 首期关闭。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
