## Agent Brief

**Category:** enhancement

**Summary:** 基于现有有限 Worker、授权与受控内容服务，建立 Brain.Decide / Model.Generate 分离的问答切片，在持久预算内生成完整结构化结果，并由 Core 校验、核对和持久发布。

**Current behavior:**
已有任务接纳、Worker 领取与有限重试、控制意图和结果提交核对。生成层尚无独立 Model Interface，现有脚本结果不构成真实模型问答；任务步数限制不等于模型 token、请求次数或未知用量预算。07 已提供精确内容引用、位置/用途限制与正文生命周期，本票必须通过受控入口消费和保存内容，不能直接读取其数据库或文件目录。

**Desired behavior:**

Brain.Decide 负责组织当前决策输入、调用符合条件的 Model、解析并校验完整输出，返回有限结构化提案。Model.Generate 隐藏供应商协议，显式声明模态、上下文容量、结构化输出方式、流式支持和实际处理位置。模型输出不是执行指令；本票只接受其限定的答案提案，不允许模型私有工具循环执行动作、写记忆、创建子任务或更改政策。

模型选择先核验必需能力、输入模态和允许处理位置，再选择已配置实现。请求中的位置声明不能替代受信 Adapter 配置；发送前检查来源对该处理位置的许可。没有合适模型时明确能力不足，不能为继续工作隐式上云、改模态或放宽来源限制。供应商模型名、端点和凭证由受信配置注入，凭证不进入模型输入、普通协议、日志或错误正文；不要求特定供应商或大型本地模型作为默认安装依赖。

内核在任务状态中保存有限的生成预算，包括请求次数、输入/输出 token 上界、生成/修复次数、并发和期限。每轮生成工作先在本地原子边界预留额度并记录关联，再以该次提交后的任务版本作为决策基线；模型调用在事务外进行。一次 Decide 的格式修复和配置回退只能使用已预留的有限额度，每次实际请求分别记录，Adapter 不得隐藏重试。沿任务与既有工作身份定位生成尝试，不为每个 token 或片段新增全局业务 ID。

用量完成后进行幂等结算：已核实实际消耗与仍未知的占用分开表达；只有可证明不再消费的未用份额才可释放。超时、取消请求、进程崩溃和供应商没有返回用量均不等于零消耗；未核清部分保留占用。迟到用量可以结算原尝试，但不能借此接纳过期提案。若 Adapter 无法提供可执行的保守 token 上界或可验证配额机制，则明确不支持该硬限制配置，不能把字符估计或金额估计当成保证。所有预算边界须在参考配置及报告中显式给出。

本票提供简单问答所需的最小上下文组装与来源验证接口：固定目标、必要约束、已知事实和精确内容修订，限定输入大小，并为输出及协议包装预留容量。可选信息可按明确规则裁剪，目标和必需信息放不下时拒绝或等待，不默默丢弃约束。受控内容不自动保存为长期记忆。来源修订、用途和处理位置在发送前、模型返回后及发布前复核；受限正文、派生答案与诊断数据都遵守适用存储和披露限制。

完整模型输出须有明确结束状态，并通过本票固定 Schema 和语义校验。截断、格式错误、不支持、输入失效、取消、预算不足及暂不可用分别表达。完整性校验不能靠模型声称已完成；来源引用必须属于获准且实际交付的输入。需要修复时有明确次数上限且计入额度，禁止无限修复。流式能力可声明不支持；支持时临时增量不构成正式答案、任务完成或可执行参数。默认不启用用户草稿披露。

Core 复用现有 owner/epoch、Worker 代次、任务版本、暂停/取消及期限检查，决定是否准入答案。内容需保存时经 07 生成受控答案引用，并携带适用来源限制；普通任务状态只保留允许的结果引用及最小事实，不借字符串结果字段长期保存禁止留存的正文。内容准备完成与任务结果发布不是跨存储原子事件：只在引用已确认且当前可用、准入条件满足时提交正式结果；失败或旧提案产生的暂存/未采用产物按留存规则处置。

“发布”在本票指正式结果经 Core 持久准入并可由获准 SDK 查询，不代表 UI 已呈现或用户已看到。提交不明先核对原结果提交，不重新问模型或生成新发布身份。模型结果无法恢复时，只能在剩余预算、当前权限和任务资格允许时重新生成；供应商请求引用仅用于诊断，不能充当业务去重或恢复权威。恢复依赖持久任务事实、受控引用和用量状态，不依赖隐藏会话或内部思维链。

**Key interfaces:**
- Brain.Decide：输入预留后的任务版本、目标/约束、受控上下文、来源清单和有限生成额度；返回完整答案提案或明确领域失败。保留已有脚本 Brain 契约及控制行为。
- Model.Generate 与能力声明：供应商无关的受控输入块、模态、输出 Schema、处理位置、生成限制及取消上下文；输出完整内容、结束原因、已知/未知用量和可披露诊断引用。参考 Adapter 与核心按接口依赖。
- 生成预算及工作提交接口：预留、启动、结算和原尝试核对语义随任务持久化；幂等处理重放、并发竞争和迟到结算，不新增必需预算服务。
- 最小上下文组装/验证接口：消费精确内容引用及当前来源约束，表达必需信息不足、来源不可用或失效；完整个性化 ContextAssembler 留给后续票。
- 结果准入与 SDK 查询：校验提案和任务资格，保存受控答案引用及完成事实，提交不明恢复原结果；查询仍需当前披露权限，正文清理后不得从旧回执复现。
- 配置和验证入口：模型端点/模型名/凭证来源、实际位置及能力、上下文容量、请求和 token 上限、输出大小、修复/回退次数、并发与 I/O/生成期限均显式有界。脚本契约 profile 与真实模型 profile 分开。

**Acceptance criteria:**
- [x] 通过可运行 SDK/CLI 路径接纳简单问答任务，由模型驱动 Brain 产生完整提案，经 Core 正式发布并可查询；至少一个真实 Model Adapter 有实际调用证据，脚本结果不计真实模型验收。
- [x] Brain 与 Model 的接口独立，核心不依赖供应商对象；能力声明实际约束模态、结构化输出、上下文容量、流式支持和处理位置，错误或缺失必需配置拒绝启用。
- [x] 生成前检查实际处理位置与来源许可，禁止离端内容不会进入远程请求、诊断日志或回退模型；无满足限制的 Adapter 时明确不足，拒绝路径证明未调用模型。
- [x] 模型请求前持久预留请求次数与可执行 token 上界，生成工作和额度关联可恢复，Brain 输入使用预留后的版本；预留失败、提交未知未核实或额度不足均不开始请求。
- [x] 格式修复、回退和失败请求分别计入有限额度；禁止隐藏重试，超限停止新增生成。并发预留、重放及重启不增加总可用余额，已用加未知占用加可用份额保持声明的不变量。
- [x] 已知用量只结算一次；未知用量保持占用，不因超时、取消或重启归零。迟到或重复用量更新只作用于原尝试，不释放仍可能使用的份额，不使旧答案重新获准发布。
- [x] 不能提供可执行上界的 Adapter 明确拒绝硬限配置；输入/输出及协议开销纳入容量核对，未知/异常用量不被伪装成零或正常结算。金额估算与 token 硬限分别描述。
- [x] 必需目标、约束和已知事实在有界输入中保留，超限时明确拒绝；精确来源修订可追溯，引用缺失、被删除或权限收紧不会被当作空内容继续生成。

- [x] 正式答案通过受控内容保存并继承适用来源限制，任务状态只持久允许的结果元数据；拒绝答案保存/披露时无虚假发布，结果正文不会进入普通错误、日志或旧回执。
