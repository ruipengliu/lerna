# 40: 按任务和操作查询运行事实

**What to build:** 从持久来源形成可重建诊断视图，按身份查询关联事实和用量；重复导出不重计，采样与缺口可见。

**Blocked by:** 11：恢复异步与未知效果调用

**Status:** ready-for-agent

**能力映射:** C8、C5、C7；A4

**规范依据:** 运行观测、能力评测与受控自进化；评测接口、参考基准与发布判定。共享实施及报告约束见本工作包规格说明。

- [ ] 任务、执行及授权持久事实通过受控 Outbox/信号进入 Observation.Ingest，可按 task_ref、operation_id 和因果引用查询关联进展。
- [ ] 来源绑定实际认证节点/模块与局部变更位置，不信载荷自报来源；批次重发不重复计数或重写业务权威。
- [ ] SQLite 投影可从获准持久事实重建，Query 有界并绑定授权视图/修订；GetCoverage 分开报告接纳、应用、采样与缺口。
- [ ] 诊断输出默认最小元数据，正文和秘密不得随错误或调试自动进入；耗时、已知用量、未知消耗分别表达。
- [ ] 导出失败不把已确认业务成功改为失败；原模块持久化失败仍禁止不可靠新动作，缺少观测不等于没有动作。
- [ ] 用提交重复、投影中断、权限变化、慢消费和采样丢失验证查询结果及范围，保留后续逐模块接入入口。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
