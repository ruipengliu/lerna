# 47: 构建个性化成对对照基准

**What to build:** 形成 400 对任务与两臂独立重置，核验适用/边界分类、端侧比例及严格留端和有限披露覆盖。

**Blocked by:** 38：检索端侧数据并只返回许可投影

**Status:** ready-for-agent

**能力映射:** C2、C7、C8

**规范依据:** 专项验收、持久化替换与实施交接；端云记忆驻留与联合检索。共享实施及报告约束见本工作包规格说明。

- [ ] 生成并独立核验 400 对任务：200 对适用个性化中回答/行动各 100，200 对边界中不适用、过期/删除、冲突、禁止披露各 50。
- [ ] 一对包含同目标/环境下的获准个性化版本及预定对照，每臂独立重置业务状态与可变记忆；一对只计一个结果，不能当 800 独立样本。
- [ ] 每臂有允许的正确输出/动作，适用任务必须使上下文差异引发可观察选择，不能只检查调用 Memory；边界预定默认、澄清或拒绝。
- [ ] 每类至少一半采用端侧来源；至少 40 对严格留端检索/使用、至少 40 对获准派生结果回传，分别记录覆盖。
- [ ] 检查计划覆盖云存储、模型请求、日志/评测及派生出口；缺获准处理位置应等待，不能为对照便利上传原文。
- [ ] 冻结每臂模型 8 次/token 131072、新操作 8/辅助查询 64、300 秒和共同限制，来源族用途隔离并记录逐对真值及审核。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
