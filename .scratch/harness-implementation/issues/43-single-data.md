# 43: 构建并核验千级单步基准

**What to build:** 为 K≥1001 的完整目录生成每 API 20 例及独立真值，满足族和混淆覆盖；开发、验证、保留用途隔离。

**Blocked by:** 13：在千级目录中检索准确版本

**Status:** ready-for-agent

**能力映射:** C4、C6、C8

**规范依据:** 评测接口、参考基准与发布判定；工具执行与多模拟设备。共享实施及报告约束见本工作包规格说明。

- [ ] 交付可重复生成、冻结及核验工具与数据清单，固定 K≥1001 个独立业务 API；每 API 20 例、10 个意图/状态族各 2 个变体，至少 8 例有近义或参数依赖。
- [ ] 每例有独立核验的目标、初始业务状态、合法资源/参数和效果条件，可通过正式模拟 API 执行；不是只生成自然语言描述或空成功回包。
- [ ] 全部被测检索面对完整目录，不注入正确 API 或提前筛答案；别名、重复版本和部署实例不充数。
- [ ] 按意图来源/模板族划分开发、验证及保留用途，防止同族改写跨集合；冻结内容摘要及生成/审核记录，保留材料不向被测路径暴露。
- [ ] 校验逐 API 分母、族覆盖、重复和依赖关系并输出缺口；定义首次宏平均和同批任务成功宏平均，同时保留微平均及逐项统计。
- [ ] 公开夹具不继续称隐藏保留集；本票交付数据和判定基础，不用生成数量冒充真实模型质量或统计精度。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
