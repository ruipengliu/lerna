# 35: 通过图像完成模拟 GUI 动作

**What to build:** 独立图像/坐标 Driver 与视觉模型使用正式观察完成动作，判定器单独核对状态，模型不能读取隐藏结构树。

**Blocked by:** 34：通过结构树完成模拟 GUI 动作

**Status:** ready-for-agent

**能力映射:** C4、C6、C7；V2；A2

**规范依据:** 工具执行与多模拟设备；执行接口、资源控制与故障验证。共享实施及报告约束见本工作包规格说明。

- [ ] 提供独立图像/坐标 Driver，利用模拟 UI 生成的真实图像和声明视觉能力的模型完成观察—动作—再观察—效果核对。
- [ ] 模型只能取得图像模式公开内容及坐标系，不取得结构树、隐藏坐标答案或后端业务状态；判定器独立读取真值。
- [ ] 点击、滑动、替换/追加输入和返回沿共同动作契约，图像尺寸/方向、设备生命周期和前提变化有明确拒绝。
- [ ] 两种观察模式用可比较任务族验证且分别报告成功/失败；共享模拟业务状态不把两个 Driver 合并成同一实现的不同配置。
- [ ] 覆盖图像不可读、感知不足、弹窗布局改变、陈旧观察、取消与接管；私有截图无获准处理位置时等待，不自动远程发送。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
