# 81: 验收完整目录的单步 API 质量

**What to build:** 真实模型运行完整 20×K 样本，分别判定首次≥90%、任务成功≥95%，报告逐 API 分母、预算及错误副作用。

**Blocked by:** 48：恢复、取消和重新判读评测；43：构建并核验千级单步基准；62：替换 Brain 策略与 Model Adapter；64：替换独立 API Adapter；52：导入用户 Skill 并用于任务

**Status:** ready-for-agent

**能力映射:** C1、C4、C8；C7

**规范依据:** 评测接口、参考基准与发布判定；专项验收、持久化替换与实施交接。共享实施及报告约束见本工作包规格说明。

- [ ] 用冻结真实模型/Brain/Skill/目录配置对完整 K≥1001 API 运行每 API 20 例正式单步评测，共 20×K，K=1001 时为 20020；每例一次正式尝试。
- [ ] 逐 API 等权宏平均分别判定首次正确率≥90%、同批有限纠错任务成功率≥95%，同时报告微平均、逐项分母/成功数/错误和候选覆盖。
- [ ] 首次从完整目录检索开始，候选遗漏、未出提案或首份输出修复均计错；目标/版本/资源/参数都正确才算首次正确，错误副作用不能被最终结果抵消。
- [ ] 每任务纠错≤2、模型≤4/token≤65536、新操作≤3、辅助查询≤32、每操作补发≤2、120 秒；并发≤4 任务/模型请求，父子用量共享，预热和排队单列。
- [ ] 模型 token 无可执行上界或必需证据缺失阻止完整 profile 通过，估算/实际/费用分别报告；设施事故保留原分母，被测失败不能删例。
- [ ] 交付可复核 PASS/FAIL/INCOMPLETE 及证据，在未达标时记录原因并提出有界修复范围，不修改预算/目录/权重来通过；后续发布还须同候选完整报告。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
