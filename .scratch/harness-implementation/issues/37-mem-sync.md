# 37: 同步获准记忆并恢复离线修改

**What to build:** 单一 Memory Authority 管理正式修订，副本快照接增量并原子推进游标；冲突、删除、视图失效与离线意图可核对。

**Blocked by:** 27：同步授权并落实有限离线运行；19：删除记忆并使派生内容失效

**Status:** ready-for-agent

**能力映射:** C2、C5、C7；A3、A4

**规范依据:** 记忆数据契约与生命周期；端云记忆驻留与联合检索。共享实施及报告约束见本工作包规格说明。

- [ ] 两个独立节点经真实协议同步获准记忆视图，每集合单一 Memory Authority，端/云均可承担不同集合的权威。
- [ ] 一致分页快照绑定获准字段、策略修订和世代，增量从同一边界开始；副本应用及游标同事务持久后才报告已应用。
- [ ] 非权威离线修改只是稳定身份及基础修订的待提交意图，重连先查原操作、权限和版本，冲突不按设备时钟覆盖。
- [ ] 字段投影不能覆盖未披露完整记录，源正文引用不自动同步；权限收缩使旧视图失效并清理旧范围，放宽不自动全集上传。
- [ ] 删除传播分别显示权威、本地、副本和派生进度；游标过期重建视图并隔离本地草稿，旧世代不能复活删除内容。
- [ ] 注入应用/游标提交中断、回执丢失、竞争修订、断网删除、墓碑清理及旧备份恢复，验证无漏删、重复应用或假完成。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
