# 59: 向 A2A 外部 Agent 委派任务

**What to build:** 仅使用 HTTP+JSON，保存远端身份/句柄并处理查询取消；正确解析两种 JSON 媒体类型及结构化错误。

**Blocked by:** 28：委派子任务并收集结果；50：准备并激活受信能力插件；15：绑定目标使用加密凭证

**Status:** ready-for-agent

**能力映射:** C1、C5、C6、C7

**规范依据:** 原生接口与消息目录；扩展清单、运行器与激活恢复；决策准入、交互与协作恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 固定协议 1.0、规范文字 v1.0.1 与 a2a-go/v2 v2.5.0/已确认提交，仅注册 HTTP+JSON，禁用默认传输集合及隐式 JSON-RPC 优先。
- [ ] 注册受信外部 Agent 端点，父任务委派保留目标、预算和收缩授权；经受控凭证使用发起请求，不向 Agent 交付用户长期密钥。
- [ ] Message 与 Task 响应分开映射，远端身份、版本、句柄、保留期与本地提交关系持久保存；查询/取消能力按对端声明。
- [ ] 普通 JSON 支持 application/a2a+json 和兼容 application/json，在 SDK 解析前保留结构化错误及原始媒体信息，SSE 类型不得改写。
- [ ] 无幂等、句柄过期、取消失败及外部效果未知明确呈现，外部完成标签不直接决定父终态，流式/推送按已声明能力启用。
- [ ] 通过独立对端验证回包丢失、重复/迟到更新、媒体类型和版本失败；Agent Card 快照不能当远端二进制固定证明。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
