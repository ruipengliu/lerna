# 24: 跨进程执行并核对能力调用

**What to build:** 经真实 gRPC unary 与双向 Exchange 调用同侧独立执行进程；统一授权、取消、错误和结果未知语义。

**Blocked by:** 23：登记节点并验证双向 TLS 身份；11：恢复异步与未知效果调用

**Status:** ready-for-agent

**能力映射:** C4、C5、C6、C7；A2、A3、A4

**规范依据:** 原生接口与消息目录；内部契约与外部协议映射；执行接口、资源控制与故障验证。共享实施及报告约束见本工作包规格说明。

- [ ] 调用方与执行方在同侧不同进程运行，以 mTLS gRPC unary 完成受控能力调用/查询，Exchange 双向流推送进度与结果；禁止共享内存绕过实际链路。
- [ ] Negotiate 固定版本、必需能力、限制及配置引用，配置失效重新协商；身份校验和业务授权分别执行。
- [ ] 绑定映射相同领域请求/响应和错误确定性，gRPC status 不替代业务错误；已发送变更回包丢失按原操作核对，SDK 不盲目重试。
- [ ] 双向流发送、消费和缓冲有界，慢消费者及两端同时发送无死锁；流断开不自动取消持久任务。
- [ ] 共同用例比较进程内与 gRPC 的结果、权限拒绝、取消及未知效果，声明 transport 特有失败；生成成功或同进程假连接不计验证。
- [ ] 为后续接口提供具名绑定及可复用一致性入口，尚未实现的方法明确不支持，不暴露 Store 任意读写。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
