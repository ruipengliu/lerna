**Category:** enhancement

**Summary:** 为同侧独立进程提供受控能力调用的真实 mTLS gRPC unary 与双向 Exchange 绑定，保留既有执行、授权、取消和未知效果语义。

**Current behavior:**

已检查 `sdk.CapabilityClient`、`sdk.Transport`、`executionlocal.Binding`、`executionrouter.Router`、`CapabilityService` Proto 描述、执行恢复模块和节点 TLS Adapter。SDK 经 Protobuf 字节调用进程内绑定，已有 Invoke、GetInvocation、Reconcile、RequestCancel、GetCancel 及受控资源接口；`Exchange(context.Context, []byte)` 是本地请求响应入口，不是真实双向流。当前生成入口只生成 Protobuf 消息，依赖清单尚无 gRPC 运行库。未发现 gRPC 服务注册、Negotiate 或网络 Exchange 实现，也未发现既有拒绝记录。

11 已提供异步作业关联、有限核对、可信进度及取消恢复；23 已提供节点登记、mTLS、当前资格检查、签名授权绑定与原业务入口恢复。二者提供可复用基础，不替代本票的跨进程协议证据。23 记录过记忆回归中的 SQLite 锁失败，实施时按当前环境复核，仍失败则单独归因和报告，不将历史失败直接视为当前已通过。

**Desired behavior:**

调用方通过具名 RPC 访问独立执行进程；执行事实仍由已有领域服务持久化，Core 保持任务状态推进权。固定 bootstrap 协商版本、必需/可选能力和有限限制，后续请求引用绑定实际认证对端的配置。配置到期或服务重启后重新协商；业务操作身份和未决事实保持。

Exchange 提供经授权订阅的进度与结果交付，两方向可独立推进。临时进度可按声明合并，可靠结果及必要控制按既有持久化、回执与核对契约交付。流关闭、RPC 等待取消和业务取消分别表达；可能已发送的变更失去回包时，SDK 返回结果未知并保留原操作供查询或核对。

**Key interfaces:**

- `CapabilityService` 与 `sdk.CapabilityClient`：至少提供 Invoke、GetInvocation、Reconcile、RequestCancel、GetCancel 的具名 RPC；复用 `CapabilityRequest`、`CapabilityResponse` 和现有领域映射。实际启用的其他方法同样验收，未启用方法明确不支持；拒绝 RPC 方法名与载荷分支不匹配。
- `ConnectionService.Negotiate` / `Exchange`：补齐固定 Proto、生成绑定和 SDK 接入；声明支持的方法、消息类别、配置期限、消息尺寸、连接/流/订阅数量、队列和待确认窗口等有限约束。范围外能力不能协商为已支持。
- `nodetls.Endpoint.Authenticate` / `Presentation` 与 `GrantAuthority`：身份来自实际 TLS 对端，逐调用、执行准入和结果披露落实当前资格与权限；可信主机负责构造领域服务身份。请求中的节点名、用户或证书摘要仅能作为待验证声明。
- `NodeAuthority.RememberPresentation` / `LookupPresentation` 与 `Endpoint.RestorePresentation`：按需要复用可信入口恢复，保留原操作关联；从普通网络载荷上传证书不能取得恢复入口资格。
- `execution.Service`、`AsyncDriver` 和既有执行/异步验收 profile：复用持久事实、受控启动、独立取消、报告和核对能力；gRPC 对象留在 Adapter，SDK 继续依赖消费方传输接口。

**Acceptance criteria:**

- [x] 提供可运行调用方及执行方，以不同 PID、真实监听地址和 mTLS gRPC 完成能力接纳、实际动作与独立效果核对。双方使用各自受控持久状态；调用方不能通过直读执行方数据库或内存替代 RPC。记录进程与链路证据，同进程 bufconn、生成成功或固定成功桩不计跨进程验收。
- [x] Negotiate 成功后 unary 与 Exchange 使用同一有效配置；无共同版本、缺必需能力、非法或无限制值、未协商调用、跨主体使用配置、过期配置及服务重启后的旧配置均被明确拒绝。重新协商不扩大授权、不改变原操作身份。
- [x] 对错误目标节点、无证书、自报身份、跨命名空间、无代理资格及不匹配签名授权分别验证拒绝。既有连接和订阅中发生节点停用、证书过期或授权撤销后，新动作及后续披露被阻止；订阅成功不成为永久读取许可。
- [x] 共享用例经进程内与 gRPC 运行，比较领域结果、权限拒绝、原操作去重、载荷身份冲突、取消和未知效果。归一化传输尝试标识后比较业务事实；保持 operation_id，message_id/reply_to 关联正确，内部提交身份不公开。
