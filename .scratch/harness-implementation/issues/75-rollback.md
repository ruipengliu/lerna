# 75: 检测退化并停止或回滚候选

**What to build:** 违规立即阻止新路由，完整窗口失败触发处置；核对在途效果并复验旧版本兼容，证据不足不自动晋级。

**Blocked by:** 74：按阶段激活获准改进；12：接管并恢复共享资源

**Status:** ready-for-agent

**能力映射:** C9、C5、C6、C7

**规范依据:** 评测接口、参考基准与发布判定；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 确认禁止动作/披露、同操作重复写入或状态破坏时立即停止候选新路由，按实际运行控制处置在途任务和资源。
- [ ] 阶段完整窗口不达质量或成本/延迟门槛时停止扩大并请求回滚；仅样本不足或无真值转待评估，不伪称质量退化。
- [ ] 回滚复验目标资产当前信任、授权及数据状态兼容，不兼容则隔离等待，不能强行激活被撤销旧版本。
- [ ] 全面激活后仍监测至少 24 小时、1000 个可核对任务、最长 7 天；关键治理证据缺失阻止受影响执行，单纯样本不足不扩适用范围。
- [ ] 停止/回滚意图与逐节点实际应用持久保存，原操作重启核对；旧未知效果不被清理或因回滚重复执行。
- [ ] 验证阈值退化、证据缺失、节点失联、回滚不兼容和中断恢复；影子实验不得重复向真实共享资源发写操作。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
