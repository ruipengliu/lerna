# 69: 在 bbolt 上管理身份与授权

**What to build:** 运行授权、撤销、消费预留及凭证管理路径，验证固定快照和水位；失效后不凭缓存恢复新授权。

**Blocked by:** 67：在 bbolt 上运行并恢复任务；27：同步授权并落实有限离线运行；16：轮换密钥和凭证并恢复中断

**Status:** ready-for-agent

**能力映射:** C7、C5；A2

**规范依据:** 授权生命周期、凭证与控制接口；专项验收、持久化替换与实施交接。共享实施及报告约束见本工作包规格说明。

- [ ] 以 bbolt 持久实现所选配置的身份登记、策略、授权、撤销、预留与凭证记录，正式入口完成签发、拒绝、撤销及目标绑定使用。
- [ ] 管理状态、操作回执、消费预留和通知在规定本地事务内更新，单次执行消费仍由 ExecutionStore 管理，不能跨模块假设事务。
- [ ] 一致跨请求快照使用受控固定产物和变更边界，读事务占用有界，超大快照显式失败；副本应用与游标原子推进。
- [ ] 当前身份、祖先限制、出示证书绑定、时钟及离线状态与 SQLite 路径一致，恢复旧数据库或同步失败不能放宽策略。
- [ ] 凭证继续 AES-GCM 及独立主密钥，轮换中断可恢复；受信登记、撤销水位和加密格式保留，持久 I/O 不明不凭缓存放行。
- [ ] 共跑身份伪造、配额交付未知、撤销同步、时钟异常和轮换故障，明确对应数据库文件及实际平台范围。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
