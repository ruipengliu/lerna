# 60: 通过 A2A 受理外部任务

**What to build:** 外部请求经统一任务准入运行并返回 Message/Task；以独立对端验证版本、授权、期限、重复与终态映射。

**Blocked by:** 28：委派子任务并收集结果；50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C5、C6、C7；A4

**规范依据:** 原生接口与消息目录；扩展清单、运行器与激活恢复。共享实施及报告约束见本工作包规格说明。

- [ ] 独立外部 Agent 经既定 A2A HTTP+JSON 服务端提交任务，映射受信主体、有限权限及预算，通过 Harness TaskService 真实运行并返回 Message 或 Task。
- [ ] 固定协议/SDK/规范快照并按原生语义映射生命周期，调用者不能直接写终态或用外部状态重开已终结任务。
- [ ] 查询按当前权限提供状态/结果，取消受理与停止分别返回；必要句柄及外部关联持久化，重复和重启恢复能力如实声明。
- [ ] 支持规定的 JSON 媒体类型与结构化错误，SSE/推送仅按声明启用，不默认依赖 webhook 或把方法存在当已支持。
- [ ] 用独立客户端验证受理、流转、结果、权限/期限拒绝、取消竞态及版本不支持，与出站适配分别报告互操作方向。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
