## Agent Brief

**Category:** enhancement

**Summary:** 提供可经正式 SDK 保存、定位、分块读取及清理的受控证据/产物服务，以当前权限、来源和位置限制约束引用及正文，并在真实 SQLite 与文件中断后恢复原发布及清理进展。

**Current behavior:**
已有本地身份、策略、有限持续授权、受限签名授权及任务运行基础；任务结果中的证据标记不构成内容服务。尚无内容元数据、受控引用、暂存发布、正文读取和留存清理的完整切片。既有任务授权事务绑定 task/local；内容操作必须能表达实际用途和可信位置，并保留原任务行为及已有数据库恢复能力。

**Desired behavior:**

证据与产物共用内容生命周期，以类型区分含义。受控引用在命名空间内定位精确内容修订；来源包含类型、引用及来源修订，获取/生成时间、媒体类型、长度和内容摘要可核对。正文修订不可被悄悄替换，生命周期修订与内容修订语义分开；无需为每个字段再建立全局实体。引用及其元数据只披露获准部分，来源声明只用于追溯，不作为授权或事实真实性证明。

保存前分别检查存储、处理、发现、披露及留存约束。实际主体和处理/存储位置由受信绑定提供，请求中的用途、接收范围和保留期限只能收缩权限；来源策略由受信接口解析，多个来源取适用限制交集，无法解析必需限制时拒绝。持有来源引用不自动授权读取来源、长期记忆保存或同步。当前本地部署无需启动云服务，也不能因以 local 命名位置便跳过政策判定。

小正文直接持久到 SQLite；超过显式阈值的正文以有界方式进入受控内容目录。只有完整内容已耐久保存、可读并通过长度及摘要校验，且提交时权限与来源限制仍有效，才发布引用和稳定操作回执。文件准备在数据库事务外进行，发布元数据与回执在声明的本地原子边界提交；文件系统与 SQLite 之间用可恢复状态协调。并发清理不得误删正在准备或已发布的内容。未确认提交不能报告成功，重试沿原 operation_id 核对，不生成第二份产物。

读取引用元数据与读取正文是不同操作，均检查当前权限；分块固定内容修订、偏移和有限读取范围，每次返回正文前复验适用限制。已知权限撤销、来源失效、删除或到期后拒绝新分块，不承诺撤回已披露字节。授权可见的正文缺失、损坏或存储不可用分别如实表达；无权主体的响应不泄露记录是否存在、已删除或缺失。不能以公开 URL、任意宿主路径或摘要本身作为读取凭证。

有权删除须绑定原操作及预期生命周期修订；到期按可信时间立即停止新读取，实际清理可分批恢复。清理区分新使用已阻止、正文清理中和已清理，覆盖声明范围内的小正文、大正文和暂存副本。只保留政策允许的最小引用/核对状态，不借去重保存已禁止留存的正文。历史发布是否成功与当前内容是否可用分别返回；清理后原操作补交不得复活正文，无法可靠比较原语义时拒绝重交并指向原操作查询。外部效果和任务事实不因正文删除被改写。

**Key interfaces:**
- 受控内容用例 Interface：提供保存/发布、读取元数据、读取有限分块、删除和 LookupOperation 语义；上传可有界分阶段，但准备状态不等于发布成功。名称由实现决定，不暴露存储句柄、路径或无限 Reader 给普通调用方。
- 内容引用与元数据契约：命名空间、精确内容修订、来源及来源修订、时间、媒体类型、长度、摘要、控制约束及当前可用状态；正式 SDK/Protobuf 表达固定结构，未知必需字段或限制拒绝。
- 策略与可信上下文 Interface：复用既有身份、资源和授权判定，补齐用途、位置、来源限制和留存判定；受信配置与普通请求分离，不能以管理员身份绕过业务内容政策。
- 元数据 Store 与正文 Adapter：调用方按接口依赖，参考实现使用 SQLite 和受控本地目录；原操作回执与发布/删除状态原子保存，文件 I/O 与数据库提交不伪装成跨存储原子事务。
- 清理与恢复入口：有界扫描及可重入处理，协调活跃准备、已发布内容及待清理状态；持续失败或暂不可用保持可核对进展，不悄悄标记已清理。
- 配置：小内容阈值、单对象/总存储/暂存容量、元数据及来源数量、分块大小、并发、准备期限、I/O 时限、保留期限、清理批次及回执容量均显式有界。无必需外部服务；无效配置拒绝启用。

**Acceptance criteria:**
- [x] 正式 SDK/本地协议入口可保存、读取元数据、读取分块、删除并查询原操作；重启后保留精确引用、修订和回执，不以任务证据字符串冒充内容服务。
- [x] 保存后可核对来源及修订、时间、媒体类型、长度和摘要；读取精确修订不返回其他版本，篡改、截断、错误摘要或未知必需限制不能得到成功正文。
- [x] 独立负例验证存储、处理、发现、披露与留存限制：引用可见但正文不可读、可读取但不可再保存、允许本地存储但禁止向其他位置披露；策略不能由请求自报主体、位置或来源标记绕过。
- [x] 多来源限制收缩有效，缺失必需来源政策或已知来源修订失效时拒绝受影响的新使用；不把来源引用或客户端时间当作可信授权依据。
- [x] 小正文走真实 SQLite，大正文走真实受控目录；暂存完成、长度及摘要校验和可读性确认之后才发布，文件不可读或提交未确认时无虚假成功。
- [x] 相同操作相同语义返回原发布身份，换正文、来源、用途或其他影响语义的字段拒绝身份复用；跨类型/跨主体/跨命名空间复用不绕过去重，关闭接纳窗口不使旧操作重新受理。
- [x] 分块限制单次大小、范围、总对象大小、并发和期限，固定内容修订；越界、慢读取、超量及取消有明确有界结果，不能靠无界缓冲实现所谓分块。
- [x] 读取过程中策略收紧、到期、删除或已知来源失效后，新分块被拒绝；无权查询存在与不存在引用不暴露存在性，错误、日志和回执不含受限正文或宿主敏感路径。
- [x] URL、绝对路径、目录穿越、符号链接越界及伪造存储标识不能读取或删除受控目录外文件；适配器内部生成的定位信息不成为外部访问凭证。
- [x] 授权可见的悬空引用、损坏正文和存储不可用有可观察区别；原发布回执只证明历史提交，不把缺失正文显示为当前可读，也不自动以新正文修复旧身份。
- [x] 有权删除核验预期生命周期修订并原子保存决定与回执；到期立即阻止新读取，正文删除失败显示清理中，恢复后继续同一清理，不提前声明完成。
- [x] 暂存垃圾、到期正文及允许删除的内容副本被有界清理；并发发布与清理、读取与删除不会交付不完整内容或误删其他仍有效引用的正文。若共享物理正文，证明跨引用的权限和清理隔离，否则不引入共享假设。
- [x] 删除或到期后原回执不返回正文，原操作重放不复活内容；允许保留的最小状态可核对历史提交及当前可用性，不改变已有任务/操作事实，不承诺介质立即物理擦除。
- [x] 真实子进程中断至少覆盖暂存未完成、文件已准备但引用未发布、发布提交后回包丢失、删除决定提交后正文未清理、正文清理后进展未确认；重开原 SQLite/目录后无重复发布、无虚假清理完成、可回收孤立暂存。
- [x] 真实多句柄竞争覆盖重复发布及发布/清理竞争；权限在文件准备期间收紧时，最终发布拒绝失效授权。故障注入通过独立可观察状态核对结果，而非仅自报成功。
- [x] 原 SQLite 身份、授权、任务与控制记录仍可恢复；如扩展持久编码提供旧记录升级验证，不删除数据库迁移，不覆盖已有运行数据分区。
- [x] 提供具名可重复 profile，记录配置、版本/依赖、执行方法、实际结果与范围；01–06 适用回归通过，区分本地权限验证、文件/SQLite 耐久恢复与尚未实现的远程能力，不改写历史报告。
