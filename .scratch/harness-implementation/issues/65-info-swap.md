# 65: 替换搜索与内容获取 Adapter

**What to build:** 分别接入独立搜索和获取实现，复用证据及失败契约；固定重放和实际联网的支持范围分开报告。

**Blocked by:** 22：搜索、综合证据并回答问题；50：准备并激活受信能力插件

**Status:** ready-for-agent

**能力映射:** C3、C6、C7；V1；A2

**规范依据:** 工具执行与多模拟设备；能力里程碑与实施依赖；专项验收、持久化替换与实施交接。共享实施及报告约束见本工作包规格说明。

- [ ] 搜索与内容获取分别接入至少一个与默认实现独立的 Adapter，以相同信息需求和证据契约完成问答链路。
- [ ] 分别保留真实来源、获取时间、支持范围、失败与部分证据；不可访问或只录制响应时不能标为实际联网通过。
- [ ] 不同结果形式经明确映射进入 Task Context，引用解读不能依赖供应商私有对象，公开链接不自动成为结论支持。
- [ ] 权限、查询隐私、内容留存、请求预算和实际处理位置在替换后继续检查，凭证不进入模型或异常文本。
- [ ] 用共同可回答/冲突/不足/失败用例比较替换，两种搜索和两种获取各留证，固定回放与真实网络分开，完整 V1 数值另验。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
