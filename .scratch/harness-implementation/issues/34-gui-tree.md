# 34: 通过结构树完成模拟 GUI 动作

**What to build:** 多模拟设备执行点击、滑动、追加/替换输入和返回；重新观察验证独立业务状态，陈旧前提拒绝。

**Blocked by:** 12：接管并恢复共享资源；14：让大脑选择 API 并完成任务

**Status:** ready-for-agent

**能力映射:** C4、C5、C7；V2

**规范依据:** 工具执行与多模拟设备；执行接口、资源控制与故障验证。共享实施及报告约束见本工作包规格说明。

- [ ] 多个模拟设备各有独立页面、控件、焦点、滚动、导航和业务状态；以结构树观察经正式能力调用完成点击、滑动、替换/追加输入及返回。
- [ ] 观察携带设备/应用、生命周期、视图版本、采样时间及定位信息，动作原子核验模拟前提；陈旧观察拒绝并重新观察，新语义动作另用操作身份。
- [ ] 动作后再次观察并以独立业务状态及历史验证效果；驱动返回成功、页面相同或成功提示不能单独证明正确或未重复。
- [ ] 同设备 GUI 变更串行、不同设备可并行，资源接管阻止新动作，恢复先观察和核对；模拟手动操作/弹窗/布局变动能改变后续选择。
- [ ] 真实模型使用获准结构树完成有限任务，脚本驱动另跑确定性套件；本票自动化例明确无适用 API，路径切换资格由后续共享状态票验证。
- [ ] 截图/文字及输入遵守位置策略，图像未启用不偷偷调用云端感知；不要求 Android/iOS 或真机。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
