## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement

**Summary:** 在原任务授权与预算内，经可替换搜索和获取能力取得证据，由 Brain 形成可核对的答案及明确缺口。

**Current behavior:** 正式任务已支持能力发现、行动、执行、受控内容、实际 HTTP 获取、有限失败事实和恢复。AnswerBrain 可生成受控文本与来源集合，但没有网络搜索发现、结论与实际片段关联、冲突/不足综合的完整流程。来源集合合法不等同引用支持或覆盖合格。

**Desired behavior:**

- 从用户信息需求提出有限搜索，经消费方定义接口选择搜索 Adapter，返回带实际查询时间、模式、来源和状态的有界候选；真实 HTTP 与固定资料可独立运行。普通 Snippet 只用于发现；豆包 Summary 可作为标明来源的二手证据，不能声称已经读取原始页面。
- 搜索与获取沿正式 Core/Brain/Execution/SDK 工作，Core 推进任务状态，不另建绕过其授权、用量和恢复的执行循环。搜索结果、网页、模型不能授予新的目标范围、处理位置、凭证或个人信息披露权。
- 总结模式直接使用受控搜索响应中的 Summary，不再请求候选页面；显式页面模式可经 21 获取接口取得受控正文及实际时间。结论引用精确关联已取得材料、摘要、片段范围与获取时间；拒绝伪造来源、越界片段及引用内容不匹配。结构核验只能证明可追溯性，语义支持和必要事实覆盖由独立评价核对。
- 答案契约区分可回答、证据不足、来源冲突、获取失败，可保留部分有据结论和同时存在的缺口。明确必要范围和时效；不把检索无结果等同事实不存在，不从失败补造正文，不默认以多数或最新来源消解冲突。已有普通问答保持兼容。
- 搜索、抓取、模型及必要查询均有任务级硬上界，含失败、重定向和恢复观察。每个新操作在对外调用前预留，重复和中断恢复沿原身份核对，不能退款后无限重试，不能以新查询/新抓取冒充原结果。
- 查询文本、正文、上下文、模型输入和答案出口均遵守原始及个性化来源的用途、位置、期限和披露限制。保留独立授权，当前授权在对外调用及交付前复核；撤权/过期后不得通过答案、引用、日志或评测继续披露。网页指令不能改变运行授权，不自动写长期 Memory。
- 提供 SDK/CLI/profile 可重复入口。Go 与单机 SQLite 默认可运行，不引入必需搜索服务器或云数据库；联网及模型服务按能力配置，实现依赖消费方 Interface。外部配置缺失和真实网络失败如实报告，不用固定桩替代实际联网结果。
- 在实现之前固定小型独立评价材料、必要事实、引用支持/覆盖分母和四类预期处置；评分不由被测模型自评，不在看到结果后变更题型。固定资料、真实 HTTP、公网和真实模型分别报出版本、环境、来源时间、配置、预算与限制。

**Key interfaces:** 搜索候选与搜索状态的消费方接口；正式能力声明/参数 Schema；Core 任务及原操作用量；21 获取证据与有限失败接口；Task Context 当前来源验证；Brain Model 的结构化答案契约；受控答案保存、发布、查询与原身份恢复；独立答案/引用评测接口。

**TDD seams:** 按持续授权，以真实 Core/SDK/授权/Content、SQLite、可观测 HTTP 搜索服务与页面、模型服务边界、正式答案查询为测试边界。模型协议夹具仅验证运行契约，实际模型质量另验；不 mock 自有业务模块，不直接读取数据库断言业务结果。

**Acceptance criteria:**

- [x] 用户任务经正式搜索取得总结（或按显式页面模式获取材料）、Brain 综合并发布可查询答案；引用可追溯实际片段、内容摘要与时间。
- [x] 可回答、不足、冲突、获取失败四类各有运行记录；关键结论由实际取得的 Summary 或正文支持，不以普通 Snippet 或未获取链接替代；部分失败与冲突不被成功内容掩盖。
- [x] 搜索及页面越权、恶意重定向、网页指令、个性化禁止外发、运行中撤权和过期被正确阻止；答案及引用继承全部来源限制。
- [x] 搜索、抓取、模型和必要查询有原任务预算；失败及未知消耗保留，重复/中断不重置预算、不重新获取后冒充原证据。
- [x] 独立小型评价报告逐例必要事实、引用支持/覆盖分子分母、不适用项及判定；协议夹具不宣称真实模型效果，实际联网和固定材料分开运行并记录。
