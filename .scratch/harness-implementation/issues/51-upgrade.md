# 51: 升级、停用和回滚固定版本扩展

**What to build:** 新工作用新绑定，在途工作固定旧版本；崩溃、投影延迟、隔离与删除引用不丢失恢复事实。

**Blocked by:** 50：准备并激活受信能力插件；11：恢复异步与未知效果调用

**Status:** ready-for-agent

**能力映射:** C6、C5、C7

**规范依据:** 扩展清单、运行器与激活恢复；执行接口、资源控制与故障验证。共享实施及报告约束见本工作包规格说明。

- [ ] 升级精确版本后新工作选新绑定，已固定的决策/动作继续原版本，Schema、Skill、实现及恢复资料以持久引用保留。
- [ ] 启动在事务外，未激活候选不得接正式工作；激活提交失败隔离候选，提交不明先核对原操作，投影交接可恢复。
- [ ] Disable 区分排空与风险隔离，停止新路由并跟踪在途真实状态，无法取消的外部工作不因卸载标为结束。
- [ ] 回滚再次验证旧版本信任、权限、依赖和持久状态兼容；不兼容保持待处理，不能回滚业务数据库抹去新事实。
- [ ] Remove 需无在途/恢复/允许保留的引用，敏感内容删除按来源策略处置工作而非无限保留；操作回执、消费和水位不随卸载删除。
- [ ] 注入并行调用中升级、激活前后崩溃、投影迟到、旧版本重启、隔离迟到结果及回滚失败，证明无重复未知动作。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
