# 54: 让 Wasm 执行受控子动作

**What to build:** 每个子动作持久登记身份、预算和授权，受限 hostcall 交付效果；中断后核对原动作，不盲目重跑脚本。

**Blocked by:** 53：运行受限 Wasm 计算能力；14：让大脑选择 API 并完成任务

**Status:** ready-for-agent

**能力映射:** C4、C5、C6、C7

**规范依据:** 扩展清单、运行器与激活恢复；执行接口、资源控制与故障验证。共享实施及报告约束见本工作包规格说明。

- [ ] 执行类 Wasm 通过裁剪宿主接口提出受控子调用，内核/执行先持久登记操作、父子关联、授权及预算，再改变模拟业务状态。
- [ ] Brain 类扩展只能返回提案，不获得直接执行/记忆写入 hostcall；未声明接口、越权参数或数据位置不符实际拒绝。
- [ ] 子动作不因嵌入脚本获得新预算池，SDK 重试也不能改变原身份；返回文本不等于子动作效果已确认。
- [ ] 在子动作发出/生效、guest 返回及回执窗口中断，恢复按原子动作核对；不恢复 Wasm 栈，也不盲目重启脚本重复写入。
- [ ] 纯计算仅在声明可重跑且剩余预算允许时重执行；停用或资源超限仍保留已发生效果和恢复记录。
- [ ] 用有状态目标检查重复次数、取消及未知效果，宿主回调的限额、期限、秘密引用和错误输出均落实。
- [ ] 提供可重复验证入口，记录实现/依赖、配置、环境、执行方法、实际结果与限制；未运行或失败不写成通过。
