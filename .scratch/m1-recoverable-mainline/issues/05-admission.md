# 05: 准入：脚本化提议到动作意图交接

**What to build:** 脚本化推理对任务提出一次 API 调用的提议；任务编排在裁决域的一个事务中执行准入门禁（条件、预配置的持续授权、按单次费用上界的最小预留），写下动作意图和待办工作，再按 R7 三步交给执行管理持久接纳。用户能查询到已准入的动作及其依据。

**Blocked by:** 03（持久化点崩溃钩子与重启）、04（待办工作、租约与接替）

**Status:** ready-for-agent

- [ ] 脚本化推理实现推理的公共接口，提议绑定快照中的条件版本、输入版本和控制版本
- [ ] 准入门禁按核心契约 2.6 的编号条件实现；本工单涉及的条件各有带编号标注的测试（如"准入-n"）
- [ ] 持久记录写明动作基于的条件版本、授权和预算（标注 G4）
- [ ] 费用上界未知的调用不准入
- [ ] 提议本身不产生任何执行；只有准入后的意图进入执行管理（标注 G6、R1）
- [ ] R7：裁决域记下意图 → 执行管理持久接纳（P2）→ 裁决域记下回执；在三步之间分别崩溃和丢回执，恢复后查询原交接，不新建（标注 R7）
- [ ] 同进程也不省略回执，不跨域共用事务
