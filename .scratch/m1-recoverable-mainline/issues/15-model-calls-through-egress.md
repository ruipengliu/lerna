# 15: 模型调用经出口闸门

**What to build:** 推理的每次模型调用由受信宿主封存完整调用描述后准入，按费用上界预留，经出口闸门发往模拟模型供应商，用量回报预算。推理崩溃后同一调用位置拿回原结果，不再发送；模型超时后原调用保持未知、费用继续结算。

**Blocked by:** 06（出口与效果：一次 API 调用经出口闸门）、10（预算结清、未知费用与迟到费用）

**Status:** ready-for-agent

- [ ] "提议请求 + 调用位置"标识一次模型调用；同位置同描述返回原结果，同位置不同描述报冲突
- [ ] 调用位置额度与实际发送额度分开计算；M1 两者都为 1
- [ ] 准入之后不得改变调用输入；无法重现描述时返回"准备不可恢复"
- [ ] 模拟模型供应商独立记录真实发送次数；推理崩溃恢复后次数不增加
- [ ] 模型响应超时按未知处理；用新位置重新采样不消除原调用的未知和费用
- [ ] 流程按"模型调用"流程文档的三段和故障表逐项测试
