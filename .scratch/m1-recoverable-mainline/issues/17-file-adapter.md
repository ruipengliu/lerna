## Answer

已实现 `managed://根标识/目标标识` 的受管理单文件读取、创建、版本检查替换、原尝试查询与显式准入清理。纯文件适配器固定调用描述；所有原生读写经统一 P4/P5 出口，发布／删除前重查授权、内容资格、控制与领取。真实 CLI 通过受信宿主的 `--file-root 根标识=绝对路径` 装配不可变根映射，配置不创建文件、不绕过准入。

对象与提交指针采用稳定独立锁、锚定原生目录句柄、不可变根身份绑定、四道独立文件／目录屏障和完整读回。拒绝符号链接、硬链接、特殊文件、根替换和跨设备复制回退；同步失败不得凭可见或读回匹配宣称持久完成。原 A 证据未被账本接纳时 B 不能覆盖，原查询只读且保留原动作／尝试／发送身份；A/B/C 串行交接、账本不可用／回执未知、同版本竞争、历史查询与清理责任均通过公开入口验证。文件能力不声明写入幂等，清理如实声明可能部分完成；临时资源与内容来源、持有和追踪事件随原事务保存，追踪不复制原生路径、身份、正文或自由错误文本。

`conformance/executor.Run` 以同一公开 fixture 工厂接口验证模拟 API 与真实文件目标，使用独立目标次数确认许可重放不增加发送或发布。真实 CLI 子进程覆盖创建、替换、原回执重放、非法配置与跨重启根重绑定拒绝。文件零费用来自固定可信非计费规则，查询／原发送／重发保留独立费用来源。完整普通预检发现并修复了既有 `simulator-idempotent-queryable` 到 `simulator-queryable` 的固定查询对应回归；追加三分支实际目标／费用身份断言，以及文件跨适配器查询拒绝与零目标 I/O 检查。

2026-10-06 验证通过：普通全包 race 预检 220.979 秒；全部非存储故障 race 预检 851.749 秒；同一冻结树 `8ff205ed86702b86480c0fde8381907bac447bd7` 的完整 `make check` 4456.104 秒（完整 fault 包 4185.892 秒），包含所有原有 SQLite／首次启动／P4 存储检查。真实原生轨迹的 225 个字节与命名空间镜像、四个实际省略屏障负对照，以及 980 个 SQLite 事件与 14 个原生事件构成的 995 个共同切点、全部 4975 个联合恢复镜像均纳入该完整检查。随后仅补充本票据结论与 ADR 验收记录，运行代码未变更。

支持的平台、布局、元数据策略、有限故障模型及未覆盖的物理断电／inode 重分配边界见 [ADR 0007](../../../docs/adr/0007-managed-file-publication.md)。最终原始日志保存在工作区旁的 `lerna-m1-context/ticket17-full-make-check.log`；首次普通预检失败和定点修复证据一并保留。
