# 08: 授权与确认

**What to build:** 用户可以对具体动作给出单次授权或有明确范围和期限的持续授权，在命令行确认核心生成的动作描述；确认只消费一次，参数改变后旧确认失效；撤销授权后依赖它的新准入立即被拒绝，并能查询撤销进度。

**Blocked by:** 05（准入：脚本化提议到动作意图交接）

**Status:** ready-for-agent

- [ ] 单次授权与动作在准入事务中原子绑定；持续授权有主体、资源、动作、范围、期限、用户和语义版本
- [ ] 确认绑定核心生成的描述和事项类型；回执丢失后重试只消费一次（交互适配器 M1 演示 2）
- [ ] 参数改变后旧确认失效
- [ ] 出口凭据为不透明引用，绑定准入、主体、出口、请求摘要和期限；出口处再次核验当前有效性
- [ ] 撤销被接纳后新准入和新凭据被拒绝；同进程内撤销与出口的竞争按权威检查处排序；进度可查询
- [ ] 操作权利与处理目的两字段保留，未知值拒绝；委派、组合多个来源返回"不支持"；不得实现成"读取自动包含保存、同步和行动"
