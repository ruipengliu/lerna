# 02: 提交目标与创建任务

**What to build:** 用户在命令行输入一个目标，Lerna 持久保存输入、创建会话和任务，并能查询任务快照。这是第一条端到端切片：Protobuf 定义命令身份、回执、会话输入和任务；持久工作的命令回执落在 SQLite（本地档）；进程内装配（harness）可以被测试用公共契约命令驱动。

**Blocked by:** 01（骨架与工具链）

**Status:** ready-for-agent

- [ ] 命令行可以提交目标、查看会话和任务的全量快照与当前阶段
- [ ] 同一 `CommandIdentity` 同内容的重复提交返回原决定，只有一个任务；同标识不同内容被拒绝（测试标注 G3 及持久工作的命令回执规则）
- [ ] "提交结果未知"时可以用原标识查询决定，明确区分"没看到"和"确定没提交"
- [ ] 业务修改、回执和必要的待办工作在同一事务提交；处理函数没有事务外副作用
- [ ] SQLite 的同步和日志设置满足本地档的声明（ADR 0001），配置写在一处
- [ ] harness 与生产宿主共用同一装配代码；测试只通过公共契约命令驱动，断言持久记录
- [ ] 所有记录和接口带用户范围，错误身份被拒绝
