# 18: API 适配器

**What to build:** 用户可以让 Lerna 调用按固定版本能力描述接入的真实 HTTP API：确定性参数编译、凭据引用加受控注入、固定幂等键、单次请求、原尝试查询；遇到 429 时持久等待并区分限流类别。

**Blocked by:** 12（安全重发与保持未知）

**Status:** resolved

- [x] 能力描述固定版本；参数编译确定性
- [x] 凭据以引用表示，只在出口处注入；推理和适配器看不到真实密钥
- [x] 幂等键在尝试创建时固定，安全重发沿用
- [x] 429 区分速率、并发和资源冲突，持久等待，不由适配器自行重发
- [x] 未知和迟到的回报按执行管理规则处理
- [x] 与模拟 API 通过同一套执行适配器一致性测试
