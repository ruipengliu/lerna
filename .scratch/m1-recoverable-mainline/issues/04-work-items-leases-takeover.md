# 04: 待办工作、租约与接替

**What to build:** 持久工作的待办工作能被工作者原子领取、续租，租约到期后由另一工作者接替；被接替的旧工作者不能再覆盖当前推进。用户感受到的是：进程中途卡住或重启后，任务继续推进且不出现两个执行者。

**Blocked by:** 02（提交目标与创建任务）

**Status:** ready-for-agent

- [ ] 原子领取、有界租约、续租、领取代次、工作修订号、受阻和封闭
- [ ] 旧领取者在接替后提交的写入被拒绝（fencing），用故障测试证明（标注 G11）
- [ ] 接替不改变动作的执行端点
- [ ] 持久工作语义测试按"同一事务后端接口"组织，以便将来 PostgreSQL 后端复用同一套用例
