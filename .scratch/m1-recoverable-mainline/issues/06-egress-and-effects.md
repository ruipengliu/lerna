# 06: 出口与效果：一次 API 调用经出口闸门

**What to build:** 已准入的动作由执行管理创建尝试和发送身份（P3），出口闸门执行开始门禁（P4，占用发送额度），持久写下"可能已发出"（P5）后，向模拟 API（幂等型）发送；原始观察、用量和轨迹分别回报（P6、P7），执行管理判定效果（P8）。用户能看到动作的效果和证据。

**Blocked by:** 05（准入：脚本化提议到动作意图交接）

**Status:** ready-for-agent

- [ ] 模拟 API 独立于被测进程记录真实收到的调用次数、请求标识和生效时间；正常路径下次数为 1（标注 G5）
- [ ] 没有 P5 持久化成功不得执行外部 I/O；在 P4 前、P4 与 P5 之间、P5 之后分别崩溃，恢复后的行为与出口闸门 4.1 一致
- [ ] 开始门禁的条件各有带编号标注的测试（"开始-n"）
- [ ] 效果三态（已生效、未生效、未知）由执行管理写入；适配器只回报（标注 R3）
- [ ] 禁用隐式重试与回退：出口闸门和适配器内部不重发
- [ ] 执行适配器的能力属性（效果、幂等、可查询）由适配器声明，执行管理据此决策；模拟 API 提供幂等、可查询、不可查询三种配置
