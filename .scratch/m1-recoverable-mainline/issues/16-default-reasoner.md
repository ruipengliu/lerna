# 16: 默认推理

**What to build:** 提供 M1 的默认推理：根据目标、条件版本、进展和证据来源，确定性地选择和裁剪上下文，经模型调用产生提议，解析四类提议。用户用真实模型（或模拟供应商）运行一个简单任务能得到合理提议。

**Blocked by:** 15（模型调用经出口闸门）

**Status:** ready-for-agent

- [ ] 上下文快照只用确定性的选择和裁剪，不做模型摘要
- [ ] 每个提议请求最多一个调用位置；关闭自动重试、降级、修复和摘要
- [ ] 解析四类提议；提议绑定版本、引用证据并说明缺口
- [ ] 有限计划长度上限为 1，参数只允许具体值
- [ ] 可以机器核验的条件使用明确核验规则；主观条件关联用户确认
- [ ] 与脚本化推理通过同一套推理接口一致性测试
