# 11: 可查询目标的结果核对

**What to build:** 当动作结果未知且目标可查询时，执行管理按证据核对效果：只有确认未生效并且原请求不会再迟到生效，才记为"未生效"。核对有持久调度、退避、上限，可以暂停和恢复，并通知任务编排。

**Blocked by:** 06（出口与效果：一次 API 调用经出口闸门）

**Status:** ready-for-agent

- [ ] 模拟 API（可查询型）注入接单后丢回执、提交后丢回执、弱查询、延迟生效
- [ ] "只查到当前不存在"不足以判定未生效（标注 G1）
- [ ] 核对查询本身经过准入和出口闸门
- [ ] 核对调度、退避、上限、暂停、恢复都持久；重启后继续
- [ ] 迟到的回报独立接纳，结果仍归原动作（标注 G11）
