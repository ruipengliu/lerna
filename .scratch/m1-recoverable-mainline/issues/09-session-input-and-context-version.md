# 09: 会话输入与上下文版本

**What to build:** 用户在任务运行中修改目标或回答问题，修改被接纳后，基于旧上下文的提议无法准入；一个会话可以先后关联多个任务，任务关闭不关闭会话；分支和历史编辑明确返回"不支持"。

**Blocked by:** 05（准入：脚本化提议到动作意图交接）

**Status:** ready-for-agent

- [ ] 会话输入类型：新目标、修改、回答、确认、任务控制，带准确的目标和请求引用
- [ ] 会话事务序、稳定身份、依赖和版本检查；模拟并发下不误投、不丢输入
- [ ] 修改或回答被接纳后，旧快照上的提议被准入门禁拒绝
- [ ] 条件集接纳只支持任务模板和显式条件列表；模板外的目标请求用户澄清
- [ ] 分支与历史编辑返回"不支持"，不原地覆盖
