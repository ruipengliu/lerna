# 模块与数据 UML 图册

用户已接受首轮建议：UML 组件图与领域类图；全局总览加九模块详图；独立原生多页 `docs/architecture/diagrams/uml-models.drawio` 与 `docs/architecture/uml-models.md` 导读。沿用优化后的浅色样式，模块结构和数据关系分别成页。

只投影当前设计、接口登记、Schema 及持久记录约束，不新增代码类、继承、ORM、外键、级联删除或部署承诺。领域类图允许省略方法区；行为接口在组件页单独表达。字段名优先用精确 Schema；内部记录以实现文档明确命名为准，标注来源。

组件页采用 `«component»`、`«interface»`、实现（虚线空心三角）和依赖（虚线开箭头）。领域页使用类型属性、普通关联、多重性与必要约束；没有生命周期依据时不画组合或聚合。
